# Strict 规则重编号方案（`SXXYY`）

> **状态**：**已落地**（`src/passes/strict_style.py`、测例、`docs/编码规范.md` §1.1）。本页保留旧→新对照供查阅。  
> **现行规则表**：[编码规范.md §1.1](./编码规范.md#11-翻译期强检查--strict默认开启)。

将 `--strict` 报错编号从 `S01` / `S06a` 迁到 **`SXXYY`**（前两位=类别，后两位=类内问题）。落地时默认：一次切换、升格 `S06a`–`e`、不拆 S27/S25/S47、删除文档幽灵「Result/@noexcept」条目。

---

## 1. 编号约定

| 位 | 含义 | 例 |
|----|------|-----|
| `S` + **前两位 `XX`** | 类别 | `01` = 命名与标识 |
| **后两位 `YY`** | 类内序号 | `0103` |
| 旧 `S06a`–`S06e` | 独立四位号 | `S06b` → `S0304` |

报错格式：`[S0304]`（四位）+ 场景 + 请用/勿用 + 原因 + 例如。

---

## 2. 分类（01–12）

| XX | 类别名 |
|----|--------|
| **01** | 命名与标识 |
| **02** | 模块布局 |
| **03** | 构造与 `new` |
| **04** | 字段初始化 |
| **05** | 属性与访问器 |
| **06** | 类型注解形态 |
| **07** | 表达式惯用法 |
| **08** | 分支与模式 |
| **09** | 字符与转换 |
| **10** | 签名与继承 |
| **11** | 基础设施类型外露 |
| **12** | 生成器与解包 |

原文档双「S36」：元组解包 → **S1202**；「Result/@noexcept」文案已删除（未实现检查）。
