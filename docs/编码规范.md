# Py2Cpp 标准库编码规范

本文档总结 `py2cpp/` 下标准库 Python 源码的**推荐写法**，以 `str.py`、`list.py`、`dict.py` 为范本。后续新增或修改标准库、示例与测试代码时，**应优先遵循本规范**。

> 翻译器能力、类型系统与架构说明见 [参考手册.md](./参考手册.md)。本文聚焦「怎么写才译得好、读得懂」。

---

## 1. 基本原则

| 原则 | 说明 |
|------|------|
| **Python 即规格** | 源码同时是 C++ 生成的规格书；写法应接近 CPython 3.13 文档语义，便于对照 `library/stdtypes.html`。 |
| **对照 CPython 实现** | 算法与 API 语义以 [cpython v3.13](https://github.com/python/cpython/tree/v3.13.3) 的 `Objects/`、`Python/` 为准（见 [§8](#8-对照-cpython-313-标准实现)），勿照搬 C++ STL 惯用法。 |
| **禁止 STL** | 标准库 `.py` 与生成 C++ **均不**使用 `std::string`、`std::stringstream`、`std::ostringstream`、`std::vector` 等；容器用 `PyArray`/`PyList`，字符串用 `PyStr` + `char[:]` + C 库 `snprintf`/`fprintf`（见 [§9](#9-字符串构建与格式化禁止-stl-字符串流)）。 |
| **语法糖优先** | 能用运算符、`len`、`in`、字面量、`Self`、`new` 表达的，不要手写 dunder 调用。 |
| **协议集中实现** | `__getitem__`、`__contains__` 等只在类内实现一次；其它方法通过 `self[i]`、`x in self` 复用。 |
| **概念用 `@protocol`** | 优先 `from .protocols import SizedType, IterableType, IteratorType, ComparableType, …`；`...` 方法体，不生成 C++ 类、不作继承基类。 |
| **类型写全** | 局部变量、参数、返回值尽量带注解（`list.py` / `dict.py` 风格）；无注解时的 ``T0``/``void*``/``int`` 分工见 [参考手册 §5.3.1](./参考手册.md#531-缺少注解时的-c-类型策略)。 |
| **void 协议 / 生命周期** | **隐式 void dunder**（``__init__``、``__del__``、``__copy__``、``__move__``、``__exit__``、``__post_init__``、``__setitem__``、``__setattr__``、``__delattr__``、``__delitem__``、``assign``）**勿**写 ``-> None``。其它 void 方法（含模板、无 ``return expr``）自动推断 ``void``，**不必**写 ``-> None``。``__enter__`` / ``async def __aenter__`` 等仍须写返回类型（如 ``Self`` / ``int``）。 |
| **类型别名** | …**条件类型**（G1）：``type ListElemOf[T, _V = ...] = _V if T is list[_V] else T`` 等，见 [type-conditional.md](./type-conditional.md)。 |
| **私有逻辑下沉** | 复杂算法放在类内 `_` 前缀辅助方法（**优先**实例 ``@immutable`` 方法，见 [§6.0.1](#601-私有-helper-实例方法优先)）；仅无自然接收者（工厂、哨兵、纯元数据）时用 ``@staticmethod`` / ``@classmethod``。辅助类用 **PascalCase**（``ListIterator``、``ZipIterator``），勿用 `_Foo`。 |
| **Python / C++ 命名** | 源码写 Python 名（``class range``、``list``、``DictEntryUnsafe``）；C++ 默认加 ``Py`` 前缀（``list``→``PyList``，``_Handle``→``_PyHandle``）。标量见 ``CPP_RENAME``；特殊缩写仍可用 ``@native_name``。**勿**在 ``.py`` 里手写 ``PyRange`` / ``PyList``。 |
| **`range` 译法** | **仅** ``for i in range(...)`` → 原生 C++ ``for``；其它 ``range(...)`` → ``py2cpp::util::range::PyRange``（见 ``py2cpp/util/range.py``）。 |

### 1.0 标识符命名（强制）

与 CPython **拼写刻意偏离**时，以本表为准（语义仍对照 §8）。**特殊类型后缀**与 **Meta / Var / Mixin / 异常** 由 **S47** 翻译期强制检查。

#### 1.0.1 一般标识符

| 类别 | 规则 | 示例 |
|------|------|------|
| **模块文件 / 包路径** | `snake_case` | `native_sys.py`、`io/file/path.py` |
| **一般类名**（含辅助类；**迭代器 / 视图**不作额外后缀要求；``@boxing`` 见 §1.0.2） | **PascalCase** | `ProcessTask`、`ListIterator`、`DictEntryUnsafe` |
| **内建容器类型类名** | 保持与 CPython 相同的**全小写**单名 | `list`、`dict`、`str`、`set`、`range`、`bytes`、`frozendict` |
| **枚举 / Flag 成员** | PascalCase（非 `SCREAMING`） | `AnsiColorEnum.Red`、`PermFlag.Read` |
| **`@union` 变体** | PascalCase（**不**要求带 `Union`） | `Result.Ok`、`Optional.Some` |
| **模块级常量** | PascalCase | `Pipe`、`DevNull`、`FOk` |
| **函数 / 方法 / `@property` / 参数 / 局部 / 实例字段** | **camelCase** | `splitLines`、`setDefault`、`isAbsolute`、`isAtty`、`returnCode`、`_minLevel`、`maxSplit` |
| **私有** | 允许前导 `_`，其后仍按上表 | `_inner`、`_state`、`_minLevel` |
| **dunder / 译器装饰器 / 生成名** | 不改 | `__init__`、`@native_name`、`value__get` |
| **哨兵类名** | 保留尾部下划线 | `None_`（勿写成 `None`） |
| **FFI ``Pyi…`` / C++ ``Py*`` 类型名** | 不改（见 [c-ffi-pyi.md](./c-ffi-pyi.md)） | `PyiSqlite3`、`pyiSqlite3Open`、`PyList` |
| **条件别名 / 捕获** | ``{Role}Of``；捕获 ``_V`` / ``_W`` / ``_K``（见 [type-conditional.md §3](./type-conditional.md#3-标准库范本别名与命名规范)） | `ListElemOf`、`_V` |
| **C 布局包装** | ``C`` + PascalCase | `CTime` |
| **例外：`str`/`bytes` 生成器扩展** | ``xsplit``/``xrsplit`` **全小写**；含 ``Lines`` 的用 camelCase | `xsplit`、`xrsplit`、`xsplitLines` |
| **例外：`r*`/`l*` 单前缀族** | **全小写**（与 CPython 拼写同形） | `rpartition`、`rsplit`、`rfind`、`rindex`、`rstrip`、`rjust`、`lstrip`、`ljust` |
| **例外：惯用整词** | 保留整词，不拆 camelCase | `strftime`、`strptime` |

粘连的 CPython 式全小写名也拆成 camelCase：``splitlines``→``splitLines``、``xsplitlines``→``xsplitLines``、``removeprefix``→``removePrefix``、``striplines``→``stripLines``、``setdefault``→``setDefault``、``isatty``→``isAtty``、``maxsplit``→``maxSplit``、``fillchar``→``fillChar``、``tabsize``→``tabSize``、``exist_ok``→``existOk``、``asctime``→``ascTime``、``gmtime``→``gmTime``、``localtime``→``localTime``、``mktime``→``mkTime``。勿把 ``xsplit``/``xrsplit`` 改成 ``xSplit``/``xRSplit``，勿把 ``rpartition``/``rsplit`` 等改成 ``rPartition``。

#### 1.0.2 特殊类型类名后缀（S47）

| 装饰器 / 角色 | 类名须以…结尾 | 示例 / 豁免 |
|---------------|---------------|-------------|
| ``@enum``（默认 / ``flag=False``） | **`Enum`** | `AnsiColorEnum`、`ModeEnum` |
| ``@enum(flag=True)`` | **`Flag`** | `PermFlag` |
| ``@enum.mro`` | **`TypeEnum`** | `PetKindTypeEnum` |
| ``@union`` | **`Union`** | `MessageUnion`、`JsonDocStepUnion`；**豁免** ``Result`` / ``Optional`` / ``IterResult`` |
| ``@union.mro`` | **`TypeUnion`** | `ExcTypeUnion`、`ErrorTypeUnion`；嵌套 ``Enum`` 类型名**保持** ``Enum``（不作 ``TypeEnum``） |
| ``@protocol`` | **`Type`** | `SizedType`、`EncoderType`、`IteratorType` |
| ``@boxing`` | **`Unsafe`** | `DictEntryUnsafe`、`DequeNodeUnsafe`、`CellUnsafe` |
| ``@annotation`` | **`Meta`** | `TagMeta`、`PosArgMeta` |
| ``@descriptor`` | **`Var`** | `RangeVar`、`LenRangeVar` |
| ``@mixin`` | **`Mixin`** | `TestCaseMixin`、`ArgumentParserMixin` |
| ``@delegate``（``def`` 名） | **`Delegate`** | `UIEventDelegate`、`UIValueChangedDelegate`、`FuncDelegate`；基类 ``Delegate`` 已符合；C++ 默认 ``Py…Delegate`` |
| **异常类** | **`Error`** | 自定义如 `EmptyError`、`ConsoleError`；**CPython 同名**（含 `Exception`、`StopIteration`、`ExceptionGroup`、`TypeError` 等）**一律豁免**；勿用 ``*Exception`` 作自定义后缀 |
| **枚举名简化** | 去掉后缀前冗余段 | `FlowPinKindEnum`→`FlowPinEnum`、`DrawCmdKindEnum`→`DrawCmdEnum` |

范本：``py2cpp/core/protocols.py``、``py2cpp/core/exceptions.py``、``test/lang/test_enum.py``、``test/lang/test_union_mro.py``。

### 1.1 翻译期强检查（``--strict``，默认开启）

``python main.py …`` 在语义分析之后、代码生成之前执行 **Phase 1** 规则（违规即 ``TranslationError``，可用 ``--no-strict`` 关闭）。**S01–S38** 按相似性分为 **A–F** 六组，编号连续；构造优先级为 **S06**，报错子码 **S06a–S06e** 区分场景。

#### A — API 与结构（S01–S03）

| 规则 | 检查内容 |
|------|----------|
| **S01** | 禁止直接调用 dunder；例外：全局 ``__cmp__(a, b)``、``__mod__``/``__truediv__``/``__floordiv__``（勿 ``x.__cmp__(y)`` / ``x.__truediv__(y)`` 等）；``iter``/``next``/``aiter``/``anext`` 等内建；``.__await__()``（协程/awaitable 基础设施）；``@copyable`` 类内 ``.__move__``；非 ``@copyable`` 类内 ``.__copy__``；**``__init__`` 内** ``super.__init__(...)`` / ``self.__init__(...)`` 参数转发；**仅**脱糖类 ``*_coroutine``/``*_generator`` 体内 ``.__aenter__``/``.__aexit__`` 另议（用户源码仍禁止） |
| **S02** | 勿用常见 C++ / STL 风格**方法名**定义（``def push_back`` 等）；**前导 `_` 不能规避**；见下表；``reserve``/``reshape``/``capacity``/``clear``/``insert`` 等运行时 API 豁免；**``Rect``** 另豁免 ``contains`` / ``size``（几何矩形 API，非容器 ``len``） |
| **S03** | 同文件全局函数或同类方法中**仅**转发形参到另一函数 → 删除薄封装、调用方直调；``@property``/dunder/``...`` 桩/无参转发不受限 |

#### B — 构造与字面量（S04–S07、S26）

| 规则 | 检查内容 |
|------|----------|
| **S04** | 空 ``list()`` / ``dict()`` 等 → 用 ``[]`` / ``{}`` |
| **S05** | 禁止 ``str("…")`` 造字面量 → 直接 ``'…'`` |
| **S06** | **赋值/默认参数/返回值/字段赋值**处：仅**单个** ``new()`` / ``new(...)`` / ``new.静态方法(...)`` / ``new.静态属性`` 可用 ``new``；嵌入表达式（二元运算、增强赋值、实参等）均不规范（见 §2.2、子码 S06a–S06e） |
| **S07** | ``id`` / ``init`` / ``destroy`` / ``free`` / ``freeArray`` 调用须省略 ``[T]``（C++ 模板实参推导） |
| **S26** | ``@dataclass`` 容器 / ``char[:]`` / ``byte[:]`` 字段带类体默认（``[]``/``{}``/``new()`` 等）须 ``T @optional = …``（容器不能作 C++ 构造形参默认）；**``@copyable`` 选项类**勿叠 ``@dataclass``，类体直接 ``dict[str, str] = {}`` 等，**不必** ``@optional``（见 S32） |
| **S32** | ``@dataclass`` 须至少一个**非** ``@optional`` 实例字段；禁止无字段或全部 ``@optional``——后者**去掉** ``@dataclass``，改用 ``@copyable`` + 类体 ``T = 默认``（如 ``RequestOptions``：``headers``/``params``/``data`` 默认值，``**kwargs`` 仍可用；勿 ``_pad`` 占位） |

**S06 子码**：

| 子码 | 场景 |
|------|------|
| **S06a** | 初始化/默认参数/返回值/字段赋值：字面量 > ``new`` > ``Self`` > ``Cls(...)``；宿主类 ``-> Self`` 仍用 ``[]``/``""`` 等；空 ``deque`` **禁止**无参 ``new()``（须 ``[]``，有界用 ``new(maxLen)``） |
| **S06b** | 注解 ``Self`` / ``-> Self``：无参 ``new()``、有参 ``new(...)``；非宿主类勿 ``Self()``/空 ``""``；返回/赋值注解已写明目标类（``*_iterator``、``*_view``、``PoolSlotLoc`` 等）时勿 ``Foo[T](…)`` → ``new(…)``；静态工厂/方法（如 ``JsonDocument[T].open``、``Matrix4.fromAxesOrigin``）须 ``new.open(...)`` / ``new.fromAxesOrigin(...)`` 勿 ``Cls[T].open(...)``/``Cls.open(...)``/``Self.方法(...)``；``@staticproperty`` 当赋值/返回注解为本类时须 ``new.zero``/``new.identity`` 勿 ``Self.zero``（``new`` 指该注解类型；注解为其它类型时写 ``Self.属性``，如 ``usage: str = Self.helpText``）；**赋值/返回注解处** ``@union`` 变体构造须 ``new.Variant(...)`` 勿 ``Union.Variant(...)``；**调用实参等嵌入处**须 ``Union.Variant(...)``（见 S06e，勿造注解临时变量绕开，见 S46）；``match @union`` 须 ``case new.Variant(...)`` 勿 ``case Union.Variant(...)`` |
| **S06c** | 增强赋值（``+=`` 等）：``out += Self(x)``，勿 ``+= new(...)`` / ``+= new.静态成员``（**非**赋值处单个 ``new`` 调用） |
| **S06d** | 二元表达式操作数：``Self(...)``、``Cls(...)``、``Cls.静态属性``（如 ``Vector3.right``），勿 ``new(...)`` / ``new.静态成员`` |
| **S06e** | 调用实参：字面量 / ``Cls(...)``，勿 ``new(...)``（**非**赋值处单个 ``new`` 调用） |
| **S40** | 赋值/返回注解已给出目标类型时：``cast(obj)`` 简写优先，勿 ``cast[T](obj)``（``T`` 与注解一致） |
| **S41** | 禁止同一类内 ``def kind(self): return self._kind`` / ``def isDone(self): return self._done`` / ``def getValue(self): return self._value`` 与 ``def setKind(self, v): self._kind = v`` / ``def setValue(self, v): self._value = v`` 成对的纯私有字段读写（方法体仅上述单句；getter 除 ``self`` 外无参，setter 除 ``self`` 外仅一个形参，勿 ``setValue(self, name, value)``；方法名按 §1.0.1 **camelCase**）；须 ``@property`` + ``@property.setter``（同名连续），或改为公有字段 ``kind: T`` |
| **S42** | 禁止 trivial ``@property`` …（略） |
| **S43** | 禁止类内 ``type Alias = TypeParam`` 简单转发（类形参已自动生成 ``using Alias = _Alias``）；须 ``class Foo[Alias]`` 并使用语义化形参名（短名见 **S48**） |
| **S44** | 禁止 ``T @final @optional`` 同字段；``@dataclass(frozen=True)`` 禁止 ``T @optional`` |
| **S45** | 禁止非 ``@dataclass`` 字段使用 ``@optional``（``@copyable`` 等类体直接 ``T = 默认``，见 S26/S32） |
| **S46** | 禁止仅为 ``new`` 造类型上下文的注解临时变量再立刻转发（勿 ``sp: T = new(...); self.f = sp`` / ``fn(sp)``）；有类型上下文时 ``self.f = new(...)``，调用实参等无法用 ``new`` 时 ``fn(Cls(...))`` / ``fn(Union.Variant(...))``（见 §2.2）；嵌套进 ``new`` 的实参、多处使用、类型形参临时变量豁免 |
| **S48** | 类 PEP 695 形参禁止 ``T`` / ``T1`` 等单字母（+数字）；须 ``Element`` / ``Key`` 等（见 §1.1 F） |

#### C — 表达式与控制流（S08–S13、S20–S25）

| 规则 | 检查内容 |
|------|----------|
| **S08** | ``len(s)==0`` 等 → ``not s`` / ``if s`` |
| **S09** | ``s[0:k]`` → ``s[:k]``（起始 0 省略） |
| **S10** | ``seq[len(seq) - k]`` → ``seq[-k]``（``k`` 为正整数字面量） |
| **S11** | 可写增强赋值时禁止 ``x = x op …`` → ``x op= …``（含 ``+=``、``@=`` 等） |
| **S12** | 索引计数 ``while`` → ``for i in range(…)``；豁免：条件含 ``and``/``or``、体内另有对索引变量的赋值或其它 ``+=``/``-=``、``while cur is not None`` 链表遍历等 |
| **S13** | 勿写 ``range(0, n)`` / ``range(0, n, 1)`` → ``range(n)``；``range(a, b, 1)`` → ``range(a, b)`` |
| **S38** | 同步生成器内禁止 ``for x in it: yield x``（无 ``else``、循环体仅该 ``yield``）→ ``yield from it``；``async def`` 异步生成器豁免；带 ``for`` ``else`` 或其它语句时不计 |
| **S20** | 同一 ``expr`` 在 **≥3** 个独立 ``if expr == …`` / ``if expr in …``（可接 ``and …``）或 ``if``–``elif`` 链上重复判别 → 改用 ``match`` / ``case``；**仅** ``==`` 右端为字面量 / 枚举成员 / ``ord('单字符')``，或 ``in`` 右端为字面量串/字节或字面量元素容器时计入；``async def`` 与含 ``yield``/``yield from`` 的生成器函数体豁免（脱糖状态机暂不与 ``match`` 混用） |
| **S21** | 同一 ``expr`` 的 ``expr == x or …``（**≥2** 个 ``==``）→ ``expr in {…}``；``expr != x and …``（**≥2** 个 ``!=``）→ ``expr not in {…}``；右端均为单字符字面量 / ``ord('单字符')`` 时提示 ``in "…"`` / ``not in "…"`` |
| **S22** | 注解为 ``char`` 的表达式勿与单字符字面量 ``==``/``!=``（如 ``ch == 'a'``）→ ``ch == ord('a')``；``case 'x':`` 模式与 ``case`` 分支体可写单字符字面量；``case … if …`` **guard** 须 ``ord``；``ch in "…"`` 不受限 |
| **S23** | 每个 ``match`` 须以通配 ``case _`` **收尾**，或 ``@enum``/``@union`` 已由无 guard 的穷尽 ``case`` 完全覆盖（可省略 ``case _``）；**最后一个** ``case _`` **禁止** ``if`` guard（``case _ if …`` 违规）；中间分支不可用 ``_`` 代替收尾；``@enum``：每个成员至少一条**无 guard** 的 ``case E.MEMBER``（``case E.A \| E.B`` 可合并）；``@union``：每个变体至少一条**无 guard** 的 ``case``；无字段变体用 ``case U.V:``；**有字段**变体：模式中**出现**的字段槽位须为名称绑定（``U.A()``、``U.A(x)``、``U.A(x, y)``、``U.A(x=x)`` 等，**只绑定部分字段**亦计入），字面量槽位（``U.A(x, 1)``、``U.A(x=1)``）不计入穷尽 |
| **S24** | ``@union`` **同一变体**的 ``case`` 须**连续排列**（不得与其它变体穿插）；同变体多条 ``case`` 须**从具体到抽象**（源序优先）；前序 **无 guard** 的宽模式（槽位为绑定/``_``）不得排在后序带字面量槽位的 ``case`` 之前（如 ``case U.A(x, _)`` 后不得再写 ``case U.A(0, y)``）；**暂不分析 guard**；``case U.A \| U.B`` 不计入单变体连续 |
| **S25** | ``Optional[T]``：**``match``** 勿写 ``case Optional.Some(...)`` / ``case Optional.None_:``，用 ``case None:``、内层字面量或 ``case v:``；**判空** 用 ``is None`` / ``is not None``，勿 ``== None`` / ``!= None``；**赋值/传参/返回** 勿写 ``Optional.Some(...)`` / ``Optional.None_()``，写 ``None`` 或内层值（译器按目标 ``PyOptional<T>`` 自动装箱） |
| **S36** | ``@noexcept``：写 ``-> T``（勿 ``-> Result[T,E]`` 除非调用方显式标注）；函数体勿手写 ``Result.Ok``/``Err``；``match`` 用 ``case new.Ok(v):`` / ``case new.Err(e):``；判成功/取值的用 ``r.ok`` / ``r.value``（``Err`` 时 ``value`` 抛 ``ValueError``）；``try`` 块内 ``raise`` 仍走 ``throw`` |
| **S34** | ``ord`` **仅**单字符 ``str`` 字面量（``ord('x')``）；勿 ``ord(c)`` / ``ord(s[i])`` → ``int(c)`` / ``char(s[i])`` |
| **S35** | 勿 ``n: int = c; return n`` 式仅作类型转换的注解临时变量（初始化后无其它赋值）；在用到处直接 ``int(c)`` / ``char(c)`` |

## 2. 构造与字面量

### 2.1 对照表

| 场景 | ✅ 推荐 | ❌ 避免 |
|------|---------|---------|
| 空字符串 | `""`、`return ""` | `str()`、`new("")` |
| 非空字符串（用户/测试） | `s: str = "hello"` | `str("hello")` |
| 空列表 | `x: list[T] = []` | `list[T]()`（无元素时） |
| 非空列表 | `x: list[T] = [a, b, c]`、`x: deque[T] = […]`、`fl: frozenlist[T] = […]`、`[a, *it, b]`、`[e for v in it]` | 字面量与**同注解**推导式共用容器（``list``/``deque`` 直 ``append``；``frozenlist`` 临时 ``list`` + ``initFromList``）；``*`` 按可迭代展开 |
| 嵌套列表 | `rows: list[list[int]] = []`、`m: list[list[int]] = [[], [1, 2]]`；内层 ``[o for o in range(n)]`` | 元素类型须可 ``append``（如 ``list[U]``、``PyInt``）；勿为回避嵌套拆成多段平行 ``list``（除非语义本身是多列） |
| 空双端队列 | `q: deque[T] = []` | `deque[T]()`、无参 ``new()``（无元素时） |
| 有界双端队列 | `q: deque[T] = new(maxLen)` | 仅 ``maxLen``；元素仍用 ``[]`` + ``append`` |
| 非空双端队列 | `q: deque[T] = [a, b, c]` | 手写多次 `append`（译器对 `[]` 逐元素 `append`） |
| 空字典 | `d: Self = {}` 或 `d: dict[K,V] = {}` | 仅 `dict()` 且无 `{}` 字面量时 |
| 非空字典 | `d: dict[K,V] = {1: 10}`、`c: Counter[K] = {…}`（计数默认 ``int`` 时可写 ``Counter[K]`` 省略 ``C``）、`{**other, k: v}`、`{k: v for k in keys}` | 注解目标须可无参构造 + ``__setitem__``（``MutableMappingType``，含 ``Counter``）；``Counter[str]`` → ``Counter<PyStr>``（默认 ``C`` 在类模板声明处 ``= PyInt``）；``update({…})`` 等 ``dict[K,V]`` 形参生成临时 ``PyDict``；**无** 无注解裸 ``{…}`` 表达式 |
| 空集合 | `s: set[T] = new()` | **`{}` 是 dict**；勿用于 set；**勿** ``set()`` |
| 非空集合 | `s: set[T] = {1, 2}`、`{x for x in src}` | 元素须 ``DictKeyType``；``out: Self = new()`` 用于 ``copy`` / 代数 |
| 不可变集合 | `fs: frozenset[T] = {1, 2}`、`fs: frozenset[T] = new()`（**仅空表**）、`frozenset(lst)` | 空 ``frozenset`` **无** ``{}`` 字面量，故空表用 ``new()``；非空 ``{…}`` 经临时 ``set`` + ``initFromSet`` |
| 不可变序列 | `fl: frozenlist[T] = []`、`fl: frozenlist[T] = [1, 2]`、`frozenlist(lst)` | 空表用 ``[]`` 勿 ``new()``/``frozenlist()``；非空字面量经临时 ``list`` + ``initFromList`` |
| 不可变映射 | `fd: frozendict[K,V] = {}`、`fd: frozendict[K,V] = {1: 10}`、`fd = new(d)`/`new(fd)` | 空表用 ``{}`` 勿 ``new()``/``frozendict()``；拷贝用 ``new``（S06b）；勿 ``frozendict(d)`` |

实现 ``append`` 的容器（``list``、``deque`` 等）可用 ``[…]`` 初始化；实现 ``__setitem__`` 的映射（``dict`` 等）可用 ``{…}`` 初始化；**单元素集合** ``{x}`` 与字典字面量由类型注解区分。概念约束见 ``protocols.AppendableType``、``protocols.MutableMappingType``、``protocols.DictKeyType``。

**不可变容器（``frozenset`` / ``frozenlist`` / ``frozendict``）**：与可变兄弟共享 ``Frozen*Mixin`` 核心；桶/序列逻辑用 ``_insertNew``（单前导 ``_`` → C++ ``protected``），**勿**对外暴露 ``add``/``append``/``insert_new``；``out: Self = Self()`` 等局部上的 ``out._insertNew`` 须在同类方法内。用户侧初始化优先 ``initFrom*`` 或字面量（译器生成临时可变容器），勿手写 ``_insertNew``。

**``dict`` 迭代器 / view 快照**（须在迭代中容忍原映射被改时）：``self._dct: dict[K, V] = dct.copy()``；**勿** ``dict()`` + ``__copy__``，**勿**直接读 ``dct._order``（用 ``len(dct)`` / ``len(self._dct)``）。``frozendict`` 不可变，view/迭代器可 ``self._dct = dct`` 按值持有。对照 ``ListIterator``：只保存 ``lst`` 引用，因 ``list`` 迭代语义不同。

**遍历键**：用户可见逻辑（``__str__``、``for k in d``）用 ``for k in other`` / ``for k in self``。**例外（仅 ``dict`` / ``frozendict`` 实现体）**：``copy`` / ``update`` / ``__copy__`` / ``_rehash`` / ``initFrom*`` 等须 ``for i in range(len(other._order)): k = other._order[i]``（**勿**经 ``__iter__``），因可变 ``dict`` 的 ``DictKeyIterator`` 构造会 ``dct.copy()``，与 ``update``→``__iter__`` 互递归导致栈溢出。跨类读 ``_order`` 时用 ``friends``：``class dict(friends=(frozendict, …))``（``frozendict`` 须在 ``dict`` 之前定义以供 ``import``）。``_orderRemove`` / ``popItem`` 的 ``self._order.pop()`` 等可保留。

| 元组值 | `(a, b)`、`return (before, sep, after)`、`divmod`、`%` 与 `makeTuple` | `PyTuple<…>(…)`；**禁止** ``x in (a,b,c)``、``(a,b,c)[i]``（译期报错） |
| 元组类型 | `(int, int)`、`(K, V)`、`(int,)`（**最外层**须括号简写，S16） | 最外层勿写 `tuple[T, U]`；内层如 `list[tuple[K, V]]` 可保留 `tuple[...]` |
| 小集合成员 | 标量/枚举：`x in {a, b, c}`；**码点**（``char``）：`c in "abc"`，单码点用 `c == 32`（勿 `c in {32}`） | 勿 ``x in (a,b,c)``；下标表用 ``list[…][i]`` |
| **注解 ``Self``** 新实例 | `out: Self = new()`（无参）、`buf: Self = new(buf)`（有参） | 无参勿 ``Self()``/``\"\"``/``b\"\"``；``scratch: list[T]`` 等**空** ``list``/``deque`` 用 ``[]`` |
| **用户类关键字构造** | `b: CopyableBox = new(w=10, h=20)` | `CopyableBox(10, 20)`、`new()` 无类型注解 |
| **`@copyable` 同类拷贝** | `b2: CopyableBox = b` | `CopyableBox(b)`、`b2.__copy__(b)`（测试与用户侧） |
| **异类**容器/数组 | `buf: char[:] = new(n)`、`buf: char[:] = ""` / `"Hi"`（空/已知字面量）、`buf: byte[:] = b""` / `b"..."`、`_buckets = new(self._capacity)` | 裸 `new(n)`（无注解）；空 ``char[:]``/``byte[:]`` 优先 ``""``/``b""``，勿 ``[]``；预扩用 ``x.capacity = n`` 勿 ``reserve`` |
| 堆节点（如 `DictEntryUnsafe`） | 无参 ``node: DictEntryUnsafe[K,V] = new()``；有参 ``DictEntryUnsafe[K,V](k, v, head)``；桶数组 ``DictEntryUnsafe[K,V][:]`` | ``Pointer[DictEntryUnsafe[…]]``（``@boxing`` 注解已含指针语义） |

### 2.2 `new` 与 `Self`

```python
# list.py — 空列表用 []（sort 归并缓冲、copy、__add__ 等）
scratch: list[T] = []

# list.py — 底层数组
self._data: T[:] = new(0)

# str.py — 码点缓冲区（由注解推断 PyArray<PyChar>）
buf: char[:] = new(n)
buf: char[:] = ""       # 空堆数组优先 ``""``（勿 ``[]``）
buf: char[:] = "Hi"     # 已知字面量；栈定长 char[:N] 同理（长度须一致）
buf: byte[:] = b""      # 空堆字节数组优先 ``b""``
buf: byte[:] = b"\x00"  # 已知字节字面量
buf: char[:] = [72, 105]  # 一维堆数组 ``T[:]`` 亦可用列表字面量（码点/元素须可静态求值）

# dict.py — 桶数组扩容
self._buckets = new(self._capacity)

# serde/json.py — 类体成员默认（非 @dataclass 的 [] 默认）
_buf: char[:] = ""       # 空堆 ``char[:]`` 优先 ``""``（勿 ``[]`` / ``new(0)``）

# test/lang/test_dataclass.py — @copyable + @dataclass：关键字构造与拷贝
b: CopyableBox = new(w=10, h=20)
b2: CopyableBox = b
```

规则（与 `__init__.py` 中 `new` 文档一致）：

- **``new`` 仅用于赋值处单个调用**：带类型注解的赋值、``return``、默认参数、字段默认值等处，**仅**整表达式为单个 ``new()`` / ``new(...)`` / ``new.静态方法(...)`` / ``new.静态属性`` 时可用 ``new``；二元运算、增强赋值、调用实参等**嵌入表达式**均不规范（S06c–S06e），须 ``Self(...)``、显式 ``Cls(...)`` 或 ``Cls.静态成员``。
- **同场景优先级**（上述允许 ``new`` 的赋值处）：**str/bytes 字面量**（``""`` / ``b""`` 等）> **其它容器字面量**（``[]`` / ``{}`` 等）> **`new(...)`**（**仅**空 ``set``/``frozenset``、拷贝 ``new(src)``、``deque`` 的 ``new(maxLen)``、迭代器/view、用户类等字面量无法表达的场景）> **`Self()`** > 传参时的 **`Cls(...)`**。空 ``frozendict``/``dict``/``frozenlist``/``list``/``deque`` **须**字面量（``deque`` 有界除外：``new(maxLen)``），**勿**无参 ``new()``。S06（子码 S06a–S06e）在变量初始化/默认参数/返回值及 **``self._f`` / ``other._f``**（``other: Self`` 等）字段赋值检查该顺序；传参禁止 ``new(...)`。
- **`new(...)` 必须有类型上下文**：`x: T = new(...)` 或 `-> T` 的 `return new(...)`；**类体字段** ``name: T = new(...)`` 亦同（左侧字段注解提供 ``T``，生成成员初值，见 [参考手册 §5.5 / §7.6](../docs/参考手册.md#76-静态类成员与字段默认值)）。**实例字段赋值** ``self._f = new(...)`` / ``other._f = new(...)``（``other: Self`` 等）由接收者字段类型推断，**勿**写 ``tmp: T = new(...); self._f = tmp`` 迂回（**S46**）；调用实参等无法用 ``new`` 时对目标直接 ``fn(Cls(...))`` / ``fn(Union.Variant(...))``（勿 ``c: U = new.V(...); fn(c)``）。同路径支持空字面量 ``other._adj = []`` / ``{}`` / ``""`` / ``b""`` / ``set()``：按字段注解生成 ``PyList<…>()`` 等，**勿**误推 ``list[int]``。
- **禁止 ``new(类型/类名)``**：任意上下文不得把类型或类名当实参（如 ``new(list[int])``、``new(Box)``）；类型仅由左侧/返回注解提供。合法实参为无参、容量 ``new(n)``、用户类关键字 ``new(field=v)``、运行时值（如 ``new(self)``）。
- **注解为 ``Self``**（PEP 695，非具体 ``str``/``bytes``/``list[…]`` 等）：无参空实例 → **`new()``**，勿 ``Self()``（S06b；``StringMixin``、``_sub`` 空返回等）；**有参** → **`new(...)`**，勿 ``Self(...)``。**宿主类**（``str``、``bytes``、``list``、``deque``、``dict``、``array``/``array2d``/``array3d``、``frozenlist``、``frozendict``、``Counter``、``set``、``frozenset`` 等具体实现类，非泛型 mixin）：``-> Self`` 仍用类型对应的**字面量**（``\"\"``/``b\"\"``/``[]``/``{}``/非空 ``{…}``；空 ``set``/``frozenset`` 仍 ``new()``，空 ``frozendict``/``dict``/``frozenlist`` 用 ``{}``/``[]`` **勿** ``new()``）、**列表/集合/字典推导式**、``[*seq, …]`` 等解包显示，**勿**因 ``Self`` 改 ``new()``/``Self()``。**嵌入表达式**（增强赋值、二元运算、实参等，见上条）：须 ``Self(...)`` / ``Cls(...)`` / ``Cls.静态成员``，勿 ``new(...)`` / ``new.静态成员``。**注解为具体容器类型**时仍用 ``[]``/``{}`` 等字面量，勿 ``Self()``。**空** ``list[T]`` / ``deque[T]`` 局部变量用 ``[]``，勿 ``Self()`` / ``new()``（``__add__``、``_repeated`` 等）。
- **协议与泛型形参**（详见 [参考手册 §5.3.1](./参考手册.md#531-缺少注解时的-c-类型策略)）：``x: ComparableType`` / ``def f[T: Bound](…)`` → ``T``/``T0`` + ``*_requires``，**不是** ``void*``；PEP 695 头**不**绑定无注解形参；普通无注解形参 → ``T0``、``T1``…。**返回**：有 ``return expr`` → ``auto`` + ``decltype``；无 ``return expr`` → ``void``（模板 / 普通同，``-> None`` 可选）；**勿**写 ``def fn[T0](…)``。隐式 void dunder 见 §1。
- **泛型类型条件（Py2Cpp 扩展）**：PEP 695 函数/方法体内**至多一条**对 ``T`` 的类型 ``if/elif/else`` 链（可写在 ``for`` 等普通块内，见 [参考手册 §5.2](./参考手册.md#52-泛型pep-695)）→ 整函数剪枝进 ``_pick`` 的 ``static __call__``；**暂不支持**同一函数多条平行链或链套链（未来可能支持）。支持 ``T is not int``、``T not in {…}``、``T is list[...]`` / ``dict[K, ...]`` 等容器模式（``...`` 仅用于类型判断，分支内取元素类型用 ``T.Element``）；**禁止** ``list[_]`` / ``dict[K, _]`` 等下划线通配；须写 ``T is not int`` / ``T not in``；无 ``else`` 则 ``static_assert``。范本：``test/lang/test_type_if.py``。
- **用户类关键字构造**（含 ``@dataclass``、``@copyable`` 选项类）：``obj: Cls = new(field=v, …)`` → ``Cls()`` + 字段赋值；与 §7.4 的 ``Window(w=1)`` 展开一致。
- **`@copyable` 值拷贝**（``str``、``@dataclass`` 选项类等）：``dst: T = src`` → C++ 拷贝构造。
- **标准库容器**（``list``/``dict``/``set``/``frozenset``/``deque``，**无** ``@copyable``）：``dst: T = src`` → **移动**（``__move__``）；``src`` 变空且 ``__moved__=True``。含 ``__move__`` 的类由译器自动注入 ``__moved__`` 字段并在 ``__init__``/``__copy__``/``__move__`` 中维护其赋值（``passes/move_state.py``）；**勿**手写 ``self.__moved__``/``other.__moved__`` 的 ``True``/``False`` 赋值（可读 ``.__moved__`` 做守卫）。除 ``src.__moved__`` 与对 ``src`` 的重新赋值外，**翻译期**会拒绝后续使用（``passes/moved_use_check.py``）；运行期 ``_ensureActive`` 仍抛 ``ValueError``。显式副本用 ``dst = src.copy()``。
- **`str` 空串**一律字面量 `""`，与 `new` 无关。

**泛型/未注解形参上的成员访问**：若无法在译期绑定接收者类型，``node.parent`` / ``node.method()`` 等生成 ``PY2CPP_GETATTR`` / ``PY2CPP_CALL``（见 [参考手册 §7.8](../docs/参考手册.md#78-编译期成员派发py2cpp_getattr--py2cpp_setattr--py2cpp_call)）；宏内 SFINAE 自动选 ``.`` 或 ``->``。业务 API 优先写注解形参或 ``self``，避免无谓依赖宏派发。

### 2.3 切片

- 对外 API：`s[start:stop:step]`、`lst[i:j:k]`（翻译为 `__getitem__(slice[...])`）。
- **起始下标为 0 时省略**：`s[:k]`、`path[:dotIndex]`，勿写 `s[0:k]`（与 [§5.1](#51-数组与-new) 栈子区间 ``T[:N]`` 一致；语义等价）。
- **取末元素用负索引**：`seq[-1]`，勿写 `seq[len(seq) - 1]`（swap-and-pop 等取最后一项同理用 `[-1]`；``range`` 上界、``i < n - 1`` 等边界比较仍用 ``n - 1``）。
- 复杂切片逻辑可抽到类内 `_str_getslice`（`str.py`），`__getitem__(slice)` 只委托一行。

## 3. 运算符与 dunder：不要直接调用

### 3.1 业务代码中的映射

| 意图 | ✅ 推荐 | ❌ 不要写 |
|------|---------|-----------|
| 下标读 | `self[i]`、`other[k]` | `self.__getitem__(i)` |
| 下标写 | `self[i] = v` | `self.__setitem__(i, v)` |
| 下标删 | `del self[i]`、`del xs[a:b]`（``list``/``dict`` 等已实现 ``__delitem__``） | `self.__delitem__(i)`（标准库内 ``pop``/``_eraseKey`` 可继续用私有 API） |
| 成员检测 | `key in self`、`x not in other` | `self.__contains__(key)`（生成 `::__contains__(container, item)`） |
| 哈希 | `hash(k)` | `k.__hash__()` |
| 长度 | `len(self)`、`len(self._data)`（类内） | `self.__len__()` |
| 布尔 | `if self:`、`if s:`、`if not s:`、`assertTrue(f)`、`assertFalse(sio)` | `self.__bool__()`、`f.__bool__()`；空串/空容器用 ``not x`` / ``if x``，勿 ``len(x)==0`` / ``len(x)>0`` |
| 迭代 | `for x in self:`、`for k in other:` | `other.__iter__()` |
| 生成器步进 | `next(g)`（``from py2cpp import next``） | `g.__next__()` |
| 反向迭代 | `reversed(self)`（若实现 `__reversed__`） | 手写反向索引循环（除非性能关键且已封装） |
| 拼接 | `a + b`、`out = out + self` | `a.__add__(b)` |
| 增强赋值 | `self._size += 1` | `self._size = self._size + 1`（标准库内也避免） |
| 并行多目标 | `a, b = b, a + 1`、`xs[i], xs[j] = xs[j], xs[i]` | 右值先求值到临时变量再赋值；勿手写 ``tmp`` 三行交换 |
| 比较 | `a < b`、`a == b`；**身份** ``a is b`` / ``a is not b``（对象地址，非 ``==``）；类 ``__cmp__`` 体内字段比较用 ``__cmp__(a, b)``；多字段可 ``return __cmp__(a, b) or __cmp__(c, d)`` | 用户代码 ``a < b``、``a is b``；类协议 ``__cmp__(other)``；字段三值比较用全局 ``__cmp__``（标量三目 / ``a.__cmp__(b)``）；``0`` 为假、非零短路，``or`` 链等价逐段 ``if c: return c`` |
| 字符串化 | `str(x)`、`repr(k)`、`format(x, spec)` | `repr` → `::repr`；`format` → `::format` → `__format__` |
| ``%`` | `"%d" % x` → `::__mod__(fmt, makeTuple(x))`；`"%d %d" % (a, b)` → `makeTuple(a, b)` | `PyStr::percent_format` 直调（已废弃） |
| ``/`` / ``//``（标量） | `a / b`、`a // b` | 裸 C `/`（`int` 真除应走 `::__truediv__`） |
| `print` | `print(a)` → `str(a)` 再 **`printf`**（默认 stdout）；`print(f"{x}")` 实参走 `PyStr::format`；**禁止** `std::cout` / `ostringstream` |
| 删除键（映射） | `del d[k]`（用户/测试） | 标准库 ``pop``/``discard`` 内部可继续 ``_eraseKey`` |

`dict.py` 中 `get` / `setDefault` / `__cmp__` 使用 `key in self`，**测试代码**同样用 `in`，不调用 `d.__contains__(...)`。

### 3.2 dunder 何时写、何时不调用

| 类别 | 做法 |
|------|------|
| **必须实现** | 翻译器/运算符映射依赖的协议：`__init__`、`__len__`、`__getitem__`、`__setitem__`、`__iter__`、`__next__`、`__contains__`、`__cmp__`、`__copy__`、`__str__`/`__repr__`（容器）等。 |
| **无返回注解** | 隐式 void dunder（§1）不写 ``-> None``。其它 void 方法（含 ``def replaceAt(self, steps, value):``）自动 ``void``，不必 ``-> None``。有 ``return expr`` 的模板方法可省略 ``-> T``（``decltype``，见参考手册 §5.3.1 **4）**）。 |
| **`@protocol` 类** | 实例成员仅 `...` 声明；**静态虚契约**（仅协议）：``@staticmethod`` + ``@abstract``（体 ``...``）或 ``@virtual``（可有默认体）；返回/参数用 ``Self``，勿写 ``IParsableType[TSelf]`` 式自引用泛型头；用于 `def f[T: IteratorType]` 等约束，见 [参考手册 8.5](./参考手册.md#85-protocol-与-sfinae-约束)。 |
| **实现体内部** | 容器子字段移动写 ``self.xs = other.xs``（译成 ``operator=`` → ``__move__``），**勿** ``self.xs.__move__(other.xs)``（``array``/``char[:]`` 等无对等赋值时仍可用 ``.__copy__``/``.__move__``，见 §2.2）。**S01**（§1.1）：除全局 ``__cmp__``、``__init__`` 内 ``super.__init__``/``self.__init__`` 转发及 copyable/__copy__/__move__、脱糖协议 dunder 豁免外禁止直接 dunder 调用。 |
| **本类业务逻辑** | 通过运算符与 `len`/`in` 间接使用协议，避免 `self.__xxx__()`。 |
| **C++ ``operator``** | 类内实现 ``__add__`` / ``__mul__`` / ``__eq__`` 等且存在对应 C++ 运算符时，译器在 `.h` **自动生成** ``operator+``、``operator==`` 等（委托 dunder）；``@immutable`` 方法生成 ``const`` 重载。``__mod__``、模板 dunder、已有 ``__cmp__`` 时的六个比较运算符除外。 |
| **默认 ``__ne__``** | 已实现 ``__eq__``、未手写 ``__ne__`` 时，``expand_default_ne`` 注入 ``return not (self == other)``（``@immutable``，``other`` 注解与 ``__eq__`` 一致）；**勿**再手写相同逻辑。手写 ``__ne__`` 时仍用 ``not (self == other)``，勿 ``self != other``（避免递归）。 |

## 4. 装饰器与类设计

### 4.1 类级

```python
class VaultReader:
  def read(self, v: Vault) -> int:
    return v._code

class Vault(friends=(VaultReader,)):
  """友元 ``VaultReader`` 可访问本类 ``_code`` 等 protected/private。"""
  def __init__(self):
    self._code: int = 0
```

- **`friends=(A, …)`**（类头 **keyword**，非基类）：在**被访问的类**上声明；**友元** ``A`` 为**类名**（勿写字符串）。译器在同模块内**前向绑定**友元类（``class Host(friends=(Later,))`` 与 ``class Later`` 先后顺序无关）。若该 ``.py`` 还需被 CPython ``import``，友元类须在宿主类执行前已存在（通常写在宿主之前，如 ``py2cpp/util/dict.py`` 中 ``frozendict`` 在 ``dict`` 之前）。跨类访问 ``_member`` 时，译器报错会提示 ``class Host(friends=(Accessor, …))``，**勿**改成无下划线公开名。生成物为类体顶部的 ``friend class …;``（范本：``test/lang/test_friends.py``）。

**标准库封装（``py2cpp/<域>/``）**：用户可见 API 与 CPython 对齐；内部字段/钩子不当作公开契约（域布局见 [参考手册 §2](./参考手册.md#2-架构与目录)）。

| 类型 | 保持 public（译器/字面量需要） | protected + ``friends`` |
|------|------------------------------|-------------------------|
| ``set`` / ``frozenset`` | ``add``、``initFrom*``、运算符 | ``_capacity``、``_buckets``、``_insertNew``；迭代器友元 ``SetIterator`` / ``FrozenSetIterator`` |
| ``dict`` / ``frozendict`` | ``initFrom*`` | ``_order``、``_buckets``；``dict_*`` / ``frozendict_*`` 迭代器与 view 友元；``class dict(friends=(frozendict, …))``（``frozendict`` 须在 ``dict`` 之前定义以供 import，见上行遍历键例外） |
| ``list`` / ``frozenlist`` | 常规方法 | ``_data``、``_insertNew``（mixin）；迭代器走 ``__getitem__``，无需友元读桶表 |

``dict`` / ``set`` 桶数用字段 ``_capacity`` + ``@property capacity``（可变类带 setter）；``_buckets`` 为私有桶表，跨类访问靠 ``friends``。仅收紧**插入序**与集合**桶表**插入 API 的可见性。

```python
@copyable
class list[T]:
  ...

@boxing
class DictEntryUnsafe[K, V]:
  ...
```

- **`@copyable`**：值语义类型（`str`、`list`、`dict`）。生成拷贝构造与 `operator=`。测试与用户侧拷贝写 **`dst = src`**（见 §2.1），类内实现深/浅拷贝仍写 **`__copy__(self, other)`**（见 §5.3）。
- **`@boxing`**：无引用计数的**堆上单对象**（哈希/链表节点）。注解 ``Node[T]`` 译成 ``Node<T>*``（**勿**再包 ``Pointer[Node[T]]``）；``list[Cell]`` 等对 ``@boxing`` 类模板实参译为 ``Cell*``（``T: boxing`` 仅 ``static_assert`` 校验，C++ 形参仍为 ``T``、实例化后为 ``U*``）；无参 ``node: Node[T] = new()`` → ``new Node<T>()``；有参 ``Node(...)(...)`` → ``new Node<...>(...)``；桶数组 ``Node[K,V][:]`` 元素同为指针。释放用 ``destroy`` + ``free``。与 ``@refcount``、``@copyable`` 互斥。
- 需要**共享所有权**的堆对象用 **`@refcount`**；多播回调用 **`@delegate`**。不要给节点类误标 `@copyable`。
- **`@union` / `@variant`**（``from py2cpp import union, variant``）：Rust 式 ADT。类上 ``@union``（**隐式** ``@copyable``，勿重复标注）；变体为嵌套 ``@variant class``（字段语义序）；支持 ``class Box[T]:`` 泛型参数。C++：嵌套 ``Box_Tag`` / ``Box_Payload_*`` / ``union Box_Storage`` + ``_tag`` + ``alignas`` 字节缓冲 ``_storage``（经 ``_stor()`` 访问）；``placement new`` / ``_destroy()``。构造**仅** ``MessageUnion.Move(x, y)`` / ``Value[int].Int(v)``；**禁止** ``MessageUnion(...)``。``match`` 支持 ``case A(x) | B(x):``（**各分支绑定名须一致**）；穷尽性同 Rust。默认 ``__repr__``/``__str__``：``MessageUnion.Move(x=1, y=2)``、无字段 ``MessageUnion.Quit``（省略括号）；字段值经 ``::repr``。判别 lowering：``_match_tag()`` / ``_payload_Move()``。**单继承**：``@union class Child(Parent)`` 合并父变体（子 union 内变体名可与其它 union 重名，C++ 以 ``Child_Payload_*`` 区分）；``@variant class V(Mixin)`` 合并模块级 ``@variant`` 字段模板（仅字段、不可 ``Mixin()`` 构造，基类字段在前）；泛型 ``class Box[T](CoreUnion[T])`` 须形参一致。``match``/带注解赋值构造可用基类名（``CoreUnion.Quit``），生成 C++ 时优先子类（``ExtendedUnion::Quit``）。范本：``test/lang/test_union.py``。
- **`@enum`**（``from py2cpp import enum, int64``）：整型 ``enum class``。成员写 ``name = 整型常量`` 或 ``name = ...``（普通枚举：在已有成员序列末值 **+1**，首项不能为 ``...``）；``@enum(flag=True)`` 时 ``...`` 对齐 CPython ``enum.Flag``：无成员时 **1**，否则取当前成员**最大值**的下一个 **2 的整数次幂**（如 1→2→4→8）。**默认底层** ``int``（``PyInt``），可写 ``class E(int64):`` 指定 ``PyInt64``。**单继承**：``class Child(Parent):`` 合并父枚举成员后再追加子成员；父为 ``flag`` 时子类自动沿用 Flag 顺延规则。访问 ``E.member`` → ``E::member``；同枚举类型可 ``==`` / ``!=``（**勿**与另一 ``@enum`` 或裸 ``int`` 混比，用 ``int(E.MEM)`` / ``E(n)`` 显式转换）。**整型互转**：``int(E.MEM)`` → ``{E}PyInt`` / ``{E}PyInt64`` 包装 + ``operator PyInt()`` / ``operator PyInt64()``；``E(n)`` → ``static_cast<E>(static_cast<底层>(n))``。**Flag**：``|`` / ``&`` / ``^`` / ``|=`` / ``~``（与 CPython 3.13 一致，生成 ``enum class`` 运算符或底层位运算）。**表示**（对齐 CPython 3.13）：``str(E.MEM)`` → ``"E.MEM"``；``repr(E.MEM)`` → ``"<E.MEM: v>"``；组合 Flag ``str``/``repr`` → ``"E.A|E.B"`` / ``"<E.A|E.B: v>"``（模块命名空间内全局 ``str(E)`` / ``repr(E)``，与 ``str()`` / ``repr()`` 一致）。**``match``**：``case E.MEM:`` 为精确相等；``case E.A | E.B:`` 在语法上为 ``MatchOr``，**仅** ``== A || == B``（**不**表示 Flag 位组合；位组合值请用 ``guard`` 或表达式比较）。**遍历**：``len(E)`` → 成员个数；``for m in E:`` 按声明序（含单继承合并）内联为成员表 + 索引 ``for``，**勿**手写 ``ALL_*`` 列表除非需复用。范本：``test/lang/test_enum.py``；译器详规见 [参考手册 §8.2.2](./参考手册.md#822-enum)。
- **``@ref``**（``from py2cpp import ref``；类型注解 ``T @ref``，**非**装饰器）：需要 C++ 可变引用时使用——形参 ``def f(x: Foo @ref)``、返回值 ``def __getitem__(...) -> T @ref``、局部 ``p: Position @ref = table[e]``。译器生成 ``T&``；**勿**依赖对特定方法名的隐式推断。只读传参仍用未标 ``@ref`` 的容器/用户类（常为 ``const T&``）。范本：``py2cpp/design/ecs.py``（``ECSComponentTable`` / ``ECSWorldMixin``）、``test/design/test_ecs.py``（演示 World）、``test/lang/test_ref_annotation.py``。多组件交集遍历写 ``for e in pos & vel:``（``ECSComponentTable.__and__`` → ``ECSComponentTableQuery``），勿在系统里手写 ``for e in pos: if e not in vel: continue``。迭代器 ``__iter__`` 返回 ``Self``；宿主表 ``__iter__`` / ``__and__`` 用 ``return new(self)``、``return new(self, other)``（返回类型注解提供 ``new`` 目标类），勿写 ``Foo[T](self)``。
- **`@dataclass`**（``from py2cpp import dataclass, optional, const, ref``）：从类体 ``name: T [= 默认]`` 生成 ``__init__`` / ``__eq__`` / ``__repr__``；``order=True`` 时另生成 ``__cmp__``（字典序，委托 C++ 六个比较运算符）；未写 ``eq`` 时默认 ``eq=False``（仅排序、不生成 ``__eq__``），需相等性时显式 ``eq=True``。可与 ``@copyable``、``@refcount``、``@boxing`` **叠用**（预处理最先 ``expand_dataclass``）。**勿用**已移除的 ``field()``；默认值**直接写表达式**（``y: int = 0``；``new(...)`` 且注解为非容器用户类如 ``style: UIStyle = new()`` / ``new(fontSize=11)`` 进 ``__init__`` 形参默认）。容器 / ``char[:]`` / ``byte[:]`` 带默认须 ``tags: list[str] @optional = []``（**S26**；在 ``__init__`` 体内初始化，勿作 C++ 引用形参默认）。``name: T @optional = v`` 不参与 ``__init__`` 形参，``new(kw=…)`` / ``assign`` 关键字仍可赋值；**S32** 要求至少保留一个非 ``@optional`` 实例字段（禁止空类；**全部** ``@optional`` 时优先去掉 ``@dataclass``，类体默认即可）。``order=True`` 时亦**不参与** ``__cmp__``（如 ``CTime`` 的 ``tmWday`` / ``tmIsdst``）。类级 ``static const`` 用 ``name: T @const = v``（``from py2cpp import const``）。类体只读字段 ``name: T @property = v`` → ``name__get()``（存储 ``name__value``；标记用内建 ``property``）。可定义 ``def __post_init__(self):``：在**自动生成**的 ``__init__`` 末尾调用 ``self.__post_init__()``（与 CPython dataclasses 相同）；若手写 ``__init__`` 须自行调用。关键字构造推荐 ``new``（§2.2）。尚未支持：``frozen``、``kwOnly``、``slots``。范本：``test/lang/test_dataclass.py``、``py2cpp/system/time.py`` 的 ``struct_time``。

### 4.1.1 翻译期默认协议（``expand_default_bool`` / ``expand_default_iter``）

在 ``expand_dataclass`` 之后、``expand_descriptors`` 之前自动注入（仅**用户模块**类；跳过标准库、`@protocol`/`@mixin`/`@descriptor`/`@refcount`/`@boxing` 等）。

| Pass | 条件 | 生成 |
|------|------|------|
| **`expand_default_bool`** | 无手写 ``__bool__`` | 无 ``@immutable`` 的 ``__len__`` → ``return True``；有 ``@immutable`` 的 ``__len__`` → ``return self.__len__() > 0``；并生成 ``explicit operator PyBool() const``（跳过 ``@union`` / ``@enum``） |
| **`expand_default_iter`** | 有 ``__getitem__(int, …)``（非仅 ``slice[...]``）、有 ``@immutable`` 的 ``__len__``、无 ``__iter__`` | ``{Class}_iterator``（逻辑同 ``ListIterator``）+ ``def __iter__(self) -> {Class}_iterator[…]: return new(self)`` |

**真值与 ``and``/``or``**：除拷贝/移动构造外，用户类 C++ 声明一律 ``explicit``；``__bool__`` / ``__int__`` 等对应 ``explicit operator Py*() const``。``if x`` / ``while`` / ``and``/``or`` 对实现了 ``__bool__`` 的对象用 ``static_cast<PyBool>(obj)``（**勿** ``obj.__bool__()``）；``PyRefCount<T>`` 用 ``(rc)``；``@boxing`` 的 ``T*`` 用 ``(ptr != nullptr)``。``and``/``or`` 仍按 CPython **短路并返回操作数对象**（三目链，见 [参考手册 §6.5](./参考手册.md#65-表达式与运算符)）。

范本：``test/util/test_list.py`` 中 ``ThreeInts`` / ``EmptySeq``（``DefaultSeqIterTests``）。

### 4.1.2 反射相关类命名（``Meta`` / ``Var`` / ``Mixin``）

完整标识符与特殊类型后缀见 **[§1.0](#10-标识符命名强制)**（含 ``@enum`` / ``@union`` / ``@protocol`` / 异常，**S47**）。本节仅补充反射范本：

| 装饰器 | 类名后缀 | 示例 |
|--------|----------|------|
| ``@annotation`` | **`Meta`** | ``@annotation(inheritable=True) class TagMeta``；``Self.iterFields[TagMeta](mro=True)`` 合并实体基类字段（须 ``inheritable``）；``repeatable=False``（默认）时同一目标不得重复同一注解类 |
| ``@descriptor`` | **`Var`** | ``RangeVar``、``LenRangeVar``（``py2cpp/util/vars.py``）；宿主 ``level: int @RangeVar(0, 10) = 0``；泛型 ``RangeVar[T: ComparableType]`` 等，左侧类型即 ``T`` |
| ``@mixin`` | **`Mixin`** | ``ECSWorldMixin``、``TestCaseMixin``、``UIPanelMixin``（``py2cpp/ui/panel.py``） |

- Panel：… ``showPanel(title="", width=-1, height=-1)`` 一行打开 Win32 窗口（``-1`` 按 ``win.style`` 与已布局控件自适应客户区；``title`` 空串 → ``Self.__name__`` 写入 ``win.title``）；分步用 ``win = obj.createPanel(…)`` 或 ``new()`` / ``win.title`` / ``begin`` / ``drawPanel`` / ``resize`` / ``run``。范本 ``test/ui/test_panel.py``、``examples/ui_panel_demo.py``。

### 4.2 方法级

```python
@immutable
def index(self, value: T, start: int = 0, end: int = int.Min) -> int:
  ...
```

| 装饰器 | 用途（范本） |
|--------|----------------|
| `@immutable` | 只读查询：`__len__`、`count`、`index`、`copy`、`__cmp__`、`_normIndex` |
| `@overload` | 多签名：`__getitem__(int)` vs `__getitem__(slice)`、`str.__init__` 多构造 |
| `@staticmethod` | `dict.fromKeys` 等工厂 |
| `@virtual` / `@override` / `@abstract` | 继承体系（`object.py`、用户扩展类）；``@abstract`` 体须 ``...``，勿与 ``@virtual`` 等同标（**S39**） |
| ``super`` / ``Super`` / ``Proxy[T]`` | ``super()`` ≡ ``super.__call__()``（任何上下文），要求 ``__base__`` 定义 ``__call__``；构造基类写 ``super.__init__(...)``，禁止 ``super().__init__`` |

同一组 `@overload` 方法须**全部标注**；仅区分签名的存根用 `pass` 体（仍会生成 C++ 定义，函数体为空 `{}`）；含语句的重载正常译为该签名的完整实现。详见 [参考手册 §8.4](./参考手册.md#84-overload)。

### 4.3 类体内成员顺序

仅约束 **Python 源文件**书写顺序（`py2cpp/`、`test/`、用户模块）；**不**规定 C++ `.h`/`.inl` 发射顺序。译器按 AST 收集成员，重排源文件**不改变**语义。

**同一 Tier 内成员须连续**；不得跨 Tier 穿插。

#### 4.3.1 十二个 Tier（自上而下）

| Tier | 内容 |
|------|------|
| **T0** | 类 docstring（若有）；类体 ``type Alias = …``（按依赖或字母序） |
| **T1** | 类级常量 ``name: T @const = …``（含 ``_testTag``） |
| **T2** | 实例字段 ``name: T`` / ``name: T = …`` / ``@optional``；**语义序**（如 ``CTime`` 的 ``tmYear``→…→``tmIsdst``、``_YMD`` 的 ``year,month,day``），**勿**按字段名字母序 |
| **T3** | **全部** ``@staticmethod`` / ``@classmethod``（含工厂与 ``_`` 前缀辅助）；组内：**非** ``_`` 名在前，``_`` 在后，各组字母序 |
| **T4** | 生命周期：``__new__`` → ``__init__``\* → ``__post_init__`` → ``__del__`` → ``__copy__`` → ``__move__`` → ``__enter__``/``__exit__``/``__aenter__``/``__aexit__`` |
| **T5** | 表示：``__str__`` → ``__repr__`` → ``__format__`` → ``__bool__`` → ``__bytes__`` |
| **T6** | 比较/哈希：``__cmp__`` → ``__eq__``/``__ne__`` → ``__lt__``…``__ge__`` → ``__hash__`` |
| **T7** | 容器：``__len__`` → ``__getitem__``\* → ``__setitem__``\* → ``__delitem__``\* → ``__contains__`` |
| **T8** | 迭代：``__iter__`` → ``__next__`` → ``__reversed__`` |
| **T9** | ``@property`` / ``@property.setter``（同名连续：getter 再 setter）；全部实例 property 后再全部 ``@staticproperty`` / ``@staticproperty.setter``，组内字母序 |
| **T10** | 算术/位 dunder（``__add__``→``__radd__``→``__iadd__``，再 ``__sub__``…``__imod__``，再移位/位，再一元；有 ``__cmp__`` 时勿重复六个比较 dunder） |
| **T11** | 公开实例方法（非 ``_`` 前缀、非 dunder） |
| **T12** | 私有实例方法（``def _…``） |

\* 同名 ``@overload`` 变体**连续**占该 Tier 的一个槽位，组内保持原有相对顺序。

**伴生类**（``StrIterator``、``ListIterator`` 等）作为独立 ``class`` 放在**宿主类之前**；其类体内仍按上表，通常仅 T4 + T8。

**Pass 生成成员**（``expand_dataclass``、``expand_default_bool``、``expand_default_ne`` 等）不在源中出现；若手写同名 dunder，仍落在对应 Tier。

#### 4.3.2 Tier 内排序

| Tier | 标准库 ``py2cpp/`` | 用户 / ``test/`` |
|------|-------------------|------------------|
| **T11** | 与 [CPython 3.13 库文档](https://docs.python.org/3/library/) 该类型方法表顺序一致（如 ``str`` → ``stdtypes#string-methods``，``list`` → ``typesseq-mutable``） | 字母序，或域内已有分组时保持组内字母序 |
| **T12** | 调用链自上而下（被调者在上）或字母序 | 同左 |
| **T3** | 非 ``_`` 静态 → ``_`` 静态；**native**（见下）置组末 | 同左 |
| **各 Tier** | 含实现的方法在前；**native 桩**（``pass`` / ``...``，C++ 注入体）在**该 Tier 末尾** | 同左 |

**禁止单行转发私有实现**：公开 API 若体仅为 ``return self._helper(...)``，须把实现**写在公开方法内**，并**删除**仅服务该 API 的 ``_helper``。

**共享逻辑须走公开 API**：若原 ``_helper`` 对应已有公开方法（或使用方应调用 ``find`` / ``len`` / ``split`` 等而非 ``_find_sub`` / ``_logical_len``），则**类内其它方法（含 T12）一律改调该公开方法**，**不得**再直调 ``_helper``；仅当无对外等价、仅供内部拼装（如 ``_findSubForwardKmp`` 仅由 ``find``/``rfind`` 实现体调用）时，保留 T12 私有实现。

**native 桩**：函数体为 ``pass`` 或 ``...``（``@native`` 模块 API 仅 ``...``）；译器/C++ 注入（如 ``str`` 标量 ``__init__``、``format``）在源中仍占 Tier 位，但须排在**同 Tier 已实现成员之后**（如 T4 中带实现的 ``__init__`` 在前、``pass`` 标量重载在后；T11 中 ``format`` 在 ``zfill`` 之后）。

**例外**：``return self._field`` 等只读字段；``__format__`` → ``__str__()``。

#### 4.3.3 工具与整改

- 批量重排：``python scripts/reorder_class_members.py py2cpp``（按 Tier 重排类体，保留源码片段与装饰器行）。
- 新改标准库或大文件触达时，先跑脚本再 ``python main.py py2cpp\__init__.py -o generated --no-main``。
- 历史文件允许随触达 PR 重排；``py2cpp/`` 全量应与 §4.3 一致。

### 4.5 `@decorator` 与 `@context`（翻译期包装）

```python
from py2cpp import decorator, context

@decorator
def repeat(count: int = 2):
  for i in range(count):
    yield

@context
def sample(begin: str = "begin", end: str = "end"):
  print(f"{begin} {__func__.__name__}()")
  yield
  print(f"{end} {__func__.__name__}()")
```

| 用法 | 写法 | 展开结果（概念上） |
|------|------|---------------------|
| **重复执行** | `@repeat(3)` / `@repeat` 装饰 `def f(): ...` | `for` + 多次调用 `f_impl`（无参 `@repeat` 用默认 `count=2`） |
| **前后置逻辑** | `@sample` / `@sample("a","b")` 装饰 `def f(): ...` | `print` enter + `f` 体 + `print` exit |
| **`with` 内联** | `with sample:` / `with sample("a","b"):` | enter 语句 + `with` 体 + exit 语句（无 `__enter__`） |
| **类方法** | `@repeat(3) def inc(self): ...` | 同模块类上展开；`yield` → `self.inc_impl()` |

**必须遵守：**

- 工厂函数本身标 `@decorator` 或 `@context`；应用处写 `@工厂名` 或 `@工厂名(...)`，**不要**与 `@override` 等混淆（后者不参与展开）。
- 用 **`yield`** 表示“执行被装饰函数”；**禁止** `__func__(...)`。
- `@context` 的 enter/exit 分界须为**顶层** `yield`；`@decorator` 可在 `for` 等循环内 `yield`。
- 工厂内 `__func__.__name__`：作装饰器时为被装饰函数名字符串；`with` 内联 enter/exit 中为 `"<with context>"`。
- 工厂内 `yield` **不会** 生成 `GeneratorType`（须在 `expand_generators` 之前由 pass 排除工厂）；详见 [参考手册 §8.6](./参考手册.md#86-decorator-与-context翻译期)。

**范本**：`test/lang/test_decorator.py`（`build_all.bat`）。

## 5. 内存与所有权（`list` / `dict` / `str`）

### 5.1 数组与 `new`

- 一维存储：`T[:]`、`char[:]`，容量变化用 `reshape`（``list``/``str``/``bytes`` 内嵌 ``_data``，类内访问；**无**对外 ``@property data``）。
- **栈定长**（优先 **`T[:N]`**）→ `PyStackArray<T, N, 0>`（仅拥有存储），下标 `k∈[0,N)`。`buf: int[:N] = new()` 或 **`buf: int[:N] = […]`**（列表长度须等于 `N`，否则**翻译期**报错）；`T[i:j] = […]` 同理（长度须为 `j-i`）。勿其它非法整体赋值。
- **栈定长二维/三维**：**`T[:R, :C]`** / **`T[:D0, :D1, :D2]`** → `PyStackArray2D` / `PyStackArray3D`；子矩形 **`T[r0:r1, c0:c1]`**（及 3D 类比）→ 带 offset 的栈块；**`a[i, j]`** / **`a[i, j, k]`** 下标规则与一维 offset 一致（全块相对、子块绝对）。初始化 **`[[…], …]`** / 三层嵌套列表，形状须与注解一致。
- **二维/三维堆数组**：**`T[:,:]`** / **`T[:,:,:]`** → `PyArray2D` / `PyArray3D`；**无** **`__len__`** / **`len(a)`**（一维堆/栈仍可用 `len` 或编译期长度）。
- **多维视图**：**`span2d[T]`** / **`span3d[T]`**；字段 **`shape`** 为 **`(int, …)`** 元组；**`span2d.stride`** 为行步长标量（列步长恒为 1）；**`span3d.strides`** 为 **`(plane, row)`** 二元组（最内维步长恒为 1）；行主序连续块默认 **`stride = cols`** / **`strides = (d1*d2, d2)`**；**`grid.view`** / **`heap.view`** → 对应 span；**`vw[r0:r1, c0:c1]`** 共享子矩形（步长须为 1）。**`grid[r0:r1, c0:c1]`** 表达式 → 堆 **`array2d`** 拷贝（栈/堆对称）。
- **栈子区间注解**：**`T[i:j]`**（优先 **`T[:N]`**，`T[0:N]` 等价）→ `PyStackArray<T, j-i, i>`；**`s[k]` 为绝对下标** `k∈[i,j)`。仅注解/形参，**不能**由 `buf[i:j]` 得到。
- **可变参数整包**：``def f(*args: int[:])`` 表示 **整包** ``PyArray<PyInt>``（与 ``xs: int[:]`` 形参相同）；``f()`` 生成空 ``PyArray<…>()``；额外位置实参按堆数组字面量规则打包。注解须为 ``T[:]``，其它类型报错；无注解的 ``*args``（标准库 ``print`` / ``new`` 等）不启用。调用侧可变段可 **交错** 标量与 ``*`` 解包：``f(3, *a, 4, *b, 5)``（``a``/``b`` 为同类型 ``T[:]`` 变量；定参之后拼成整包）；函数体内可向同签名 callee **转发** 整包：``return g(*args)``（``args`` 须为本函数可变参数名；**不可** ``scalar(*args)`` 传给仅 ``x: int`` 的形参）。``*args`` 后仅关键字形参、关键字与位置段混用时的 ``*``、``**kwargs`` 泛化**暂不实现**。范本：``test/lang/test_vararg_pack.py``。
- **可变参数形参包（TypeVarTuple）**：``def f[*Ts](*args: Ts)`` 复用函数头 ``TypeVarTuple``；``def f[*Ts](*args)`` 或 ``def f(*args)`` **无注解**时另增独立形参包（译器自动 ``__Ts`` / ``__Ts1``…，与头内用户 ``Ts`` 等区分、与 ``*args`` 形参名无关）；无注解普通形参自动模板为 ``__T0``、``__T1``…；``for x in args`` peel 辅助 struct 为 ``__py2cpp_vt_loop_*``，入口静态方法 ``__call__``（非 ``go``）。函数头至多一个 PEP 695 ``TypeVarTuple``；显式注解须 ``*args: Ts``（**勿** ``*args: *Ts``），与 ``*args: T[:]`` **互斥**。``len(args)`` → 编译期 ``sizeof...(args)``。``for x in args`` 按包展开（命名空间级 peel struct）；循环体内 **禁止** ``break``/``continue``/``for-else``。调用与 ``T[:]`` 整包相同：位置标量 + ``*PyTuple``/``*args`` 交错、``return g(*args)``→``g(args...)``。形参包对应元组类型：规范写法 ``(*Ts,)``（亦可用 ``tuple[*Ts]``，S16 会建议改为 ``(*Ts,)``），译为 ``PyTuple<Ts...>``；``t: (*Ts,) = args`` → ``PyTuple<Ts...> t(args...)``；``g(*t)`` 按定长 ``PyTuple`` 解包传参。``class C[*Ts]:`` 体内规则相同。**暂不实现**：``type if``、``*args`` 后仅关键字形参。范本：``test/lang/test_variadic_template.py``。
- **栈数组切片表达式**：**`buf[i:j]`** / **`buf[::2]`** 等 → 堆 **`PyArray<T>`**（`_getslice`，拷贝）。结果 **`T[:]`**，下标从 0 起。
- **堆 ``str`` 切片表达式**：同样优先 **`s[:k]`**，勿 **`s[0:k]`**（如 ``io/file/path.py`` 的 ``splitExt`` / ``splitDrive``）。
- **视图**：**`s.view`**（只读）为覆盖整段的 **`span[T]`**（1D）或 **`span2d`/`span3d`**（2D/3D）；**`s.view[i:j]`** / **`vw[r0:r1, c0:c1]`** 仍为共享视图；**`v[k]`** / **`v[r,c]`** 相对视图局部坐标。可写回父容器；**不可** `s.view = …`。形参 **`const PySpan&`** 仍可通过 **`__setitem__`**（``@immutable``）写底层元素；**勿**对仅写下标的 ``span`` 形参加 ``@ref``（``@ref`` 留给改视图句柄或 ``list``/``dict`` 等容器本体）。
- **堆一维**：**`T[:]`** → **`PyArray<T>`**。栈数组**不支持** `del`（含单下标）。
- 初始化：`self._data: T[:] = new(0)`，不要用 `allocArray` 除非与 `init`/`destroy` 手动管理生命周期。

### 5.1.1 ``Pool[T]``（对象池，纯 Python 规格）

- 模块 ``py2cpp/util/pool.py``：``_blockBufs`` + 栈定长 ``_freeTop`` / ``_freeData`` + ``_useMark``（``clear`` 仅析构在用槽并清零标记）+ ``_meta_*`` / ``_skipHi``（``_metaInsert`` + 跳表 ``_skipHiAppend`` 增量维护）。``_locatePtr`` 勿把 ``list[Pointer]`` 下标结果赋给局部 ``Pointer`` 再比较（易生成悬垂 ``T*&``）。``PoolSlotLoc`` 勿元组解包返回值。
- **容量**：``@property capacity``（读已分配槽总数；写 ``p.capacity = N`` 仅扩容至至少 ``N``，代替 ``reserve``）。``list`` / ``dict`` / ``set`` 同理（``list`` 写 ``capacity`` 调 ``_reserve``；映射/集合空表时直接扩桶，非空 ``_rehash``）；``frozendict`` / ``frozenset`` 只读。
- 扩容**只追加新块**；``release`` 经跳表 + ``ptr - base``。``destroy`` / ``init`` 见 §5.2。
- **语义**：对象池，非序列容器。勿与 ``alloc[T]()`` 混淆。

### 5.2 显式 `init` / `destroy` / `free`

在**原位构造/析构**或**链表节点**场景使用（`list.insert`/`pop`、`dict` 清桶）：

- ``p: Pointer[T] = id(x)`` 取对象地址（非 CPython ``id()`` 整数）；``@refcount`` 得堆对象 ``T*``。``x`` 须为可寻址左值，勿写 ``id(字面量)``（**S07**：勿 ``id[T](x)``）。
- ``init(ptr, …)`` / ``destroy(ptr)`` / ``free(ptr)`` / ``freeArray(ptr)`` **须**省略 ``[T]``（**S07**；C++ 从指针实参推导）；``alloc[T]()`` / ``allocArray[T](n)`` 仍须显式类型。

```python
destroy(self._data.view.at(index))
init(self._data.view.at(index), item)

destroy(cur)
free(cur)
```

- 节点类加 **`@boxing`**，命名如 `DictEntryUnsafe` → C++ `PyDictEntry`（见 `analysis/ir.py` 的 `CPP_RENAME`）。
- 构造：`entry = DictEntryUnsafe[K, V](key, value, head)`（译器生成 `new`，勿手写 `new`）。
- **`__del__` / `__copy__` 前**先释放旧资源（`dict._clearEntries`）。

### 5.3 拷贝与移动

- **类实现**：深/浅拷贝逻辑写在 **`__copy__(self, other)`**（`dict` 深拷贝桶链）；仅在类型内部需要定制拷贝语义时使用。
- **调用方**（含 ``test/``）：``@copyable`` 类型用 **`dst: T = src`** 触发拷贝构造，不写 ``T(src)``、``dst.__copy__(src)``。
- 数组块转移用 **`__move__`**（``str(data)`` / ``bytes(data)`` 的 ``__init__``），不要重复分配再逐元素拷贝。

```
模块 docstring（Python 3.13 文档 + CPython Objects/*.c 出处，见 §8）
    ↓

    ├─ ``StringMixin`` 已提供：``__len__``、切片 ``__getitem__``、``find``/``index``/``rfind``/``rindex``、
    │   ``count``、``startsWith``/``endsWith``、``glob``、``join``、``split``/``rsplit``/``splitLines``、
```

**``text/mixins.py``**：``@mixin class StringMixin[T]``；混入后译器将方法内 ``T`` 替换为 ``char`` / ``byte``，``Self`` 替换为 ``PyStr`` / ``PyBytes``。mixin 内空缓冲写 ``T[:] = []``；``str`` 业务空串仍可用 ``""`` / ``b""``。

**``startsWith`` / ``endsWith``**：单段 ``Self``、多段 ``list[Self]`` / 堆 ``Self[:]``（``str[:]`` / ``bytes[:]``，``new(n)`` 后填元素）、裸缓冲 ``char[:]`` / ``byte[:]``（单段码点/字节；勿用元组字面量）。

**``glob(pattern, ignoreCase=True)``**（``StringMixin``）：shell 通配（``*`` / ``?`` / ``[…]``），语义对齐 ``fnmatch`` / ``fnmatchcase``；``ignoreCase`` 时对 name 与 pattern 做 ``io.file.path.normCase`` 等价规范化（``/``→``\\`` + ASCII ``lower``）。内部 ``_glob_*`` 为实例 helper（``name._globMatch(pat)``、``pat._globMatchBracket(c, pi)``），非 ``pathlib.Path.glob``；无独立 ``fnmatch`` 模块。

### 6.0.1 私有 helper：实例方法优先

类内 ``_`` 前缀辅助逻辑**优先**写成**实例方法**（``@immutable``），让主要操作对象作 ``self``，组合层用 ``self._helper(...)`` / ``other._helper(...)`` 调用，**避免** ``Self._helper(x, …)`` 式静态分发。

| 场景 | ✅ 推荐 | ❌ 避免 |
|------|---------|---------|
| 对某 ``str``/``bytes`` 做变换 | ``def _globNormcase(self) -> Self: …``；``pat._globNormcase()`` | ``@staticmethod def _globNormcase(s: Self)`` |
| 在 name 上匹配 pattern | ``def _globMatch(self, pat: Self) -> bool``；``name._globMatch(pat)`` | ``Self._globMatch(name, pat)`` |
| 字符类体 ``body`` 判定 | ``body._globClassContains(c)`` | ``Self._globClassContains(c, body)`` |
| 无接收者的工厂/哨兵 | ``@staticmethod def makeTrans(...)``、``@const`` 哨兵 | 硬把工厂改成 ``self._makeTrans`` |

**仍用 ``@staticmethod`` 的例外**：``makeTrans``、``fromKeys``、``@const`` 哨兵比较所需的纯函数、以及**确实**与实例无关的模块级式 helper。宿主钩子（``_toLowerChar``、``_isFieldWhitespace`` 等）保持静态。``StringMixin.glob`` 的 ``_glob_*`` 链为实例 helper 范本。

**protected 访问**：同类另一实例的 ``._helper`` 须通过带 ``Self`` 注解的局部/参数（``chunk: Self = chunks[j]`` 再 ``chunk._globClassChunkContains(c)``）；**勿**写 ``chunks[j]._helper``（下标接收者无法绑定类，bootstrap 会误报 str/bytes 交叉访问）。

**``makeTrans`` / ``translate``**：``dict[T,T]``（``str``→``char``、``bytes``→``byte``）；``makeTrans(frm, to[, remove=new()])``、``translate(table[, delete=new()])`` 均在 ``StringMixin``；``bytes(n)`` 构造 ``n`` 个 ``\\0`` 字节（``n<=0`` 同 ``b\"\"``）。

勿用 `# ---` 分隔注释块；方法之间单空行即可。

### 6.1 哨兵形参

可选 `end` 未传时，CPython 表示「搜到末尾」，**不能用 `-1` 当默认索引**：

```python
# list / str / deque — 类内 @const 哨兵；比较与 @staticmethod 互调均写 Self._NAME
class list[T]:
  _EndIndex: int @const = int.Min

  def _normStop(self, end: int) -> int:
    if end == Self._EndIndex:
      return len(self)

# str / bytes — 哨兵在 StringMixin：``_EndIndex: int @const = int.Min``

class deque[T]:
  _EndIndex: int @const = int.Min
  _NoMaxLen: int @const = int.Min

  def _normStop(self, end: int) -> int:
    if end == Self._EndIndex:
      return self._length

def index(self, value: T, start: int = 0, end: int = Self._EndIndex) -> int:
  stop: int = self._normStop(end)  # end 为哨兵 → 搜到 ``len``
```

**容器类 ``@const`` 命名**（值均 ``int.Min`` 时亦须分语义命名，勿混用）：

| 名 | 语义 | 典型宿主 |
|----|------|----------|
| ``_EndIndex`` | 可选 ``end`` 未传 → 搜/切到末尾 | ``StringMixin``、``FrozenListMixin``、``deque`` |
| ``_NoMaxLen`` | ``deque`` 未限长（``maxLen()`` 对应 ``None``） | ``deque`` |
| ``_SsoCap`` | 小字符串/字节 SSO 缓冲长度 | ``StringMixin`` |
| ``_BlockCap`` / ``_BlockCount`` / ``_SlotCap`` / ``_FreeDataLen`` | 对象池块/槽容量 | ``Pool`` |
| ``_DeleteChar`` / ``_DeleteByte`` | ``translate`` 删除码点哨兵 | ``str`` / ``bytes`` |

新模块若引入「省略 end」语义：哨兵值统一为 ``int.Min``（``PY2CPP_INT_MIN``），类内 ``@const`` 上表名定义一次；比较与默认形参均写 ``Self._EndIndex`` 等（勿重复字面量 ``int.Min``）。容量常数同理：注解 ``array[T, _SsoCap]``、栈 ``int[:_BlockCount]`` 与逻辑均引用 ``@const`` 名。

### 6.2 类内 ``type`` 别名

```python
class list[T]:
  type Element = T

  def append(self, item: Element): ...

class dict[K: DictKeyType, V]:
  type Key = K
  type Value = V

@protocol
class ContainerType[T]:
  type Element = ...
  def __contains__(self, item: Element) -> bool: ...
```

- 协议**关联类型**（如 ``ContainerType`` 的 ``Element``）仍用 ``type Element = ...``，探测 ``typename U::Element``。
- 协议**数据成员**用 ``name: T = ...``（如 ``RationalType`` 的 ``numerator: int = ...``），探测 ``decltype(U::name)``；**属性**用 ``@property def name(self) -> T: ...``，探测 ``decltype(U::name__get())``（实例 property 译为 ``name__get()`` / ``name__set``）。
- 类内具体别名 ``type Element = T`` 生成 ``using Element = T;``；方法签名写 ``Element``，不展开为 ``T``。
- 泛型别名 ``type Counter[T: DictKeyType] = dict[T, int]`` → ``template<typename T, DictKey_requires<T> = 0> using Counter = PyDict<T, PyInt>;``；``Counter[PyStr]`` 注解 → ``Counter<PyStr>``。
- 别名形参上的 ``T: Protocol`` **仅当** ``T`` 出现在 ``=`` 右侧时有意义；``type Element[E: ComparableType] = T`` 中 ``E`` 未使用，约束会被忽略——应在类头 ``class list[T: ComparableType]`` 或 ``type Counter[T: DictKeyType] = dict[T, int]`` 中写约束。
- ``@protocol`` 类不生成 C++ 类体；其中 ``type Element = T`` 仍在分析阶段展开到底层形参，供协议方法注解使用。

#### 6.2.1 条件类型别名（Py2Cpp 扩展，G1 已实现）

> 设计定稿与**命名规范**见 **[type-conditional.md §3](./type-conditional.md#3-标准库范本别名与命名规范)**。

**标准库条件别名**（恒等 ``else T`` 或 ``ListOnly`` 严格变体，捕获 ``= ...``）：

```python
type ValOf[T, _V = ..., _W = ...] = (
  _V if T is list[_V]
  else _W if T is dict[str, _W]
  else T
)
type StrDictValueOf[T, _V = ...] = _V if T is dict[str, _V] else T
type ListElemOf[T, _V = ...] = _V if T is list[_V] else T
type ListOnly[T, _V = ...] = _V if T is list[_V] else Never
```

| 规则 | 说明 |
|------|------|
| 命名 | ``{Role}Of`` + PascalCase；捕获须 ``_V``/``_W``/``_K`` 等 ``_X = ...``（见 type-conditional §3.3） |
| 调用 | 仅 ``Alias[Concrete]``；**禁止**传入捕获实参 |
| RHS | ``X if T is Pattern else Y``；无 ``else`` 等价 ``else Never`` |
| 严格变体 | 标准库 ``ListOnly``；其它 ``else Never`` 模块内自建 |
| 组合 | ``type Inner[T] = ListElemOf[ListElemOf[T]]``；勿发明 ``InnerElem`` 标准名 |
| 指针 | ``Pointer[T]`` 的 ``T`` 已是 pointee；分派用 type if |
| ``@boxing`` | ``Node[T]`` 已是 ``Node<T>*``，勿 ``Pointer[Node[T]]`` |

**type if 分派**（函数/类体内）：``if T is list[...]:`` + ``T.Element``；**注解与跨函数**优先 ``ListElemOf[T]`` / ``ValOf[T]`` 等。

### 6.3 迭代器、视图与内置辅助类

- **命名**：`ListIterator`、`DictKeysView`、`ZipIterator`、`EnumerateIterator`、`DequeNodeUnsafe`（`@boxing` 链表节点，对齐 `DictEntryUnsafe`）。**不要**用 `_ZipIterator`、`_Pair` 等带前导下划线的类名（下划线留给模块内函数/常量）。
- **泛型形参**：与元素/迭代器类型一致，写 PEP 695 约束而非协议类型变量名当占位，例如：

```python
class ZipIterator[ItL: IteratorElementType, ItR: IteratorElementType]:
  def __init__(self, left: ItL, right: ItR):
    self._left: ItL = iter(left)
    ...

def zip[ItL: IteratorElementType, ItR: IteratorElementType](left: ItL, right: ItR):
  return ZipIterator(left, right)

def enumerate[T](xs: IterableType[T], start: int = 0):
  return EnumerateIterator(xs, start)
```

``zip`` / ``ZipIterator`` 与 Python 一致：参数为**可迭代对象**（``list``、``dict.keys()`` 等），类内用 ``iter(left)`` 取迭代器；``ItL``/``ItR`` 为两侧 ``__iter__`` 的返回类型。

- 迭代器：`__iter__` 返回 `self`，`__next__` 抛 `StopIteration`（生成器/协程 C++ 为 `PyIterResult<Y,R>`）；`EnumerateIterator.__next__` 注解 `-> (int, T)`（C++ `PyTuple<int, T>`）。
- **`for i, x in enumerate(seq)`**：译器对支持 ``__len__`` + ``__getitem__(int)`` 的 ``seq``（``list``、``str`` 切片、定长栈数组、`reversed` 包裹的同类容器等）**优先**生成索引 ``for``（``i = start + fi``），与 ``for x in seq`` 的 ``_index_for_loop_plan`` 同一套；仅无法索引化时才实例化 ``EnumerateIterator``。业务代码仍写规范 Python，勿手写下标循环替代。
- **`ListIterator` 默认构造**：须用 ``@overload`` 提供无参 ``__init__``（``pass`` 存根），供生成器 ``yield from`` 成员字段在 MSVC 下先默认构造再赋值；``list.__iter__`` 对宿主 ``list`` 传 ``this``（指针），见 ``translator._emit_list_iterator_ctor_inner``。
- **用户序列默认 ``__iter__``**：若类仅有 ``__len__`` + ``__getitem__(int)``，勿手写 ``__iter__`` 时由 ``expand_default_iter`` 生成 ``{Class}_iterator``；逻辑与 ``ListIterator`` 相同（``0 .. len-1`` 下标）。须 ``@immutable`` 的 ``__len__``；仅有 ``__getitem__(slice)`` 的类（如 ``str``）不注入。
- **不要**写 `class foo_iterator(IteratorType[T])`：`IteratorType` 是 `@protocol`，具体类只需实现 `__iter__`/`__next__`。
- 视图：持有宿主引用 + `__len__` 委托宿主；`keys()` / `values()` / `items()` 返回视图对象，不返回裸 `list`。

### 6.4 参数化协议（``NavigatableType[Node]`` 等）

带关联类型形参的 ``@protocol``（如 ``alg.protocols.NavigatableType[N]``）用于约束「接收者 + 节点类型」。方括号内可以是 **PEP 695 头上已声明的形参名**（如 ``Node``），也可以是**模块内具体类型名**（如 ``Cell``）；无 ``[…]`` 头时译器为接收者注解自动分配 ``T0``（与 ``x: ComparableType`` 同类）。

**标准库推荐写法**（接收者约束写在形参注解，关联形参只声明一次）：

```python
def astar[Node: DictKeyType](nav: NavigatableType[Node], start: Node, goal: Node) -> list[Node]:
  ...
```

| 写法 | 说明 |
|------|------|
| ``def f[Node: DictKeyType](nav: NavigatableType[Node], …)`` | ✅ **优先**：``Node`` 在头上；``nav`` 另增模板 ``T0`` + ``Navigatable_requires<T0, Node>`` |
| ``def f[Nav: NavigatableType[Node], Node: DictKeyType](nav: Nav, …)`` | ✅ 约束写在头上，形参用 ``nav: Nav`` |
| ``def f[Nav, Node: DictKeyType](nav: NavigatableType[Node], …)`` | ❌ **S19**：头上 ``Nav`` 未使用（``nav`` 绑定的是 ``T0`` 而非 ``Nav``） |
| ``def walk(nav: NavigatableType[Cell], start: Cell, …)``（无 ``[…]``） | ✅ 译器补 ``T0`` + ``Navigatable_requires<T0, Cell>``；``Cell`` 为**具体类型**（勿进 ``template_names``） |

擦除类协议（``IterableType``、``ComparableType`` 等）仍用 ``xs: IterableType[T]`` + 头上 ``[T]``（``T`` 即容器/元素模板）。详见 [参考手册 §5.3](./参考手册.md#53-类型注解与模板形参)。

**S19**：``--strict`` 下对**函数** PEP 695 形参做未使用检查；删除无用形参或写入注解/体。
- 容器 `__str__`/`__repr__`：实现体内用 `str(x)` / `repr(k)` 拼串（`out = out + ...`），见 §9；勿用 STL 字符串流。

## 7. 算法与 Pythonic 控制流

| 推荐 | 示例来源 |
|------|----------|
| `for i in range(n)` | `list.sort`、`str` 各方法（**S13**：勿 `range(0, n)`、`range(0, n, 1)`、`range(a, b, 1)`） |
| `for x in iterable` | `list.extend`、`dict.update` |
| `for i, x in enumerate(seq)` | 索引可内联时与 ``for x in seq`` 同策略；``EnumerateIterator`` 为后备 |
| `s[i] == '"'` / `s[i] in '"'` | JSON/文本扫描：``==``/``!=`` 与单字符字面量由译器发 ``PyChar``；成员检测可用 ``in "…"`` |
| `while cur is not None` | `dict` 桶链遍历（链表例外，不用 `for` 伪造） |
| 早返回 | `str.capitalize` 空串 `return ""` |
| 私有交换 | `list._swap`、Timsort 内部 |

避免在标准库中写 `while i < n: i += 1` 代替 `range`（**S12** 会报错）。体内若还有 ``i = j``、分支里不同步长的 ``i += …`` 等其它索引修改，或 ``while i < n and …`` / ``while cur is not None``，则不在 S12 范围。

### 7.1 生成器函数（``yield`` / ``yield from``）

含 ``yield`` 或 ``yield from`` 的 ``def`` **不**按普通函数体翻译。译器在 **``expand_decorators`` 之前** 执行 ``expand_generators``（``passes/generators.py``），将函数降为 **``{name}_generator``** 迭代器类（嵌套于类内时为 ``{Class}_{method}_generator``），再由 ``passes/generator_emit.py`` 为 ``__resume`` 生成 C++ ``switch`` 状态机。语义对齐 **Python 3.13** 生成器（``send``、``return`` 返回值、``StopIteration.value``）。

#### 翻译管线

| 阶段 | 模块 | 作用 |
|------|------|------|
| 展开 | ``generators.py`` | AST：``def f`` → ``class f_generator`` + 包装 ``def f: return f_generator(...)``；``GeneratorType[Y,S,R]`` 注解；``__resume`` / ``__next__`` / ``send`` |
| 分析 | ``SemanticAnalyzer`` | ``__next__`` / ``send`` / ``__resume`` → ``IterResult[Y, R]`` |
| 生成 | ``generator_emit.py`` | ``translator`` 对 ``generator_methods`` 中的 ``__resume`` 调用 ``emit_generator_next`` |

#### 生成 C++ 结构（Allman 大括号）

与全项目一致（``translator._use_block``、[参考手册 §8.4](./参考手册.md#84-overload)），状态机在 ``__resume`` 中；``__next__`` 等价于 ``send(None)``：

```cpp
PyIterResult<PyInt, PyNone> gen_echo_generator::__next__()
{
  return this->send(0);  // SendType 为 int 时；None 则为 send(PyNone())
}

PyIterResult<PyInt, PyInt> gen_with_return_generator::__resume()
{
  // ...
  return PyIterResult<PyInt, PyInt>::Return(99);  // return 99 → Return 变体
}
```

| 规则 | 说明 |
|------|------|
| **注解** | 生成器函数写 ``-> GeneratorType[Yield, Send, Return]``（``@protocol``，定义于 ``py2cpp/protocols.py``，由 ``__init__.py`` 再导出）；``None`` → ``PyNone`` |
| **C++ 类型（双轨）** | ``-> GeneratorType[Y,S,R]`` **仅**生成器函数 → 具体 ``{name}_generator``（``for x in f():`` 热路径不装箱）；形参/字段/局部 ``GeneratorType[Y,S,R]`` 注解及 ``@virtual``/``@override`` 返回 → 擦除句柄 ``PyGenerator<Y,S,R>``（``templates/core/generator.h``）；具体生成器赋给擦除位时译器插入 ``makeGenerator<Y,S,R>(…)`` |
| **入口** | ``def f(...)`` → ``return f_generator(...)``；``for x in f():`` 走 ``__iter__`` |
| **``IterResult[Y, R]``** | ``Yield`` 变体的 ``value``；``Return`` 变体或 ``done`` 为真时 ``returnValue`` 为 ``return`` 表达式（见 ``iter_result.py``） |
| **``send``** | 成员 ``_send_value``、``_send_pending``；续体从 ``yield`` 下一状态读入发送值（``x = yield v`` / ``x: T = yield v``） |
| **状态** | ``_state`` + ``case N: { ... }``；``__resume`` 含状态机，``__next__`` / ``send`` 为薄包装 |
| **循环** | ``while`` 内含 ``yield`` 时，循环尾 ``continue`` 回到外层 ``while (true)`` |
| **形参 / 局部** | 形参 ``self.<param>``；跨挂起局部 ``self.g_<name>`` |
| **``yield from``** | ``_yf0_it`` / ``_yf0_active``；子迭代器 ``PyIterResult`` 的 ``value`` 向上传递 |
| **``for x in it: yield x``** | **S38**：须写 ``yield from it``（``async def`` 豁免）；带 ``else`` 或循环体内其它语句时不适用 |
| **``x = yield from g()``** | 子迭代器 ``done`` 时 ``x = .returnValue``（PEP 380 ``StopIteration.value``） |
| **``yield from`` 子类型** | 由可迭代对象推断；``list[T]`` → ``ListIterator[T]``；``mgr.__aenter__()`` / ``__aexit__()`` → ``{Class}___aenter___coroutine`` 等（见 §7.3） |
| **与 ``@context`` 区分** | ``@context`` 工厂内 ``yield`` 在 ``expand_decorators`` 展开 |

### 7.3 协程（``async def`` / ``await`` / ``async for`` / ``async with``）

``async def`` 先经 ``passes/coroutine_desugar.py`` 将 ``await`` / ``async with`` 降为 ``yield from .__await__()``，再在 **``expand_generators``**（``passes/generators.py``）中译为 **``{name}_coroutine``**（含 ``__await__``，返回 ``Self``）。类内 ``async def`` 为 ``{Class}_{method}_coroutine``，宿主经 ``__init__(host)`` 写入 ``g_self``；另生成无参默认构造 ``: Type(Host()) {}``，供 ``_yf*_it`` 成员占位。

| 阻塞驱动 | ``from py2cpp.concur.task import Task`` → ``Task.run(main[, period=…])``（单线程协作调度；``await Task.sleep`` 为帧 tick 等待，非 ``time.sleep``；``await Task.runThread(fn)`` 把阻塞 callable 放到 OS 线程） |

| 规则 | 说明 |
|------|------|
| **注解（纯协程）** | 直接返回值写 ``-> T``；需要形参/字段/虚函数擦除时写 ``CoroutineType[LoopHandle, None, T]``（导入 ``LoopHandle``），包装函数返回 ``*_coroutine`` |
| **注解（异步生成器）** | 含 ``yield`` 的 ``async def`` **推荐** ``-> AsyncGeneratorType[Yield, Send]``（**Python 3.13** ``typing.AsyncGeneratorType``，两形参、无 ``ReturnType``）；仍译为 ``*_coroutine`` |
| **C++ 类型（双轨·协程）** | ``-> CoroutineType[Y,S,R]`` **仅**无 ``yield`` 的 ``async def`` → 具体 ``{name}_coroutine``；形参/字段/``@virtual``/``@override`` 的 ``CoroutineType[Y,S,R]`` → ``PyCoroutine<Y,S,R>``（``templates/core/coroutine.h``）；装箱 ``makeCoroutine<Y,S,R>(…)`` |
| **C++ 类型（双轨·异步生成器）** | ``-> AsyncGeneratorType[Y,S]`` **仅**含 ``yield`` 的 ``async def`` → 具体 ``{name}_coroutine``；形参/字段/``@virtual``/``@override`` 的 ``AsyncGeneratorType[Y,S]`` → ``PyAsyncGenerator<Y,S>``（``templates/core/async_generator.h``）；装箱 ``makeAsyncGenerator<Y,S>(…)`` |
| **协议** | ``CoroutineType`` / ``AsyncGeneratorType`` / ``AwaitableType`` / ``AsyncIterableType`` / ``AsyncIteratorType`` / ``ContextManagerType`` / ``AsyncContextManagerType``（``protocols.py``） |
| **与生成器** | 同一 ``__resume`` + ``generator_emit.py``；``@context`` / ``@decorator`` 内不生成协程 |
| **``await``** | ``await expr`` → ``yield from expr.__await__()`` |
| **``async for``** | **Python 3.13** ``ast.AsyncFor``；``__aiter__`` + ``while`` + ``__anext__`` + ``if (r.done) break``（同 §7.1 ``__next__``，**不**用 ``StopAsyncIteration``） |
| **异步可迭代** | 含 ``yield`` 的 ``async def`` 自动 ``__aiter__`` / ``__anext__``（``__anext__`` 转发 ``__next__()``） |
| **``async with``** | 管理器宜满足 ``AsyncContextManagerType``；仅 ``async def`` 内；``awmN = expr``、``aweN = yield from __aenter__()``、``as v`` → ``v = aweN``、``return`` 前 ``yield from __aexit__()``；**无**异常三元组（同 §7.2） |
| **跨挂起局部** | ``awm*`` / ``awe*`` / ``as`` 等 → ``self.g_*``；剥离占位 ``= 0`` 时保留 ``self.g_v = self.g_awe0`` 等字段间赋值 |

#### 生成 C++ 片段

``async for``（``generator_emit._emit_for_async``）：

```cpp
auto ait = asyncGenTwo().__aiter__();
while (true) {
  auto ar = ait.__anext__();
  if (ar.done) break;
  // ar.value
}
```

``async with`` 状态机顺序（脱糖后）：``__aenter__`` → ``g_v = g_awe0`` → ``__aexit__`` → ``return g_v``（见 ``generated/test/lang/test_async.cpp`` 中 ``use_async_with_coroutine``）。

#### Python 写法范本

与 ``test/lang/test_async.py`` 一致（``build_all.bat``）：

```python

  return 42
```

#### 限制（生成器 / 协程）

| 项 | 说明 |
|----|------|
| ``yield from`` 子类型 | 同步 ``def`` 生成器：``list``、``*_generator`` 等，由构造 / 调用推断 |
| ``async def`` 内 ``yield from`` | **禁止**（Python 3.13 ``SyntaxError: 'yield from' inside async function``）；委托子异步可迭代用 ``async for x in ag(): yield x``；``await`` / ``async with`` 仍由译器脱糖为 ``yield from .__await__()`` |
| ``async with`` | ``as`` 仅简单变量名；模块级 ``async with`` 不支持 |
| 控制流 | ``if`` / ``while`` / ``for`` / ``async for`` / ``yield`` / ``return`` / ``try`` / ``except`` / ``else`` / ``finally``（同步生成器另见 §7.1 ``yield from``） |
| 并发 / 事件循环 | ``Task.run`` / ``Task.create`` / ``await Task.sleep`` / ``await Task.gather`` / ``await Task.runThread``；``Task.periodCount`` / ``Task.duration`` |

### 7.4 ``**kwargs: Options``（关键字选项）

参数较多时，用 **选项类** 或 **类自身** 承载关键字（``passes/kwargs_options.py``，在 ``expand_mixins`` **之后** 展开）。

| 规则 | 说明 |
|------|------|
| **函数 / 方法** | ``def f(**kwargs: Opt)`` → ``def f(kwargs: Opt)``；``__init__(self, **kwargs: Opt)`` 同理 |
| **``assign``** | **翻译期专用**：无 C++ ``assign`` 成员；仅 ``obj.assign(w=1)`` 或 ``self.assign(**opt)``（``opt`` 为 ``**kwargs: Opt`` 形参）；**不支持** ``assign(opt)`` 位置传参；只读 ``@property`` 不可 ``assign`` |
| **``select``** | **翻译期专用**：无 C++ ``select`` 成员；仅 ``obj.select("path")``（字符串字面量）；返回类型见 [§7.5](#75-select路径选择) |
| **``build``** | **翻译期专用**：无 C++ ``build`` 成员；``Type.build("…")`` / ``list[T].build("…")``；见 [§7.6](#76-build对象构造) |
| **构造（无 ``**kwargs``）** | ``Window(w=1, title="x")`` → ``Window()`` + ``.w = 1`` …（字段 / ``@property``） |
| **构造（有 ``**kwargs: Opt``）** | ``Win(w=1)`` → 构造 ``Opt`` + ``Win(opt)``；可与位置参数混用 |
| **选项类** | 推荐 ``@dataclass`` + 类体 ``width: int = 0``（实例字段默认）；``static const`` 用 ``width: int @const = 0`` |
| **转发** | ``g(**kwargs)`` 且 ``g`` 亦为 ``**kwargs: 同类型 Opt``（或 ``__init__`` 接收同类型 Opt）→ ``g(kwargs)`` |
| **``new`` / ``Self``** | ``x: Opt = new(w=1)``、类内 ``Self(w=1)``（须类型注解）→ 默认构造 + 字段赋值 |
| **限制** | 不支持 ``**dict`` 解包；不支持 ``obj.method(k=v)``（``self.method`` / 模块函数可以） |

范本：``test/lang/test_kwargs_options.py``。

### 7.5 ``select``（路径选择）

与 ``assign`` 同级 **译期专用** 读路径 API（``TRANSLATOR_ONLY_METHODS``；**无** C++ ``select`` 成员）。**完整 DSL** 见 **[selector.md](./selector.md)**；架构见 [参考手册 §7.9](./参考手册.md#79-select译期路径选择)。

```python
names: list[str] = org.select(".teams[0].name")
hits: list[Member] = team.select(".members{.score > threshold}@sort(-.score)")
n: int = org.select(".teams@count")
```

| 规则 | 说明 |
|------|------|
| **调用** | ``receiver.select("…")``；参数须为 **字符串字面量** |
| **返回** | 无后处理：**恒** ``list[T]``；``@sort`` → ``list[T]``；``@group`` → ``dict[K, list[T]]``；``@count`` → ``int``；``@count(.f)`` → ``Counter[V]`` |
| **后处理** | 后缀 ``@sort(-.k, .k2)`` 等；``@group`` / ``@count(.f)`` 键与 ``{filter}`` **同表达式子集**；**禁止** ``@group@sort``、``@group@count`` |
| **路径根** | 取 receiver 字段须 ``.ident`` 起头（``".teams"`` ✓） |
| **过滤 ``{…}``** | 内为 Py2Cpp 表达式；``.field`` 表当前元素；其它标识符为调用点作用域变量 |
| **``:$`` / ``$``** | 同链 ``: $t`` 绑定；``$t`` 引用须来自**严格更早**的绑定；``@sort`` / ``@group`` / ``@count(k)`` 键与 filter 相同；**方案 A**：单父 ``list`` 可用 ``@sort($t.f, .g)``；``;`` 右从根导航时 **不可** 引用左段 ``$`` |
| **多路径** | 用 ``.field[i,j].suffix`` 或 ``.(rel1, rel2).suffix``；**禁止**顶层 ``",``（如 ``".a, .b"``） |
| **类声明** | **勿**手写 ``def select``（除非真实方法体且不与译器冲突） |
| **测试** | ``test/lang/test_selector.py``、``test/lang/test_selector_post.py``；译器 ``src/tests/test_selector_parse.py`` |

### 7.6 ``build``（对象构造）

与 ``select`` 对偶的 **译期专用** 写构造 API（``TRANSLATOR_ONLY_METHODS``；**无** C++ ``build`` 成员）。**完整 DSL** 见 **[build.md](./build.md)**；架构见 [参考手册 §7.10](./参考手册.md#710-build译期对象构造)。

```python
org: Org = Org.build('teams[:2]: $i > name={prefix + str($i)}, minScore=$i')
teams: list[Team] = list[Team].build('[:3] > name="x"')
```

| 规则 | 说明 |
|------|------|
| **调用** | ``Org.build("…")`` 或 ``list[T].build("…")``；参数须为 **字符串字面量** |
| **list 根** | ``list[T].build`` 串首 **必须** ``[:N] > …`` |
| **list 段** | ``field[:N] > body``；``body`` 只写一次，自动重复 N 次 ``append`` |
| **下标** | ``[:N]: $i > …``；``$i`` 为 0..N−1；裸 ``score=$i`` 仅赋 ``int``/``int64`` |
| **赋值** | 字符串须引号；数字 / ``True`` / ``False`` / ``None`` / ``{expr}`` |
| **类声明** | **勿**手写 ``def build`` |
| **测试** | ``test/lang/test_build.py``；译器单测 ``src/tests/test_build_*.py`` |

### 7.8 嵌套 ``def`` 闭包与 ``global`` / ``nonlocal``

设计定案见 [closure.md](./closure.md)；用户摘要见 [参考手册 §6.6](./参考手册.md#66-global--nonlocal--嵌套-def-闭包)。

| 规则 | 说明 |
|------|------|
| **模块 ``global``** | 先写 ``x: T = …``，再在函数内 ``global x``；勿指望 ``global x; x = 1`` 创建新模块变量 |
| **嵌套 ``def``** | 闭包形参与模块级 ``def`` 同范式：``new``、``Self``、``**kwargs: Opt``、``T @lazy``、``[*Ts]`` 等 |
| **赋值推断** | ``f = inner`` 推断 ``PyCallable<…>``；与 ``inc = lambda x: …`` 一致 |
| **``self``** | 类方法内嵌套 ``def`` 用 ``self`` → 与委托 ``lambda`` 相同 capture |
| **自引用** | 允许 ``inner`` 在 ``def inner`` 完成后递归调用自身 |
| **逃逸** | ``return inner`` / 存字段 **首期按 C++ lambda 引用捕获**；勿在 defining 函数返回后仍调用（无 heap cell） |
| **``lambda``** | 完整 ``global``/``nonlocal`` 闭包 **不在** ``lambda`` 范围；委托场景仍见 [参考手册 §7.4](./参考手册.md#74-多播委托-delegate) |
| **生成器嵌套** | 内层 ``def`` 含 ``yield`` 且需 capture → 首期不支持（与闭包分阶段） |

```python
_total: int = 0

def outer(seed: int) -> Callable[[int], int]:
  base: int = seed

  def inner(x: int) -> int:
    nonlocal base
    global _total
    _total += 1
    base += x
    return base

  return inner
```

### 7.2 ``with`` 语句（通用上下文管理器）

用户代码中的 ``with`` **在代码生成期**展开为 ``__enter__`` / ``__exit__`` 调用（``translator.visit_With``），**不**依赖 CPython 运行时栈。与 [参考手册 §6.3](./参考手册.md#63-with-语句) 一致。

| 规则 | 说明 |
|------|------|
| **协议** | 管理器宜满足 ``ContextManagerType``（``__enter__`` → ``T``、``__exit__`` 无返回值注解）；生成 C++ **无** ``exc_type`` / ``exc_val`` / ``exc_tb`` 参数（与 CPython 异常三元组不同，见 ``test/io/test_io.py``） |
| **``as``** | ``with mgr as x`` → ``auto x = mgr.__enter__()``（绑定 **``__enter__`` 返回值**）；``async with`` 经脱糖 ``aweN = yield from __aenter__().__await__()`` 后 ``x = aweN``（见 §7.3） |
| **嵌套** | 多个 ``with`` / 嵌套块 → 内层先 ``__exit__``，外层后 ``__exit__``（LIFO） |
| **``return`` / ``break``** | 离开 ``with`` 体前自动插入当前栈上所有管理器的 ``__exit__()`` |
| **``async with``** | 仅 ``async def`` 内；脱糖见 [§7.3 协程](#73-协程async-def--await--async-for--async-with) |
| **``@context`` 工厂** | ``expand_decorators`` 中：单上下文、无 ``as``、且表达式为 ``@context`` 定义的 ``cm(...)`` 时，可将 ``yield`` 前/后体**内联**进 ``with`` 体；其余（含 ``StringIO``、``open``）走通用 ``__enter__`` / ``__exit__`` |

**写法范本**（``test/io/test_io.py`` 中 ``with`` 用例）：

```python
from py2cpp import *

def use_sio():
  with StringIO() as sio:
    sio.write("ab")
    assert sio.value == "ab"

def use_file():
  with open("tmp.txt", "wb") as f:
    f.write("data")
  # 离开 with 时 TextIOWrapper.__exit__ 会 flush 并 close
```

实现 ``__enter__`` / ``__exit__`` 的类：``__exit__`` 为无参、**无** ``-> None``；文件类在 ``__exit__`` 中 ``close()``（见 ``io.py`` / ``io.inl``）。

### 7.3 ``io`` 模块（``StringIO`` / 文件 I/O）

模块 ``py2cpp/io/__init__.py``：纯 Python + ``ffi.crt.stdio``（**无** ``@native`` 业务函数、**无** ``templates/+io.inl``）。**禁止 STL**；文件层用 C stdio 绑定（``fopen`` / ``fread`` / ``fwrite`` / ``fgets`` / ``fseek``），``StringIO`` 用 ``char[:]`` 码点缓冲（与 ``str`` 拼串规范 §9 一致）。``open`` 的 C++ 名仍是 ``py_open``（``@global_call("py_*")``）。空堆 ``char[:]`` 成员/局部优先 ``""``（见 §2.1）。

| API | 说明 |
|-----|------|
| ``StringIO(initial="")`` | 内存文本流；``write`` / ``read`` / ``readLine`` / ``readLines`` / ``writeLines`` / ``value``（``@property``，原 ``getvalue``）/ ``pos``（``@property``，读 ``tell``、写 ``seek``）/ ``take`` / ``seek`` / ``tell`` / ``close`` / ``__bool__`` / ``__enter__`` / ``__exit__`` / ``__iter__`` / ``__next__`` |
| ``open(path, mode="r")`` | 返回 ``TextIOWrapper``；C++ 符号 ``py_open``（避免 Windows CRT ``open`` 宏；Python 仍写 ``open``） |
| ``TextIOWrapper`` | ``FILE*`` 包装；``readLines`` / ``writeLines`` / ``__iter__``（``__next__`` 调 ``readLine``）；析构与 ``__exit__`` 会 ``close``；打开失败时 ``__bool__`` 为假 |

**模式**：``mode`` 字符串原样传给 ``fopen``（常用 ``"rb"`` / ``"wb"``）；读写为 **按字节/码点** 的文本语义（``read`` 将读入字节映射为 ``PyChar``），非完整 ``io`` 文本编解码栈。

**与 CPython 对齐的注意点**：

- ``StringIO.write`` 在 ``seek`` 后**覆盖**前缀、**不**截断尾部（见 ``test/io/test_io.py`` ``StringIOSeekOverwriteTests``）。
- ``StringIO.close`` 后 ``write`` 返回 ``0``、``value`` 为 ``""``。
- ``StringIO.take()``：``self._pos = 0`` 后 ``return str(self._buf)``，经 ``str(char[:])`` 移动接管缓冲；调用后 ``value`` 为 ``""``，可继续 ``write``。需保留流内容时用 ``value``。
- 文件 I/O 测试落盘统一放在仓库根 ``_test_temp/``（``py2cpp.test.test_temp``）；``with open(...) as f`` 保证退出时关闭；``clean.bat`` 会删除该目录。

**限制（当前）**：无 ``BytesIO``、缓冲层 ``BufferedIOBase``、文本编解码器；``read``/``write`` 块大小受栈缓冲限制（见 ``io.inl``）；无 ``with`` 异常抑制语义。

### 7.4 ``time`` 模块

模块 ``py2cpp/system/time.py``：纯 Python 组合 + ``ffi.crt.time`` / ``ffi.windows.windows``（**无** ``@native`` 业务函数、**无** ``templates/system/-time.inl``）。**无 STL**。

| Python API | C++ 符号 | 说明 |
|------------|----------|------|
| ``time()`` | ``time`` | CRT ``_time64``（经 ``ffi.crt.time.pyiTime64``） |
| ``sleep(secs)`` | ``sleep`` | Win ``Sleep``（``ffi.windows.windows.pyiSleep``）；``secs <= 0`` 无操作 |
| ``monotonic()`` | ``monotonic`` | Win ``GetTickCount64`` |
| ``perfCounter()`` | ``perfCounter`` | Win ``QueryPerformanceCounter``；失败回退 ``monotonic`` |
| ``formatDuration(s)`` | 模块内 Python | ``>=1s`` 秒；否则 ``ms`` / ``us`` / ``ns``（``stopwatch``、``unittest`` 耗时） |
| ``processTime()`` | ``processTime`` | Win ``GetProcessTimes`` |

**导入**：``from py2cpp.time import time, sleep, monotonic, …``（尚未在包根 ``import *`` 重导出）。

**``stopwatch``**（``@context`` 工厂，翻译期展开）：

```python
from py2cpp.time import stopwatch, sleep

with stopwatch("load"):
  sleep(0.1)
# stopwatch load: 100.000ms（过短自动 ms/us/ns）

with stopwatch():  # 或 with stopwatch:
  sleep(0.1)
# stopwatch <with context>: …；@stopwatch 装饰函数时为该函数名
```

``tag`` 默认 ``None``；未传参时用 ``__func__.__name__``。亦可 ``@stopwatch()`` / ``@stopwatch("tag")``。

**限制（当前）**：无 ``time_ns``、时区与 ``tzset``（``CTime`` / ``gmTime`` / ``localTime`` / ``strftime`` 已提供子集）。

## 9. 字符串构建与格式化（禁止 STL 字符串流）

运行时 **不链接 STL**。拼串、格式化应对齐 CPython 的「码点缓冲 + C `printf` 族」思路，**不得**引入 `std::ostringstream`、`std::stringstream`、`std::istream` 或 `std::string` 作为实现手段。

### 9.1 拼串与「流式」写法（Python 侧）

| 场景 | ✅ 推荐（范本） | ❌ 禁止 |
|------|----------------|---------|
| 短拼接、`__str__`/`__repr__` | `out = out + ", "`、`out + repr(x)`（`list.py` / `dict.py`） | 手写 `__add__`；C++ 侧 `ostringstream` |
| 已知总码点数 | 先 `total = ...`，再 `buf: char[:] = new(total)`，循环 `Self._append(buf, at, c)`，最后 `Self(buf)`（`str.join`、`ljust` 等） | `std::string::reserve` + `push_back` |
| UTF-8 写入字节缓冲 | `Self._writeUtf8(buf, at, c)`（`encode` 路径） | `std::ostream` 逐字节写 |
| 反向/复制码点 | `new(n)` + 下标赋值或 `_reverseCodes` | STL 算法头拼串 |
| 分隔符连接 | `join`：两遍扫描（先 `len` 求 `total`，再 `_append`） | 反复 `+` 导致中间临时串过多（大列表应用 `join` 范本） |

「字符串流」在 Py2Cpp 中指 **顺序写入 `char[:]` 或 `PyStr` 拼接**，不是 C++ iostream。

### 9.2 格式化与输出（生成 C++ / 注入实现）

| 机制 | 实现位置 | 说明 |
|------|----------|------|
| `int`/`float`/`bool`/`char` → `str` | 标量 ``__init__`` 为 ``pass``；C++ 由 ``templates/text/+str.inl``（``snprintf`` 构造）注入；``CStr``/``char[:]``/``char`` 在 ``str.py`` | ``char`` 单码点 ``[c]``；标量 ``format`` 见 ``templates/+operators.inl``；``repr``/``%`` 见 ``operators.inl`` |
| ``str`` → ``int`` / ``float`` | ``int(s)`` / ``float(s)`` → ``static_cast<PyInt>`` / ``static_cast<PyFloat>``（``PyStr::operator PyInt()`` / ``operator PyFloat()``，``sscanf``） | JSON 等子集解析复用；勿手写逐字符乘 10 |
| 自定义数字 ``int(x)`` / ``float(x)`` / ``complex(x)`` | 单参数走 ``x.__int__()`` / ``.__float__()`` / ``.__complex__()``；``complex()`` 零/两参数为 ``PyComplex`` 构造 | 译器 pass ``expand_default_numeric_convert``：仅实现较低 dunder 时按 ``__int__`` < ``__float__`` < ``__complex__`` 向下兼容注入默认方法；三者皆无则不注入 |
| `chr` / `ord` | `operators.inl` | ``chr(int)`` → ``PyStr``；``ord('x')`` → ``PyChar``（**仅**单字符字面量，译期折叠）；``char``→整型用 ``int(c)`` |
| ``byte`` | ``byte.h``（``PyByte``） | 单字节注解，与 ``char``（``PyChar`` 码点）区分 |
| ``char`` / ``PyChar`` | ``char.h`` | **struct**（非 ``typedef int32_t``），避免 MSVC 上与 ``PyInt`` 重载合并；可隐式转 ``int32_t`` |
| ``char`` 比较 | 标准库 ``py2cpp/`` | 与码点比较写 ``c == ord('a')``、``c >= ord('0')`` 等，**勿**裸写 ``97``/``65``；**勿** ``ord(变量)``（``S34``）；单字符 ``ord('…')`` 译期内联 |
| `int64`/`float64` | `py_types.h`（`PyInt64`/`PyFloat64`）、`scalar64` 运算符 | 高精度标量；``int64`` 字面量 ``> 2^31-1`` 或注解为 ``int64`` 时生成 ``LL``；``//``/``%``/``/`` 走全局 ``__*__`` |
| `uint`/`uint64` | `py_types.h`（`PyUInt`/`PyUInt64`） | 无符号标量；``uint64`` 字面量生成 ``ULL``；位运算 ``& \| ^ ~ << >>`` 按 C++ 无符号溢出；**不支持**一元 ``-`` 字面量 |
| `"%d" % x`、`str % tuple` | `::__mod__` → `PyStr::percent_format` | **`vsnprintf`** + `va_list`；`PyStr` 经 `PrintfArg` 转 `char*` |
| `str.format` / f-string | `PyStr::format`（``templates/text/+str.h`` 声明 + ``+str.inl`` 实现） | 扫描格式串 + `parts[]` 替换；**非** `std::format` |
| `print(...)` | `translator._emit_print` | 各实参 `str(...)` 后 **`printf`**（仅 C stdio） |
| 调试跟踪 | `debug_cpp.py` | `fprintf(stderr, ...)` |
| 文件读写 | `io.py` / `io.inl` | `fopen` / `fread` / `fwrite` / `fgets` / `fseek`；`StringIO` 用 `char[:]` 下标写入（见 [§7.3](#73-io-模块stringio--文件-io)） |
| 打开文件 | Python `open` → C++ `py_open`（`io` 模块）→ `TextIOWrapper` | 路径经 `PyStr` 转栈上 `char[]`，**非** `fstream` |

新增格式化能力时：优先在 **Python `str.py` 单遍/两遍扫描** 或 **`snprintf`/`vsnprintf` 注入** 中扩展，勿新增 STL 依赖。

### 9.3 与 CPython 行为对齐的检查点

- **不可变**：`PyStr` 修改语义上产生新对象（`__add__`、`replace` 等），与 `unicodeobject` 一致。
- **`%`**：元组右操作数、`%%` 转义、标量走全局 `::__mod__`（见 [参考手册 §8.5](./参考手册.md#85-protocol-与-sfinae-约束)）。
- **搜索**：`find`/`count` 多码点用 KMP（对齐 `stringlib` 思路），勿引入 STL `std::search` 作为运行时依赖。

### 9.4 `@native` 原子化（基础设施）

**原则**：语义以 **Py2Cpp 纯 Python 组合** 为准；``@native`` / ``templates/**``（``+*.inl`` / ``-*.inl``）**仅**加速**不可再拆**的叶子。若某函数可无损写成「纯 Python + 更小的 ``@native``」，则**不得**对该函数标 ``@native``。删掉 C++ 叶子后改调 ``*_ref`` 或同名纯 Python 体，**集成测须仍全绿**（性能可降，行为不降）。

**Codegen 模板**：``templates/**`` + 七宏（``BEGIN`` / ``END`` / ``EVAL`` / ``Exec`` / ``ECHO`` / ``INCLUDE`` / ``TYPE``）；``ECHO`` 由 ``*_gen.py`` 注入片段，叶子 C++ 直接写在模板内。模板手写 C++ 访问 ``@property`` / ``@staticproperty`` / ``postsetter`` 方法名时优先写 ``PY2CPP_GETTER(name)`` / ``PY2CPP_SETTER(name)`` / ``PY2CPP_POSTSETTER(name)``，普通译器生成代码仍输出 ``name__get`` 等实际符号。见 [codegen-templates.md](./codegen-templates.md)。**用户** ``py2cpp/`` 与测试代码**不使用**这些宏。

**C / CRT / 平台 FFI（``.pyi``）**：``ffi/**/*.pyi``（及 ``zeus/ffi/`` 旁路）**一律由生成器产出，禁止手写**。范围 **A+B**：第三方库 + Windows SDK（``ffi/windows/``）+ UCRT/CRT（``ffi/crt/``）；**不含** C++ STL。类型/常量 ``Pyi…``、函数 ``pyi…``，``@native_name`` 钉住真实 C 名。译器按需识别（``from ffi… import 符号`` → ``generated/runtime/ffi/…``，C++ ``ffi::…`` + ``using PyiX = ::X``，见 [c-ffi-pyi.md](./c-ffi-pyi.md)）。须遵守该文档 **§10 命名污染**（禁止 star-import；不进 ``minimal.h``）与 **§11 模板迁移**（组合可留，**禁止** ``templates/**`` 直导 A/B 头；``#include <c_header>`` 仅 ffi glue）。

| 层 | 模块 | ``@native`` |
|----|------|-------------|
| 业务 | ``serde/json`` 等 | **禁止**（只组合基础设施 API） |
| 内存**叶子** | ``util/memory`` | **``copyBuf``、``loadU64Le``、``loadU64LeBytes``** |
| JSON encode**组合** | ``serde/json``（``JsonEncoder`` 静态） | **禁止**（``appendIntAt``、``fastEncode`` 等为纯 Python） |
| JSON decode**组合** | ``serde/json``（``JsonDecoder`` 实例） | ``parseIntAtAscii`` / ``skipWsBound`` / ``loadStrSpanAscii`` / ``strAssignFromSeg`` + ``try_skip_*``；**无** ``json_scan_cpp`` |
| JSON decode**组合** | ``serde/json`` / ``JsonDecoder`` | ``byteAt`` / ``parseIntAtAscii`` / ``skipWsBound`` / ``loadStrSpanAscii`` / ``strAssignFromSeg`` + ``try_skip_*`` |
| ``span``→``str`` | ``text/str`` | **``str.fromSpan``**（``@native``；C++ 见 ``str_span_cpp``） |
| ``char[:]`` 构建 | ``text/str`` | **``str.copyTo``** / **``copySliceTo``** / **``fromBuf``** / **``concat``** / **``replaceSlice``** |
| 文本内核 | ``text/str`` | **允许**（``format``、标量 ``__init__`` 等暂不可 Python 化者） |
| OS/IO/时间 | ``io``、``io/file``、``system/time``、``system/environ`` | **禁止**业务 ``@native``（纯 Python + ``ffi.crt`` / ``ffi.windows``；``util/cbuf`` 共享 C 串缓冲） |

**新增 ``@native`` 前须**：

1. 确认**无法**无损拆成「纯 Python 组合 + 更小 ``@native``」；可拆者写纯 Python，勿标 ``@native``；
2. 每个叶子 ``@native`` 须有 ``foo_ref`` 纯 Python 参照；``test/util/test_memory.py`` / ``test/serde/test_json.py``（memory + scan 段）断言 **叶子 ref 与 native 一致**；
3. ``templates/util/+memory.inl`` 只注入 ``util/memory`` 叶子；**禁止** ``json_scan_cpp`` / ``json_memory_cpp`` 等与 Python 并列的第二套语义。

**范本**：``py2cpp/util/memory.py``（``copyBuf`` / ``loadU64Le*`` 叶子）；``py2cpp/text/str.py``（``copyTo`` / ``fromBuf`` / ``fromSpan``）；``py2cpp/serde/json.py``（``JsonEncoder``/``JsonDecoder``；热路径直调 ``str.copy_*`` / ``str.fromSpan``）。

#### 9.4.1 JSON decode 理想终态（对标 ``util/memory``）

**目标**：``JsonDecoder`` 为**单一语义真相源**（decode 快路径均为其实例/静态方法）；``util/memory`` 的 ``copyBuf`` 等通用叶子加速；**已删除** ``json_scan_cpp.py`` 注入与 ``JSON_DECODER_FAST_IMPL``。

**perf 无损判据**（须保留 C++ 或译器内联补丁，不可整段纯 ``byteAt`` 循环替代）：

| 单元 | 原因 | 形态 |
|------|------|------|
| ``byteAt`` | 零拷贝 ``asciiBytes`` / ``PyChar`` 读字节 | ``@native`` + ``byteAtRef`` |
| ``parseIntAtAscii`` | SwAR 8 位十进制块 | ``@native`` + ``parseIntAtAsciiRef`` |
| ``skipWsBound`` | 8 字节 packed 空白快扫 | ``@native`` + ``skipWsBoundRef`` |
| ``loadStrSpanAscii`` | 无转义引号串 8 字节扫描 | ``@native`` + ``loadStrSpanAsciiRef`` |
| ``strAssignFromSeg`` | Arena + ``copyBuf`` adopt | ``@native`` + ``strAssignFromSegRef`` |

**纯 Python 组合**（无 ``@native``）：``trySkipValueAscii`` / ``trySkipFieldAscii``（``byteAtRef`` + 叶子 ``*_ref``）；``JsonDecoder`` bound / ``load_*`` 循环。

**应迁回 Python（已完成）**：

- ``_*_bound`` 转发 → ``JsonDecoder`` 调 ``scan.*`` 或组合 helper。
- ``tryMatchKey`` → 纯 Python + ``skipWsBound``。
- ``try_skip_*`` → **不得**再为整段 mega-loop 标 ``@native``（C++ skip 引擎已删）。

**``@serializable`` codegen 例外**（类外 static helper，须 public ``scan::`` 叶子）：

- ``scan::parseIntAtAscii``、``scan::strAssignFromSeg``（与 ``scan.py`` ``@native`` 同名）。

**暂不删 / 独立 TU**：

- ``@serializable`` 生成的 ``loadListElement<Cls>`` 模板特化（``serializable`` pass）；可改调 ``scan::parseIntAtAscii`` 等**叶子**，勿与 ``JsonDecoder`` Python 体混语义。

**迁移阶段**（小步 PR，每步 ``bootstrap`` + ``test_json_scan`` / ``test_json`` / ``test_json_serde`` 全绿）：

1. **叶子显式化**（已完成）：五组 ``@native`` + ``*_ref`` 在 ``scan.py``；C++ ``scan.inl`` **仅**注入此五组（+ ``static`` 支撑，无第二套 skip 语义）。
2. **bound / skip 编排 Python 化**（已完成）：``try_skip_*`` 去 ``@native``；删 C++ skip mega-loop；``JSON_DECODER_FAST_*`` 已删。
3. **终局维护**：``@serializable`` 仅直调 public ``scan::`` 叶子；关掉 ``@native`` 后 ``*_ref`` + Python 组合仍全绿（性能可降）。

## 10. 测试代码（`test/`）

测试源码同样遵守本规范，并作为可编译的用法示例。业务断言写在 **测试类** 里，不要堆在 `main` 中。

### 10.1 必须：`unittest` 结构

`build_all.bat` 编译的 **`test/**/test_*.py`**（**跳过** ``test/fail/``、``test/perf/``、``*_fail.py``）**不得**只写 ``main() -> int``，用 ``if`` / ``return`` 错误码或 ``print`` 充当测试结果。须使用仓库内轻量 ``unittest``（``py2cpp/test/unittest.py``），与 ``test/util/test_list.py``、``test/text/test_str.py`` 一致：

```python
from py2cpp import *
from py2cpp.test.unittest import TestCaseMixin, TestSuite, TextTestRunner

class DictLiteralTests(TestCaseMixin):
  _testTag = 28   # 分组 / 排序（各文件内自定，保持递增即可）

  @override
  def test(self):
    d: dict[int, int] = {1: 10, 2: 20, 3: 30}
    self.assertEqual(len(d), 3)
    self.assertTrue(2 in d)
    self.assertFalse(99 in d)

def main():
  suite: TestSuite = new()
  for Class in TestCaseMixin.iterSubclasses(sortConst="_testTag"):
    suite.addTest(Class())
  return TextTestRunner().run(suite)
```

``TestCaseMixin.iterSubclasses()`` / ``iterSubclasses(sortConst="_testTag")`` 由 ``@mixin``（``py2cpp/reflect/mixin.py``）提供，仅在**翻译期**展开：收集本文件内 ``class …(TestCaseMixin)`` 宿主；无 ``sortConst`` 时按声明顺序，指定时 ``sortConst`` 须与 ``static const`` 成员名一致（如 ``_testTag``），按该字段**升序**（同键保持声明顺序）。展开为 ``suite.addTest(makeRefCount<…>())``，无运行时反射（不会内联到各测试类）。

| 要求 | 说明 |
|------|------|
| **测试类** | 每个场景一个 ``TestCaseMixin`` 子类；可按 API 拆多个类（见 ``test_containers.py``） |
| **用例方法** | 固定 ``@override def test(self):``，**不要**另起名 ``test_foo``（当前 runner 只调 ``test``） |
| **断言** | 用 ``self.assertEqual`` / ``self.assertTrue`` / ``self.assertFalse`` 等；类内用 ``==`` / ``in``，**不**写 ``self.__contains__`` |
| **`main`** | **仅**组装 ``TestSuite``、``addTest`` / ``iterSubclasses`` 循环、``TextTestRunner().run(suite)`` 并 **return** 退出码；**禁止**在 ``main`` 里写业务 ``if`` 断言 |
| **耗时** | ``verbosity >= 1`` 时每条 ``PASS``/``FAIL`` 打印用例耗时；汇总区打印整次 ``suite.run`` 总耗时（``time.perfCounter``） |
| **导入** | 标准库类型（``list``/``dict``/``deque``/``str``/``StringIO``/``open`` 等）统一 ``from py2cpp import *``（``__init__.py`` 末尾 re-export + ``__all__``）；**勿**在包根另建 ``deque.py``/``str.py`` 等转发模块，**勿**在 ``test/`` 使用 ``typing`` |
| **构造** | 空容器 ``[]``/``{}``；用户类（含 ``TestSuite``）用 ``suite: TestSuite = new()``，勿 ``TestSuite()``；关键字赋字段用 ``new(w=1, …)``（§2.2）；``@dataclass`` 位置参数仍可用 ``Point(3, 4)`` |
| **拷贝** | ``@copyable`` 写 ``b2: T = b``，不写 ``T(b)`` / ``__copy__`` |
| **协议调用** | ``next(g)``、``assertTrue(obj)`` / ``assertFalse(obj)``，不写 ``__next__`` / ``__bool__`` |

**目录**（与 ``py2cpp/`` 域对齐，见 ``test/__init__.py``）：

| 路径 | 内容 |
|------|------|
| ``test/text/`` | ``str``、``bytes``、``format`` |
| ``test/util/`` | ``list``、``dict``、``deque``、``set``、``range``、``Arena``、``Pool``、``misc`` |
| ``test/io/`` | ``StringIO``、``open``、``Path`` |
| ``test/io/file/`` | ``io/file``、``io/file/path``（``os`` / ``os.path`` 子集） |
| ``test/system/`` | ``time``、``datetime`` |
| ``test/math/`` | ``math``（``sqrt[float64]``/``hypot``/``float64.Inf``/``float64.isInf`` 等；默认标量为 ``float``；``from py2cpp.math import …``）；``random``（``Random[Scalar]``；MT19937；``py2cpp.math.random``） |
| ``test/serde/`` | ``json``、``JsonDocument`` |

## 11. 反模式速查

| 反模式 | 后果 / 替代 |
|--------|-------------|
| `std::stringstream` / `std::ostringstream` / `std::string` 拼串 | 违反无 STL 约定；用 `char[:]` + `_append` 或 `out = out + ...` |
| `self.__contains__(k)` | 生成错误或非惯用 C++；用 `k in self` |
| 同类 `new()` | 应译成 `Self()` |
| 测试里 `Cls(a, b)` 关键字构造 | 用 `b: Cls = new(a=…, b=…)` |
| 测试里 `dst = Cls(src)` / `dst.__copy__(src)` | `@copyable` 用 `dst: Cls = src` |
| 测试 `main` 里 `TestSuite()` | `suite: TestSuite = new()` |
| `field()` / `@autoinit` | 已移除；用类体默认值 + `@dataclass` / 手写 `__init__` |
| `list()` 空列表 | 用 `[]` |
| `g.__next__()` / `f.__bool__()`（测试） | 用 `next(g)`、`assertTrue(f)` |
| `list[T](a,b,c)` | 不支持；用 `[a,b,c]` |
| 裸 `[a,b]` 表达式 | 须赋值或注解推断类型 |
| 裸 `new(n)` | 编译失败；加 `char[:]` 等注解 |
| `str("x")` 造字面量 | 用 `"x"` |
| `test/**/test_*.py` 仅 `main` + `return` 错误码 | 违反 §10.1；用 `TestCaseMixin` + `TextTestRunner` |
| 忘记 `@immutable` 于只读方法 | C++ 非 `const`，接口质量差 |
| `dict` 默认拷贝不清理桶链 | 必须在 `__copy__` 中 `_clearEntries` 再重建 |
| 堆节点未标 `@boxing` | 可能生成栈上值类型；节点类必须 `@boxing` |
| `@boxing` 与 `@copyable` / `@refcount` 同用 | 分析阶段报错；三选一 |
