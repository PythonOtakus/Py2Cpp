## 1. 项目是什么

**Py2Cpp** 将受限子集的 **Python 3** 源码 **静态翻译** 为 **C++11** 可执行程序或目标文件。

| 特点 | 说明 |
|------|------|
| 标准库 | 用 Python 写在 `py2cpp/*.py`，与用户代码 **一起翻译**，不是链接手写 C++ 运行时 |
| 运行时 | **不依赖 STL**；容器、字符串、引用计数等均在生成代码中 |
| 执行模型 | **无 CPython 解释器**；无反射、无 `eval`、无动态 `getattr`（仅编译期可折叠的静态反射） |
| 目标 | 嵌入式/性能敏感场景，用 Python 写逻辑、用 C++ 跑 |

示例入口：

- `examples/example.py` — `str` + `unittest` 回归
- `examples/example2.py` — `@mixin`、`@descriptor`、`@refcount`、`Vector2` 等
- `test/**/test_*.py` — 标准库与语言特性回归（`build_all.bat` 递归编译，跳过 `test/fail/` 与 ``*_fail.py``）
  - **`test/<域>/`**：与 ``py2cpp/<域>/`` 对齐（``text`` / ``util`` / ``io`` / ``system`` / ``serde`` / ``core`` / ``design`` / ``alg`` / ``misc`` 等）
  - **`test/lang/`**、**`test/import_tests/`**：语言特性与专项
  - **`test/perf/`**：性能（默认不进 ``build_all.bat``）
  - **`test/lang/`**：生成器、协程、`@protocol`、`@dataclass`、`@enum` / `@union`、`__dunder__`、`__moved__`、``select`` 路径选择等
  - **`test/util/`**：``Pool`` 等（``test_pool.py``）
  - **`test/import_tests/`**：``import`` / 相对路径
- `test/lang/test_protocol.py` + `test/fail/test_*_fail.py` — `@protocol` 正向 / 负向（`build_protocol.bat` / `build_fail.bat`）

## 2. 架构与目录

```
Py2Cpp/
├── main.py                 # CLI：翻译 + 可选编译（``from src import Translator``）
├── scripts/                # MSVC / 翻译构建脚本（见 scripts/README.md）
│   ├── _bootstrap_runtime.bat  # 重生成 generated/runtime（build*/demo 共用）
│   ├── build_all.bat      # 先 bootstrap，再递归 test/**/test_*.py
│   ├── build.bat          # 先 bootstrap，再按 PATTERN 匹配子集
│   ├── build_protocol.bat
│   └── build_fail.bat
├── build_all.bat          # 转发 → scripts\build_all.bat
├── ffi.bat                 # 第三方 C 头 → ``ffi/**/*.pyi``（见 [c-ffi-pyi.md](./c-ffi-pyi.md)）
├── ffi/                    # FFI 声明面（``sqlite/``、``windows/``、``crt/`` 等；**生成器产出，勿手改**；译器按需 import）
├── src/                    # **Python→C++ 译器**（勿与标准库包 ``py2cpp/`` 混淆）
│   ├── translator.py       # AST → C++ 主访问器
│   ├── compile.py          # ``-c`` 编译；``test/`` 默认不链 ``py2cpp.cpp``
│   ├── constant/           # 静态表：模块/类/方法名、布局、umbrella、FFI、inject、mixin…
│   │   ├── stdlib_layout.py    # 逻辑模块路径 / 命名空间 / `STR_PYSTR` 等
│   │   ├── ffi_layout.py       # ``ffi/**/*.pyi`` → ``generated/runtime/ffi/``；``using Pyi_X = ::X``
│   │   └── mixin.py            # @mixin 方法名契约
│   ├── tools/c_ffi_pyi.py  # libclang → ``ffi/**/*.pyi``（``ffi.bat``）
│   ├── analysis/           # 类型分析、IR、import 发现、命名空间（含 ``runtime_symbols``、``stubs/``）
│   ├── passes/             # 预处理：dataclass、enum、mixin、generator、decorator、move_state…（``selector_parse`` 为 path DSL 解析，非 AST pass）
│   ├── emit/               # 生成：``call_emit``、``selector_emit``、``ffi_glue_emit`` 等
│   ├── codegen/            # 模板展开、umbrella_gen、protocol_traits_gen、delegate_gen…
│   └── tests/              # 译器单元测试（``python -m unittest src.tests…``）
├── py2cpp/                 # **标准库 Python 规格**（与用户代码一并翻译）
│   ├── __init__.py         # 包根：类型标记、装饰器桩、``range``/``new``/``len``/``print`` 等
│   ├── core/               # exceptions、protocols、refcount、result、object、delegate
│   ├── util/               # list、dict、set、deque、tuple、array、pool、slice、range…
│   ├── text/               # str、bytes
│   ├── io/                 # StringIO、open；``io/file``（原 ``os`` / ``os.path``）
│   ├── system/             # time、environ、datetime
│   ├── concur/             # Task / parallel / thread
│   ├── serde/              # json、document
│   ├── sql/                # protocols + sqlite（DB-API；ORM 规划中）
│   ├── web/                # socket / http / client / server（含 async）
│   ├── ui/                 # window / panel / flow…
│   ├── alg/ math/ numeric/ spatial/ design/ weak/
│   ├── test/               # unittest
│   └── reflect/            # mixin 等（``reflect/mixin`` 通常**不**参与 bootstrap）
├── ffi/                    # 第三方 C FFI ``.pyi``（生成器产出；见 [c-ffi-pyi.md](./c-ffi-pyi.md)）
├── templates/              # C++ 注入 / 万能头模板
├── examples/               # 用户示例 .py
├── test/                   # 集成测试（翻译 + MSVC + 轻量 unittest）
├── generated/              # 默认输出（可 -o 覆盖；**勿手改**）
│   ├── runtime/py2cpp/     # 标准库 ``*.h`` / ``*.inl`` / ``minimal.h`` / ``protocol_traits.h``
│   ├── runtime/ffi/        # FFI 按需生成（**不**进 ``minimal.h`` bulk）
│   ├── runtime/py2cpp.cpp  # 可选汇总 TU（bootstrap 时；**测试链接默认不用**）
│   └── <源路径>/           # 用户/测试模块 .h / .cpp / .exe（镜像源目录）
└── docs/                   # 本文件、编码规范、[c-ffi-pyi.md](./c-ffi-pyi.md)、[selector.md](./selector.md) 等
```

**命名三层**（接手时最易混）：

| 层 | 路径 / import | 含义 |
|----|----------------|------|
| 译器 | `src/`、`from src import Translator` | Python→C++ 实现 |
| 标准库规格 | 仓库 `py2cpp/`、`import py2cpp` | 待翻译的标准库 Python 源码 |
| 生成物 | `generated/runtime/py2cpp/` | C++ 头文件与 ``namespace py2cpp::…`` |
| FFI 声明 | `ffi/**/*.pyi` → `generated/runtime/ffi/` | ``ffi.bat`` 生成；模块级 ``Pyi_*``；C++ ``ffi::…`` + ``using Pyi_X = ::X``；sqlite 自动 glue；见 [c-ffi-pyi.md](./c-ffi-pyi.md) |

**标准库域布局**（自 2026 起取代扁平 ``builtins/``；**无**向下兼容旧路径）：

| 域目录 | 典型模块 | C++ 命名空间（示例） |
|--------|----------|----------------------|
| `core/` | `protocols`、`exceptions`、`refcount` | `py2cpp::core::protocols::…`；`tuple`/`delegate`/`refcount` 等见 [§5.2](#52-泛型pep-695) 全局特例 |
| `util/` | `list`、`dict`、`set` | `py2cpp::util::list::PyList`；``set`` → 段名 **`py_set`**（MSVC 与 ``<set>`` 冲突） |
| `text/` | `str`、`bytes` | `py2cpp::text::str::PyStr` |
| `io/` | `io`、`io/file`、`io/file/path` | `py2cpp::io::…` |
| `system/` | `time`、`environ`、`datetime` | `py2cpp::system::…` |
| `concur/` | `task`, `parallel`, `thread` | `py2cpp::concur::task::…`、`py2cpp::concur::thread::…` |
| `serde/` | `json` | `py2cpp::serde::json::…` |
| `sql/` | `protocols`、`sqlite` | `py2cpp::sql::…`（ORM 规划中） |
| `web/` | `socket`、`http`、`client`、`server` | `py2cpp::web::…` |
| `ui/` | `window`、`panel`、`flow`… | `py2cpp::ui::…` |
| `alg/` / `math/` / `numeric/` / `spatial/` / `design/` / `weak/` | 域内模块 | `py2cpp::<域>::…` |
| `test/` | `unittest` | `py2cpp::test::unittest::…` |

包根 ``py2cpp/__init__.py`` 通过 ``from .core import *``、``from .util import *``、``from .text import *`` 等再导出 ``list``/``str``/``dict`` 等，并 re-export ``open``/``StringIO``（见 ``__all__``）；**不**在包根保留 ``str.py``/``list.py`` 转发文件。C++ 侧仍按 **import 闭包** 拉 ``io.h`` 等（``from py2cpp import *`` 并不等于万能头自动 include 全部子模块）。

**三阶段流水线**（权威顺序以 `src/translator.py` 为准；完整表见 [§4](#4-翻译流水线)）：

1. **解析**：`ast.parse` → 收集类（`ClassInfo`）、模块函数、常量  
2. **预处理 / 后检**：`expand_dataclass` → `expand_enum` / `expand_union` → … → **S38 / `check_yield_from_in_async_def`** → **`expand_generators`**（须在 `expand_decorators` 之前）→ … → `SemanticAnalyzer` → **`check_parallel_loops`** / **`check_moved_use`** 等  
3. **生成**：输出 `.h`、`.cpp`、`.inl`；bootstrap 时写 ``py2cpp/minimal.h``；用户入口可选 ``main()`` 包装

## 3. 快速开始

### 环境

- **Python 3.10+**（用于跑翻译器；与 PEP 695 泛型语法兼容）
- **C++ 编译器**：MSVC（Windows 推荐）、或 g++ / clang++（`--compiler` 指定）
- Windows 可用 `build_example.bat` 自动调用 `vcvars64.bat`

### 翻译

```bash
python main.py examples/example.py -o generated
```

生成：

- `generated/examples/example.h`
- `generated/examples/example.cpp`
- `generated/runtime/py2cpp/`（标准库头文件与实现）

### 翻译并编译

```bash
python main.py examples/example.py -o generated -c --compiler cl --exe generated/examples/example.exe
# 或
build_example.bat
generated\examples\example.exe
```

标准库与语言特性回归：

```bat
build_all.bat
build_all.bat --debug
generated\test\misc\test_containers.exe
generated\test\misc\test_strings.exe
```

`build*.bat` / `demo.bat` 会先经 ``scripts/_bootstrap_runtime.bat`` 翻译 ``py2cpp/__init__.py`` 生成完整 ``generated/runtime/``（同一 cmd 进程内只跑一次），再编译匹配用例；生成物路径与源路径对应（如 ``test/util/test_pool.py`` → ``generated/test/util/test_pool.exe``）。`build_all.bat` 额外参数中的 ``--debug`` 等原样传给各测试的 `main.py`（runtime 侧若需 ``--debug``，可 ``scripts\_bootstrap_runtime.bat --debug``）。**用例须按 [编码规范 §10.1](./编码规范.md#101-必须unittest-结构) 写 ``unittest``（``TestCaseMixin`` + ``TextTestRunner``），不得仅在 ``main`` 里写 ``if`` 断言；``test/lang/test_empty_main.py`` 为唯一允许的纯 ``main`` 冒烟例外；``test/lang/test_protocol.py`` 亦同。

**链接模型（测试）**：每个 `test_*.cpp` 通过 `#include "py2cpp/minimal.h"` 拉入标准库 `*.inl` 实现，**默认不再**链接 `runtime/py2cpp.cpp`（避免与头文件内联实现 **LNK2005** 重复定义）。标准库**非模板模块自由函数**与类方法一并写入对应 `*.inl`（`system/time` 等含 C 注入的模块：先粘贴 `TIME_IMPL` / `OS_*_IMPL`，再译 Python 体）。标 **`@native`** 的自由函数只生成 `.h` 声明，**不**向 `.inl` 写入 Python 函数体（实现由 `templates/**` 的 `+*.inl` / `-*.inl` 注入，如 `py_time`、`py_open`）。bootstrap 时的 `py2cpp.cpp` 仅为占位/历史汇总 TU（无函数体时几乎为空），**勿**与测试 TU 同时链接。

协议约束（SFINAE）回归：

```bat
build_protocol.bat
```

- `test/lang/test_protocol.py`：`ComparableType` / ``ArithmeticType`` / ``numbers`` 约束应 **编译通过**
- `test/fail/test_protocol_fail.py`：不满足 `ComparableType` 的类型应 **编译失败**（无匹配 `sorted` 重载）
- `test/fail/test_py2cpp_getattr_fail.py` / `test_py2cpp_getattr_multi_site_fail.py` / `test_py2cpp_call_fail.py`：宏派发失败应出现带 **`file:line:`** 前缀的 **`编译期: PY2CPP_GETATTR` / `PY2CPP_CALL` 的 `static_assert` 中文文案**
- `test/fail/test_generic_protocol_fail.py`：不满足 `AppendableType` 的泛型调用应 **编译失败**（`Appendable_requires` SFINAE）

### 常用 CLI 参数

| 参数 | 含义 |
|------|------|
| `-o DIR` | 输出根目录（默认 `generated/`） |
| `--no-stdlib` | 不嵌入标准库（仅翻译用户文件） |

| `--exe PATH` | 可执行文件路径 |

## 4. 翻译流水线

预处理 / 分析顺序以 `Translator.translate_file`（`src/translator.py`）为准。下表按**阶段**摘要（Agent 查阅表：[`.cursor/skills/py2cpp-design/reference.md` §2.1](../.cursor/skills/py2cpp-design/reference.md#21-passessrcpasses顺序不可乱)）。

| 阶段 | Pass（摘） | 作用 |
|------|------------|------|
| 前检 | `check_s32_*` / `check_s44_*` | dataclass 必填、注解标记 |
| 展开 | `expand_dataclass` → `expand_class_id` → `expand_enum_mro` / `expand_union_mro` → **`expand_enum`** → **`expand_union`** → `expand_serializable` | 数据类 / 枚举（[§8.2.2](#822-enum)）/ 联合 / 序列化；dataclass：`[]`/`{}` 默认进 `__init__` 体、`@optional` 不进形参、自动 `__post_init__` |
| | `check_native_function_bodies` → `expand_default_iter` → `expand_descriptors` → `expand_mixins` → `expand_proxy` → `expand_class_type_base` | `@native` 体须 `...`；描述符 / mixin / proxy |
| | `expand_field_properties` / `expand_property_value_references` | 字段 `@property` |
| | `expand_default_bool` → `expand_default_numeric_convert` → `expand_default_ne` | 默认协议（[§7.7](#77-默认-bool--iter)；跳过 `@union` / `@enum`） |
| | `expand_test_discovery` → `expand_kwargs_options` → `expand_static_reflect` | 测试发现；`**kwargs` / `assign`（`select` 见 [§7.9](#79-select译期路径选择)）；静态反射 |
| 生成器前 | **`check_yield_from_for_style`（S38）** → **`check_yield_from_in_async_def`** | 须在 **`expand_generators` 之前** |
| | **`expand_generators`** | `yield` → `*_generator`；`async def` → `coroutine_desugar` 再 `*_coroutine`（**须在** `expand_decorators` **之前**） |
| | `expand_decorators` → `check_noexcept_functions` → `expand_copyable` → **`expand_move_state`** | `@decorator` / `@context`；copyable；`__moved__` |
| | `expand_protocol` → `expand_member_access` → **`expand_descriptor_signatures`** → `expand_lazy_params` → `expand_final_ctor_inits` | 协议 / 访问 / 描述符签名（[§8.2.3](#823-descriptor)） |
| 分析 | `SemanticAnalyzer` | 类型、`MethodSig`、头依赖（含打破 `str`↔容器循环） |
| 后检 | `check_proxy_*` / `resolve_union_*` / `check_*_rules` / `check_*_style` / **`check_parallel_loops`** / **`check_moved_use`** | 静态约束（含 `prange`）；移动后再用（跳过标准库） |
| 生成 | `_emit_all` 等 | 写 `.h` / `.inl` / **`minimal.h`**；`@enum` → `enum_emit`；生成器 `__next__` → `generator_emit`；描述符 helper **先于**调用方（`_module_functions_emit_order`） |

**重要**：`.py` 标准库文件 **不会在 CPython 下作为运行时执行**；它们只是翻译器的 AST 输入。在 CPython 里 `import py2cpp.test.unittest` 并实例化，行为与翻译结果 **不一致**（例如 `TestCaseMixin.run` 依赖混入展开）。

## 5. 类型系统

### 5.1 基本映射

Python 源码中仍写 `list`、`str` 等；生成 C++ 时通过 `CPP_RENAME`（`analysis/ir.py`）映射为 `Py*` 前缀类型，避免与 C++ 关键字/STL 冲突。

| Python（注解/用法） | C++（生成名） |
|---------------------|---------------|
| `int` | `PyInt` |
| `int64` | `PyInt64`（`int64_t`；大整数字面量生成 ``LL`` 后缀） |
| `float` | `PyFloat` |
| `float64` | `PyFloat64`（`double`） |
| `bool` | `PyBool` |
| `char` | `PyChar`（Unicode 码点，非 UTF-8 字节） |
| `CStr` | `const char*` |
| `Pointer[T]` | `T*` |
| `T @ref` | `T&`（可变引用；``from py2cpp import ref``） |
| `name: T @property` | 只读 ``<name>__get()``（类体字段；用内建 ``property`` 作 ``T @property`` 标记）；存储字段 ``<name>__value``；getter/setter 内 ``self.__value__`` 指该字段 |
| `@property` / ``@property.setter`` | 译为 ``<name>__get()`` / ``<name>__set(…)``；``self.__value__`` 指存储字段 ``<name>__value``（描述符 / 字段 property 同规则，见 §描述符） |
| `@property.postsetter` / ``@staticproperty.postsetter`` | 类型由 ``value: T`` 推断；合成 ``<name>__get()`` / ``<name>__set(…)``（赋值后调 ``<name>__postset(…)``）；可写字段简写 ``name: T @property.postsetter(cb, …) = …``（``cb`` 为字段/方法/``Self.…``，可多参）；与 getter/setter 及同名字段简写/方法互斥 |
| `@staticproperty` / ``@staticproperty.setter`` | 译为 ``static <name>__get()`` / ``static <name>__set(…)``；``Self.__value__`` 指 ``static`` 存储 ``<name>__value`` |
| `name: T @const = v` | 类级 ``static constexpr`` |
| `name: T @final` / `name: T @final = v` | 实例 ``const`` 成员；``__init__`` 内 ``self.f = …`` → C++ 构造初始化列表；不可 ``assign`` / ``new(kw=…)`` 事后赋值；不支持 ``T @property @final`` |
| `@final class` | C++ ``class … final``；不可继承 |
| `@final def`（单独 ``@final`` 或 ``@override`` + ``@final``） | C++ ``virtual … final`` / ``override final``；不可覆盖；勿与 ``@virtual`` 同标（**S39**） |
| `@abstract def`（体须 ``...``） | C++ ``virtual … = 0``；隐含 ``virtual``；``.inl`` 无实现；仍含纯虚方法的类不可 ``new()`` |
| `name: T @optional = v` | 不进 ``__init__`` / ``assign`` / ``__cmp__`` 字典序 |
| `list[T]` | `PyList<T>` |
| `dict[K, V]` | `PyDict<K, V>` |
| `set[T]` | `PySet<T>`（C++ 命名空间 `py2cpp::util::py_set`，避免与 `std::set` 冲突） |
| `frozenset[T]` | `PyFrozenSet<T>` |
| `frozenlist[T]` | `PyFrozenList<T>`（与 `list` 同模块 `util/list.py`） |
| `frozendict[K, V]` | `PyFrozenDict<K, V>`（与 `dict` 同模块 `util/dict.py`） |
| `tuple[T, U, …]` 或 `(T, U, …)` | `PyTuple<T, U, …>`（括号形式为类型简写；单元素须 `(T,)`） |
| `slice[int, int]` 等 | `PySlice<…>` |
| `bytes` | `PyBytes` |
| `@refcount` 类 `T`（存储上下文） | `PyRefCount<T>`；源码写裸 `T`，勿 `RefCount[T]`（**S31**）；``list[Node]`` 等模板实参在 ``Node`` 为 ``@refcount`` 类时译为 ``PyRefCount<Node>``（与 ``T: refcount`` 约束无关） |
| `@boxing` 类 `T`（存储上下文） | ``T*``；``list[Cell]`` / ``Pool[Cell]`` 等对 ``@boxing`` 类模板实参译为 ``Cell*``（与 ``T: boxing`` 约束无关） |
| `IterResult[Y, R]` | `PyIterResult<Y, R>`（`@union`：`Yield` / `Return`；`done` / `value` / `returnValue` 属性） |
| `@enum class E` / `@enum class E(int64)` | C++11 ``enum class E : PyInt`` 或 ``enum class E : PyInt64``；成员 ``E.MEM`` → ``E::MEM``（见 [§8.2.2](#822-enum)） |
| `IteratorType[T]` | **协议**（`@protocol`）；不生成 `class IteratorType`；具体类型为各类 `*_iterator`（见 [8.5](#85-protocol-与-sfinae-约束)） |
| `T[:]` / `array[T]` | `PyArray<T, 0>`（默认纯堆；见 `util/array.py`） |
| `array[T, StackLength]` / `list[T, StackLength]` | `PyArray<T, _StackLength>` / `PyList<T, _StackLength>`；类内 `static constexpr PyInt StackLength = _StackLength`；`StackLength=0` 纯堆，`StackLength>0` 内联 SSO（``_stack`` / ``_ptr`` 在 ``PyArray`` 内） |
| `T[:N]`（`N` 为正整数字面量；**推荐**） | 栈定长 `PyStackArray<T, N, 0>`（拥有 `N` 个元素）；可用 `= […]` 初始化（`len([…])` 须为 `N`，否则翻译失败） |
| `T[i:j]`（`i`、`j` 为整数字面量） | `PyStackArray<T, j-i, i>`；`s[k]` 为绝对下标 `k∈[i,j)` |
| `buf[i:j]`（`buf` 为 `T[:N]`） | `PyArray<T>`（`_getslice`，堆拷贝） |
| `s.view` / `s.view[i:j]`（`s` 为 stack/array/list） | `PySpan<T>`（相对下标；切片规则同 `list`） |
| `Optional[T]` / `T \| None`（注解） | `PyOptional<T>`（**勿**再译为 `T*` 可空指针） |
| `Result[T, E]` | `PyResult<T, E>`（`@union`：`Ok` / `Err`；`ok` / `value` 属性；``-> None`` 成功载荷为 ``PyNone``） |
| `span[T]` | 单泛型视图 `PySpan<T>`（与 `T[i:j]` 注解无关） |
| `T[:,:]` | `PyArray2D<T>` |
| `T[:,:,:]` | `PyArray3D<T>` |

### 5.2 泛型（PEP 695）

类与函数可使用 **PEP 695** 语法，例如：

```python
class list[T]:
  ...

def alloc[T]() -> Pointer[T]:
  ...
```

翻译为 C++11 模板 `template<typename T> class list { ... };`。

**类形参默认值（PEP 696）**：类头 ``class Counter[K: DictKeyType, C: IntegralType = int]`` 在 C++ 声明处生成默认模板实参，例如 ``template<typename K, typename C = PyInt> class Counter``。注解与用法侧 ``Counter[str]``、``Counter[str, int]`` 仅写出**已给出的**实参，译为 ``Counter<PyStr>``、``Counter<PyStr, PyInt>``；**不在**类型分析阶段为省略的形参补默认类型——由 C++ 模板默认值在实例化时补齐（与 ``type Counter[T] = dict[T, int]`` 别名侧 ``Counter<PyStr>`` 一致）。

**非类型模板形参（Py2Cpp 扩展）**：类头 ``class ModInt[T: IntegralType, Mod: T]`` 中第二形参 ``Mod`` 的约束为**已声明的类形参名** ``T``（非 ``@protocol``）时，译为 C++ NTTP ``template<typename T, T Mod>``；实例化 ``ModInt[int, 1000000007]`` → ``ModInt<PyInt, 1000000007>``。类体内 ``Mod`` 为编译期常量；不同 ``Mod`` 的 ``ModInt`` 混用由模板实参不匹配在 MSVC 编译期拒绝。

**``oneof[…]`` 析取约束（Py2Cpp 扩展，非 CPython）**：``T: oneof[char, byte]`` 表示 ``T`` 须为列出的**具体类型之一**（与 ``A & B`` 交集约束正交，可写 ``T: DictKeyType & oneof[int, str]``）。译为 ``static_assert(std::is_same<T, PyChar>::value || …)``。``@mixin`` 混入 ``Mixin[char]`` 等具体实参时，约束检查落在宿主类（如 ``str(StringMixin[char])`` 校验 ``char ∈ oneof[char, byte]``）。

**泛型类型条件（Py2Cpp 扩展，非 CPython）**：在 **PEP 695 泛型函数/方法** 体内存在对**模板形参**的编译期类型 ``if``/``elif``/``else`` 链时，译为 C++11 分派 struct（``std::enable_if`` / 全特化），**整段函数体**（含 ``for``、链前/链后语句）进入各特化的 ``static __call__``；外层模板函数仅 ``return _pick<T, void>::__call__(…);``。**不是**运行时 ``if``：

| Python | 说明 |
|--------|------|
| ``if T is int:`` | ``T`` 与 ``PyInt`` 等具体 C++ 类型匹配 |
| ``elif T is list[...]:`` | 容器模式：``...`` 表未知类型实参，译为部分特化 ``template<typename _Ty0> pick<PyList<_Ty0>, void>``；分支内取元素类型用 ``T.Element``（非 CPython） |
| ``elif T is dict[str, ...]:`` | 多实参容器同理；``...`` **仅**出现在 ``T is …`` 右侧类型模式 |
| ``elif T is not int:`` | 仅作**首分支**，且须配合 ``else`` |
| ``elif T in [str, bool]:`` | 多类型析取；元素须为具体类型（builtin / ``list[int]`` 等），**不可**含 ``...`` |
| ``elif T not in {int, float}:`` | 否定成员；须写 ``T not in``，勿 ``not T in`` |
| ``else:`` | 默认分支；**无 ``else``** 时生成 ``static_assert`` 编译失败 |

**每条泛型函数/方法至多一条类型 if 链**；链可出现在 ``for`` / ``while`` 等**普通**语句块内（链前后可有其它语句），整段函数体剪枝进 ``__call__``。**暂不支持**（未来可能扩展，当前译器硬错误）：同一函数内**多条平行**类型链；**链套链**（外类型链某分支 / ``else`` 内再写类型链——多路分派请写一条 ``if/elif/else``）。**不支持**：``not T is int``（须写 ``T is not int``）；``T is list[T]`` / ``T is ...`` / ``list[_]`` 等下划线通配（未知实参须写 ``list[...]``、``dict[K, ...]`` 等）；链内值条件；非法类型链（不静默回退）。

典型写法：

```python
def tag[T](x: T) -> int:
  if T is int:
    return 1
  elif T in [str, bool]:
    return 2
  else:
    return 0

def tally[T]() -> int:
  n: int = 0
  for i in range(3):
    if T is int:
      n += 1
    elif T is str:
      n += 2
  return n
```

``Json.loads`` 分派示例（标准库 ``py2cpp/serde/json.py``）：

```python
@staticmethod
def loads[T](s: str) -> T:
  dec: JsonDecoder = JsonDecoder.fromText(s)
  ...
  if T is list[int]:
    out = _json_read_list_int(dec)
  elif T is list[...]:
    out = _json_read_list_serializable[T.Element](dec)
  elif T is dict[str, ...]:
    out = _json_read_dict_serializable[T.Value](dec)
  else:
    out = _json_loads_generic[T](dec)
  ...
  return out
```

``Json.load`` 为 Python 一行委托（``TextIOWrapper`` / ``StringIO`` 重载，与 ``dump`` 对称）：

```python
@staticmethod
def load[T](fp: TextIOWrapper) -> T:
  return Json.loads[T](fp.read())
```

实现见 ``src/passes/type_if.py``；集成测 ``test/lang/test_type_if.py``。

**预编译宏条件（Py2Cpp 扩展，非 CPython）**：``if "NAME" in __macro__:`` / ``elif "NAME" not in __macro__:`` / ``else:`` 译为 C 预处理器 ``#ifdef`` / ``#elif defined`` / ``#else`` / ``#endif``，用于跨平台分支（如 ``_WIN32``、``__linux__``）。**不是**运行时 ``if``；``__macro__`` **不可**作普通 ``in`` 容器。

| Python | C++ |
|--------|-----|
| ``if "_WIN32" in __macro__:`` | ``#ifdef _WIN32`` |
| ``if "_WIN32" not in __macro__:`` | ``#ifndef _WIN32`` |
| ``elif "X" in __macro__:`` | ``#elif defined(X)`` |
| ``elif "X" not in __macro__:`` | ``#elif !defined(X)`` |
| ``else:`` | ``#else`` |

宏名须为**字符串字面量**且为合法 C 宏名；否定须写 ``"NAME" not in __macro__``（**不支持** ``not "NAME" in __macro__``）；``elif`` 须继续 ``in __macro__`` / ``not in __macro__``（不可与普通条件混写）。分支体内可嵌套另一条 macro if。实现见 ``src/passes/macro_if.py``；集成测 ``test/lang/test_macro_if.py``。

**``type`` 别名**（Python 3.12+）：类内 `type Element = T` → C++ `using Element = T;`，注解保留 `Element`。模块/类内泛型别名 `type Counter[T: DictKeyType] = dict[T, int]` → `template<typename T, DictKey_requires<T> = 0> using Counter = PyDict<T, PyInt>;`。别名形参上的协议约束仅当该形参出现在 `=` 右侧时生效；`type Element[E: ComparableType] = T` 中未使用的 `E` 会被忽略。`@protocol` 类中的别名在分析时展开到底层形参。详见 [编码规范 §6.2](./编码规范.md#62-类内-type-别名)。

#### 5.2.1 条件类型与类型萃取（Py2Cpp 扩展，G1 已实现）

> **完整规格与命名规范**：[type-conditional.md §3](./type-conditional.md#3-标准库范本别名与命名规范)。

PEP 695 条件别名：**捕获** ``_V = ...`` + **类型三目** ``_V if T is list[_V] else T``，编译期展开用于注解。

```python
type ListElemOf[T, _V = ...] = _V if T is list[_V] else T
type ValOf[T, _V = ..., _W = ...] = (
  _V if T is list[_V]
  else _W if T is dict[str, _W]
  else T
)
```

| 概念 | 说明 |
|------|------|
| 命名 | 统一 ``{Role}Of[T]``；捕获 ``_X = ...``（**须下划线前缀**） |
| ``_V = ...`` | 捕获形参；调用时不传 |
| ``else T`` | 恒等回退；``ListOnly`` / ``else Never`` 为严格变体 |
| **type if** | 体内 ``T.Element`` / ``T.Value``；注解用 ``ListElemOf[T]`` / ``ValOf[T]`` |
| **T.Element** | 与 ``ListElemOf`` 在 list 解包上等价（分派 vs 别名） |

**``...`` 三义**：协议 ``type Element = ...`` ≠ 捕获 ``_V = ...`` ≠ type if ``list[...]``。详见 [type-conditional.md §5](./type-conditional.md#5--的三义须区分)。

实现分期（G0 ``Never`` → G1 条件别名 → G2 注解三目 → G3 ``Pick``/``Extract``）见 [type-conditional.md §8](./type-conditional.md#8-实现分期)。

### 5.3 类型注解要求

- 类字段、方法参数与返回值 **建议写注解**；分析器据此生成 C++ 签名。
- **缺少注解时的 C++ 类型**见 [§5.3.1](#531-缺少注解时的-c-类型策略)：函数形参**多数**为 ``T0``/``T1`` **模板形参**，**不是**一律 ``void*``；``int``/``void*`` 主要用于**类字段**与少数兜底。
- **不支持** 运行时 `typing`、Union 动态分发、`Any` 的完整语义。
- **元组类型简写**：注解中的 `(T, U)` 与 `tuple[T, U]` 均译为 `PyTuple<T, U>`；单元素类型须写 `(T,)`（逗号不可省）。仅用于**类型位置**，与运行时元组字面量 `(a, b)` 语法形式相同、语义由上下文区分。

#### 5.3.1 缺少注解时的 C++ 类型策略

实现见 ``src/analysis/ir.py``（``FuncTypeParams``、``INT_FIELDS``、``PROTOCOL_PARAM_ERASE``）与 ``analyzer.py``（``_param_cpp_type``、``_field_cpp_type``）。

**易混概念（请先读）**

| 误解 | 实际 |
|------|------|
| 「无注解形参 → `void*`」 | 普通无注解形参 → **`T0`、`T1`…** + ``template<typename T0, …>``（``FuncTypeParams.collect``） |
| 「`T0` 就是 `void*`」 | ``T0`` 是**未约束的模板类型形参**；``void*`` 是**具体指针类型**的兜底 |
| 「PEP 695 头里的 `ItL` 会绑定 `left`」 | **不会**。须写 ``left: ItL``；否则 ``left`` 仍是 ``T0``（与 ``ItL`` 无关） |
| 「`x: ComparableType` 会擦成 `void*`」 | 译为 ``template<typename T0, Comparable_requires<T0> = 0>`` + 形参 ``T0`` |
| 「模板 void 必须写 ``-> None``」 | **不必**。无 ``return expr`` 时（普通 / 模板方法均同）自动 ``void``；``-> None`` 可选 |
| 「无注解形参 + 无 ``->`` → 返回 ``T0``」 | **不会**（已修）。旧版误推 ``T0`` → MSVC **C4716**；现无 ``return expr`` 时统一 ``void`` |

**1）函数 / 方法形参**

| Python 写法 | 生成的 C++ 形参类型 | 说明 |
|-------------|---------------------|------|
| ``def f(a, b)``（无 PEP 695、无协议注解） | ``T0 a, T1 b`` + 函数模板 | 每个无注解形参独占 ``Tn`` |
| ``def f[T: ComparableType](x: T)`` | ``T x`` + ``Comparable_requires<T>`` | 约束来自 **PEP 695 头** |
| ``def f(x: ComparableType)`` | ``T0 x`` + ``Comparable_requires<T0>`` | 约束来自 **形参注解** |
| ``def f(xs: IterableType[T])`` 且头上有 ``[T]`` | ``T xs`` + ``Iterable_requires<T>`` | 子脚本中的 ``T`` 须与头/类形参同名 |
| ``def f[Node: DictKeyType](nav: NavigatableType[Node], …)`` | ``T0 nav`` + ``Navigatable_requires<T0, Node>`` + ``DictKey_requires<Node>`` | **参数化协议推荐**：头上仅关联形参 ``Node``；``nav`` **另增** ``T0``，**不复用**未写约束的占位名 |
| ``def walk(nav: NavigatableType[Cell], …)``（无头） | ``T0 nav`` + ``Navigatable_requires<T0, Cell>`` | ``Cell`` 为具体类型；仅 ``T0`` 进 ``template_names`` |
| ``def f[Nav: NavigatableType[Node], Node: DictKeyType](nav: Nav, …)`` | ``Nav nav`` + ``Navigatable_requires<Nav, Node>`` | 约束写在头上 |
| ``def zip[ItL, ItR](left: ItL, right: ItR)`` | ``ItL left, ItR right`` + 协议约束 | **推荐**：可迭代对象在函数体内 ``iter(left)`` |
| ``def zip[ItL, ItR](left, right)``（无注解） | ``T0 left, T1 right``（**错误用法**） | 头里的 ``ItL``/``ItR`` **不**替代 ``left``/``right`` |
| ``self`` | （实例方法隐式 ``this``） | 不参与 ``FuncTypeParams`` |
| 默认值为 ``None`` 的形参（如 ``key=None``） | 常落到 **`void*`** | ``arg_has_none_default`` 跳过模板分配 |
| ``__copy__`` / ``__move__`` 的 ``other`` | ``const Cls&`` / ``Cls&`` | 专门规则，非 ``Tn`` |
| ``def f(*args: int[:])`` | ``PyArray<PyInt> args`` | **整包**堆数组；与单形参 ``xs: int[:]`` 相同；``f()`` → ``f(PyArray<PyInt>())``；多位置实参 IIFE 打包（同 ``[]`` 字面量初始化） |
| ``def f(a: int, *rest: int[:])`` | ``PyInt a, PyArray<PyInt> rest`` | 定参后的额外位置实参打进 ``rest`` |
| ``*args: int``（非 ``T[:]``） | — | **翻译报错** |
| ``*args`` 无注解（如 ``print`` / ``new`` 桩） | — | 不启用本规则（仍走既有内建/未实现路径） |
| ``*args`` 后的 ``kwonlyargs`` | — | **暂不支持** |
| ``f(3, *a, 4, *b, 5)``（``def f(*nums: T[:])`` 或 ``def g(x: int, *rest: T[:])``） | 定参 + IIFE 拼接整包 | 可变段内标量与 ``*T[:]`` 变量可任意交错；单段 ``*本函数args`` 或单段 ``*变量`` 仍直传整包 |
| ``inner(*nums)``（本函数 ``*nums: T[:]`` → callee 同位置 ``*…: T[:]``） | ``inner(nums)`` | **整包转发**；``nums`` 须为当前函数可变参数名；类型须一致；**不可** ``inner(*nums)`` 传给仅有普通定参的 callee |
| 关键字与位置段混用时的 ``*``、``**kwargs`` 泛化 | — | **暂不实现**；与 ``**options: Opt``（``expand_kwargs_options``）可并存 |

**2）类字段（无类型注解时）**

| 条件 | C++ 类型 | 来源 |
|------|----------|------|
| 字段名 ∈ ``INT_FIELDS``（``_index``、``_length``、``_capacity`` 等，见 ``ir.py``） | ``PyInt`` | ``_field_cpp_type`` 启发式 |
| 其它未注解字段名 | **`void*`** | 同上 |
| ``__init__`` 中 ``self.f = 整数字面量`` | ``PyInt`` | 赋值推断 |
| ``self.f = None`` | **`void*`** | 赋值推断 |
| ``self.f = 带注解的形参`` | 跟形参类型 | 赋值推断 |
| 有 ``f: T`` 类体注解 | 按注解翻译 | 正常路径 |

**3）其它 `void*` / `int` 兜底**

| 场景 | 类型 |
|------|------|
| ``__next__`` 等无返回注解且推不出元素类型 | ``PyIterResult<…>`` 中可能为 ``void*`` |
| 模块级 ``static const`` 无注解 | 默认 **`int`** |
| ``@delegate`` 形参未进入 ``arg_types`` | **`void*`` |
| 代码生成取不到 ``param_types[name]`` | 默认 **`void*`` |

**4）函数 / 方法返回类型（``_return_type_parts`` / ``_method_return_parts``）**

实现见 ``ir.py`` 的 ``IMPLICIT_VOID_DUNDER_METHODS`` / ``is_void_return_annotation``，以及 ``analyzer.py`` 的 ``_return_type_parts``、``_method_return_parts``、``_expr_for_decltype``。

**总则**（含无注解形参 ``T0``… 的模板函数 / 方法，及 PEP 695 头）：

| Python 写法 | 生成的 C++ 返回类型 | 说明 |
|-------------|---------------------|------|
| ``def f() -> int: return 1`` | ``PyInt`` | 显式 ``-> T`` |
| ``def f(x): return x + 1`` | ``auto`` + ``decltype(…)`` | 体含可翻译的 ``return expr`` |
| ``def replaceAt(self, steps, value):``（无 ``return expr``） | ``void`` | 普通 / 模板方法均自动推断；**勿**写 ``-> None``（可选，同 ``void``） |
| ``def __setattr__(self, name, value):`` | ``void`` | **隐式 void dunder**（见下表），译器固定 ``void`` |

**隐式 void dunder**（``IMPLICIT_VOID_DUNDER_METHODS``，勿写 ``-> None``）：``__init__``、``__del__``、``__copy__``、``__move__``、``__exit__``、``__post_init__``、``__setitem__``、``__setattr__``、``__delattr__``、``__delitem__``、``assign``。

**译期专用方法**（``TRANSLATOR_ONLY_METHODS``，**非** dunder、**无** C++ 成员）：``assign``（见 [§6](#64-内置函数由翻译器识别) / [编码规范 §7.4](./编码规范.md#74-kwargsoptions关键字选项)）、``select``（见 [§7.9](#79-select译期路径选择)）、``build``（见 [§7.10](#710-build译期对象构造)）。**S33** 禁止类方法 / 属性 / 字段与之同名；就地拷贝用 ``copyFrom`` / ``copyFromSpan`` 等。

**历史问题（已删除）**：旧版在仅一个 ``Tn`` 且无 ``return expr`` 时误把返回类型设为 ``T0`` → ``T0 replaceAt(…)`` + MSVC **C4716**。现：有 ``return expr`` → ``decltype``；无 ``return expr`` → ``void``（与是否模板无关）。

模块级 / 类方法在无 ``->``、体无 ``return expr`` 且未命中专用规则时，``function_return_parts`` / ``_method_return_parts`` 兜底为 ``void``。

**书写建议**：有 ``return expr`` 的模板 API 可省略 ``-> T``，由 ``decltype`` 推导；void 副作用方法无需 ``-> None``（隐式 void dunder 亦同）。需要协议约束时用 ``def f[T: Protocol](…)`` 或 ``arg: IterableType[T]``；**参数化**协议（``NavigatableType[Node]``）优先 ``def f[Node: DictKeyType](nav: NavigatableType[Node], …)``（见 [编码规范 §6.4](./编码规范.md#64-参数化协议navigatablenode-等)）。``--strict`` **S19** 禁止头上未使用的 PEP 695 形参。

| 常量 | 值 | 含义 |

| `SliceStartUnset` | `-2000000001` | 切片起点省略 |

### 5.5 构造与字面量约定

标准库与用户代码推荐按下列规则书写；翻译器在 **有类型上下文** 时展开为对应 C++ 构造。

| 场景 | Python 写法 | 说明 |
|------|-------------|------|
| **字符串** | `"hello"`、`""` | 直接写引号字面量；**不要** `str("hello")` / `new("")`（除非无注解的复杂场景） |
| **元组值** | `(a, b)`、`(0,)` | 运行时元组字面量；**不要** `tuple[int, int](a, b)` |
| **元组类型** | `(int, int)`、`(K, V)` | 与 `tuple[int, int]` 等价；单元素类型写 `(T,)` |
| **列表** | `x: list[T] = [a, b]`、`[a, *xs, b]`、`[]` | 带元素类型注解；`*iter` 展开为 ``append`` 循环 |
| **字典** | `d: dict[K,V] = {}`、`{k: v, ...}`、`{**d, k: v}` | 空字典 `{}`；键值对 `__setitem__`；`**` 映射用 ``update`` |
| **集合** | `s: set[T] = set()`、`{a, b}` | 空集合须 ``set()``；**`{}` 是 dict**；元素须满足 ``DictKeyType`` |
| **不可变集合** | `fs: frozenset[T] = {a, b}`、`frozenset()`、`frozenset(lst)`、`frozenset(src)` | 字面量经临时 ``set`` + ``initFromSet``；无 ``add``/``insert_new`` 等可变 API |
| **异类 / 数组** | `x: T[:] = new(n)` | `new` 由左侧注解推断类型，等价于 `T(...)` |
| **用户类关键字** | `obj: Cls = new(w=1, h=2)` | ``@dataclass`` / 选项类：``Cls()`` + 字段赋值；与 ``Window(w=1)``（[编码规范 §7.4](./编码规范.md#74-kwargs-options-关键字选项)）一致 |
| **本类实例** | `Self()`、`Self(x)` | 当前类方法体内构造 **与类相同** 的类型；**不要** `new()` |
| **`@copyable` 拷贝** | `dst: T = src` | 拷贝构造；测试与用户代码**勿** ``T(src)`` / ``dst.__copy__(src)``（``__copy__`` 仅写在类实现内） |
| **裸 `new(...)`** | — | 报错：有类型上下文时写 ``… = new(...)`` / ``return new(...)``；无法推断时写 ``Cls(...)``（勿 ``x: T = new(...); … = x``） |
| **类体成员默认值** | `buf: char[:] = new(0)`、`buckets: Entry[:] = new(cap)` | 左侧**字段注解**提供类型上下文；生成成员初值 ``PyArray<…>(0)`` 等（``_emit_field_default_initializer`` → ``_emit_new_ctor_expr``）。**勿**在类体裸写 ``new()`` 无注解字段；``@dataclass`` 的 ``= []``/``= {}`` 仍在 ``__init__`` 体内初始化（见 [§7.6](#76-静态类成员与字段默认值)） |

`new` 定义于 `py2cpp/__init__.py`，仅为翻译期桩；常见用法：

```python
buf: char[:] = new(n)          # → PyArray<PyChar>(n)
buf: char[:] = new(0)          # 类体字段默认 → 成员 ``_buf = PyArray<PyChar>(0)``
items: list[PyStr] = new()     # 若在本类 list 内 → Self()；异类注解 → PyList<PyStr>()
b: CopyableBox = new(w=10, h=20)  # @dataclass + @copyable → CopyableBox() + 字段赋值
b2: CopyableBox = b            # → CopyableBox b2 = b（拷贝构造）
out: str = ""                   # → PyStr("")
shape: (int, int) = (r, c)       # 类型简写 → PyTuple<PyInt, PyInt>(r, c)
```

`list` 内新建列表、空列表乘法等标准库实现使用 `Self()`；`str` 空串一律 `""` / `return ""`。

### 6.2 `for` 循环形式

| 形式 | 支持 |
|------|------|
| `for i in range(...)` | ✅ 直译为 C++ ``for (int i = start; …; i += step)``（**不**构造 ``PyRange``） |
| `for x in iterable`（`__iter__`/`__next__`） | ✅；含 ``r = range(n); for x in r``（``PyRange`` + 迭代器） |
| `for i, x in enumerate(...)` | ✅；**索引内联**（见下） |
| `for a, b in zip(...)`（固定元组目标） | ✅ |
| `for k in dict`（键迭代） | ✅（`dict` 迭代器） |
| `for` 目标解包 / `*star` | ❌ 或极有限 |
| 列表/字典字面量内 `*` / `**` 解包 | ✅ | `x: list[T] = [a, *it, b]` 按可迭代 ``append``；`d: dict[K,V] = {**other, k: v}` 用 ``update`` |

**``enumerate`` 索引内联**（``translator._for_enumerate`` / ``_index_for_loop_plan``）：当可迭代对象支持 ``__len__`` + ``__getitem__(int)``（``list``、``str`` 切片结果、``PyStackArray``、``reversed(…)`` 包裹的同类容器等）时，

```python
for i, x in enumerate(seq, start)
```

译为原生索引循环（``for (PyInt fi = 0; fi < seq.__len__(); …)`` + ``int i = start + fi`` + ``x = seq.__getitem__(…)``），**不**构造 ``EnumerateIterator`` / 每步 ``PyTuple``。推导式中的 ``for i, x in enumerate(…)`` 走同一策略（``emit_index_enumerate_for_from_iter``）。仅当无法索引化时才退回 ``EnumerateIterator<T>`` + ``while`` + ``template get<0/1>()``。回归：``test/util/test_list.py``（``enumerate`` / 推导式）及 ``serde`` 等路径。

| 字典推导 | ✅ | 与字面量同映射注解：`dict[K,V]` / `Counter[…]` / `frozendict[K,V]`（后者临时 ``dict`` + ``initFromDict``）；``for … in range(...)`` 原生 ``for``；其余 `for`/`if` 限制同列表推导 |
| f-string / `JoinedStr` | ✅（编译期展开为 `printf` 或 `str.format` 计划） |
| 嵌套 `def` 闭包 | 📋 已定案 | 见 [§6.6](#66-global--nonlocal--嵌套-def-闭包)；**非** ``lambda`` 完整闭包 |

### 6.6 `global` / `nonlocal` / 嵌套 `def` 闭包

**状态**：设计定案，译器待实现。完整规格见 [closure.md](./closure.md)。

| 能力 | 说明 |
|------|------|
| **`global x`** | ``x`` 须已有模块级 ``x: T = ...``；读写 lowering 为模块 C++ 变量；无 prior 注解 → 翻译期错误 |
| **`nonlocal x`** | 绑定最近 enclosing 函数中的 ``x``（capture 引用） |
| **嵌套 ``def inner``** | 形成 ``PyCallable<Ret, Args...>``；形参与模块级 ``def`` **同规则**（默认实参、``**kwargs: Options``、``@lazy``、``[*Ts]`` / pack、``@overload`` 等） |
| **`f = inner`** | 推断 ``PyCallable<...>``，与 ``inc = lambda x: …`` 一致；可显式 ``Callable[[…], R]`` |
| **自引用** | ✅ ``def fact(n): … fact(n-1) …`` |
| **类内 + ``self``** | capture 等价委托 ``lambda`` 的 ``[this]`` |
| **``lambda``** | 不在此特性范围；仍仅 §7.4 |
| **逃逸 lifetime** | ``return inner`` / 存容器 **暂按 C++ lambda 引用捕获**；勿跨 defining 栈帧调用（首期无 heap cell） |

```python
_total: int = 0

def make_adder(seed: int) -> Callable[[int], int]:
  base: int = seed

  def add(x: int, default: int @lazy = 0) -> int:
    nonlocal base
    global _total
    _total += 1
    return base + x + default

  return add
```

## 7. 类、方法与运算符

### 7.1 类定义

```python
class MyClass(Base):
  _tag: int @const = 1   # 类体常量 → C++ static const int _tag = 1
  field: int = 0          # 实例字段默认值（非 static const）
  other: int              # 实例字段（``@dataclass`` 生成 __init__ 或手写 __init__ 中赋值）

  def __init__(self): ...

  @virtual
  def foo(self) -> int: ...

  @override
  def bar(self) -> None: ...
```

| Python | C++ |
|--------|-----|
| `@virtual` | `virtual` 成员函数 |
| `@abstract` | `virtual … = 0`（纯虚；体须 ``...``） |
| `@override` | `override` |
| `@immutable` | `const` 成员函数 |
| `@noexcept` | C++ ``noexcept``；函数体顶层 ``raise`` → ``Result::Err``、``return`` → ``Result::Ok``；对外 ``PyResult<T,E>``（``E`` 由 ``raise`` 静态收集）；``try`` 内 ``raise`` 仍 ``throw`` |
| `@native` | 模块级函数或**整类**：仅声明，实现由 C++/`templates/**`（`+*.inl` / `-*.inl`）写入同模块 ``.inl``；函数/方法体统一 ``...``（勿 ``pass``/``return`` 占位）。``@native`` 类（如 ``TextIOWrapper``）所有方法均须 ``...``，``.inl`` 不写 Python 体 |
| 无 `@refcount` / `@boxing` | 普通 C++ 类（值语义或栈上构造） |
| `@boxing` | 堆上单对象；`T(...)` / `T<Args>(...)` → `new T<...>(...)`；`Pointer<T>` + `destroy`/`free` 管理 |
| `@refcount` | 堆对象 + `PyRefCount<T>`；`T()` → `makeRefCount<T>(...)` |

#### `super` / `Super` / `Proxy[T]`

实体类（``@entity`` / ``@union`` 等带 ``type __base__ = …`` 的类）在方法体内可用 ``super`` 调用基类实现：

| Python | C++（普通继承） | C++（``Proxy[T]`` 族） |
|--------|-----------------|------------------------|
| ``super.foo(...)`` | ``Base::foo(...)`` | ``this->_target.foo(...)`` |
| ``super().foo(...)`` | 译前须 ``__base__`` 定义 ``__call__``（``super()`` ≡ ``super.__call__()``）；C++ 仍 ``Base::foo(...)`` | 同上 |
| ``super.__init__(...)`` | ``Base::Base(...)`` | ``this->_target.Base(...)`` |

- **类型注解** ``Super`` 严格等于该类的 ``type __base__`` 别名（``void`` 时不可用）。
- **``super()`` / ``super.__call__()``** 在任何上下文中始终等价，且要求 ``__base__`` 类**已定义** ``__call__`` 方法；否则翻译失败。``super.foo(...)``（无括号）不经过 ``__call__``。
- **禁止** ``super().__init__(...)``；须写 ``super.__init__(...)``（``super()`` 仅表示 ``__call__``，不用于构造基类）。
- **不支持** CPython 两参 ``super(type, obj)``；**不支持** ``Proxy[Proxy[T]]``。
- 回归：``test/lang/test_proxy.py``。

### 7.1.1 命名与访问级别（PEP 8 约定）

| Python 命名 | C++ 默认 | 说明 |
|-------------|----------|------|
| `name` | `public` | 对外 API |
| `_name` | `protected` | 单前导下划线：子类 / 本类 `self` 可访问 |
| `__name`（非 dunder） | `private` | 双下划线：名称改写为 `_ClassName__name` |
| `__init__` 等 dunder | `public` | 特殊方法始终在 `public` |

**跨类访问**：若成员仅在本类/子类内通过 `self._x`（或 `other._x` 等同类实参）使用，则 C++ 为 `protected` 且保留 `_x` 命名。若在**其它类**或**模块级函数**里出现 `obj._x`，**翻译失败**并提示改为公开名（去掉一个前导 `_`）或改为仅类内访问；不会在翻译期自动改名。标准库已按此规则调整（如 `str.data`、`deque.head`、`TestResult.printFailedDetails`）。

类头文件中按 `public` → `protected` → `private` 分段声明字段与方法。

### 7.2 特殊方法与 dunder 映射

翻译器识别 `DUNDER_METHODS`（见 `analysis/patterns.py`），包括但不限于：

`__init__`, `__del__`, `__len__`, `__getitem__`, `__setitem__`, `__iter__`, `__next__`, `__contains__`, `__bool__`, `__str__`, `__repr__`, `__cmp__`, `__add__`, `__sub__`, `__mul__`, `__rmul__`, `__truediv__`, `__floordiv__`, `__mod__`, `__neg__`, `__pos__`, `__copy__`, `__move__`, `__reversed__`

**二元/一元 dunder → C++ `operator`**（`src/emit/dunder_ops_emit.py`）：

- 类内实现 `__add__` 等时，在类声明中自动生成对应 `operator+` 等（`@immutable` 方法生成 **const** 运算符）。
- 若类已实现 **`__cmp__`**，不再重复生成 `==` / `<` 等六个比较运算符（避免与 `__cmp__` 推导重复）。
- **`__mod__`**、非 `const` 的 dunder **不** 自动生成 `operator`（`str.__mod__` 仍为模板成员）。

**`__str__` / `repr` / `str()`**：

- 容器与用户类实现 `__str__` 时，头文件声明 `operator PyStr() const;`，**实现**在 `.inl` / `.cpp`（避免 `str.h` 未完成时内联）。
- `str(x)` 译为 `static_cast<PyStr>(x)`（有 `operator PyStr()` 时）或 `PyStr(...)` 构造；**`@enum`** 用 `{E}PyStr` 包装 + `static_cast<PyStr>`；**不**生成全局 `::__str__`。
- `repr(x)` 译为 `::repr(x)`（`operators.h` / `operators.inl`：标量特化 + 模板转发 `obj.__repr__()`；`repr(self)` → `this->__repr__()`）。
- 标准库内格式化用 **`str(item)`** / **`repr(k)`**（容器键等标量键用 `::repr(k)`，勿对 `PyInt` 调 `.__repr__()`），勿假设存在全局 `__str__`。

**`__int__` / `__float__` / `__complex__` / 数值构造**：

- 类实现对应 dunder 时，头文件声明 `operator PyInt()` / `operator PyFloat()` / `operator PyComplex<…>() const;`，**.inl** 内联 `{ return __int__(); }` 等。
- **`PyStr`**（`text/str`）无 `__int__`/`__float__` 成员，但声明 `operator PyInt()` / `operator PyFloat()`（`sscanf` 解析，原 `py_int_from_str` / `py_float_from_str` 逻辑）。
- `int(x)` / `float(x)` / `complex(x)`（单实参且可转换时）译为 **`static_cast<PyInt>`** / **`static_cast<PyFloat>`** / **`static_cast<PyComplex<…>>`**，**不**在调用点生成 `x.__int__()` 等。
- 标量 `complex(real)` / `complex(real, imag)` 仍走 `PyComplex<…>(…)` 构造。

**`__next__` 约定**（与 CPython 不同）：

- Python 源码仍写 `raise StopIteration` 或 `return value`。
- C++ 生成 **`PyIterResult<Y, R>`**（`Yield` / `Return` 变体；`done` 属性）；`done == true` 表示结束。
- `for` 循环由翻译器展开为对 `PyIterResult` 的检查。

**`str` / `list` 切片**：`s[i]`、`lst[i]` → `__getitem__`；`s[a:b:c]`、`lst[a:b]` → `__getitem__(PySlice<...>(...))`（`list` 切片返回新 `PyList`）。同名 `__getitem__` / `__delitem__` 等须 **全部** 标 `@overload`（见 [8.4](#84-overload)）。

**多维下标**：`a[i, j]`（`array2d` 等）→ `__getitem__(PyTuple<PyInt, PyInt>(i, j))`。

### 7.3 `__cmp__` 与比较运算符

类实现 **`__cmp__(self, other) -> int`**（返回 `PyInt`）时，翻译器在类声明中自动生成：

| C++ | 语义 |
|-----|------|
| `operator==` | `__cmp__(other) == 0` |
| `operator!=` | `!= 0` |
| `operator<` / `<=` / `>` / `>=` | `< 0` / `<= 0` / `> 0` / `>= 0` |

约定与 Python 2 风格三值比较一致：负表示 `self < other`，零表示相等，正表示 `self > other`。

- **`PyStr`**、**`PyList<T>`** 已实现 `__cmp__`（码点/元素逐字比较，不等长时先比公共前缀再比长度）。
- 勿再单独写 `__eq__` 映射；统一用 `__cmp__` 即可得到 `==` 与排序比较。
- `print` 对 `PyStr` 会走 `PrintfArg(s).data`（`fprintf` 变参须 `char*`）。

### 7.4 多播委托（`@delegate`）

```python
from py2cpp import delegate, Callable, Function

@delegate
def FuncDelegate[T](x: T) -> T: ...

d: FuncDelegate[int] = new()
d += _inc              # 自由函数 → PyCallable{ _closure=fn, _func=py_callable_free_invoke::call }
d += self.apply        # 实例方法 → PyCallable{ _closure=this, _func=Class_apply_py_callable_thunk }
d += Cls.static_fn     # 静态方法 → PyCallable{ _closure=&Cls::static_fn, _func=py_callable_free_invoke::call }
d += lambda x: x + 1   # C++ lambda 对象 → PyCallable{ _closure=&obj, _func=py_callable_lambda_invoke::call }
inc = lambda x: x + 1  # 赋值为 Callable 变量；d += inc / d -= inc 直接比较 PyCallable
```

就地 ``d += lambda …`` 每次生成新 ``PyCallable`` 字面量，**不能**用 ``d -= lambda …`` 注销；须先 ``inc = lambda …``（变量类型为 ``Callable`` / ``PyCallable``），再 ``+=`` / ``-=`` 同一变量。

| Python | C++ |
|--------|-----|
| `@delegate` 定义（名须 ``*Delegate``，见编码规范 S47） | 继承 ``Delegate``（C++ ``PyDelegate<Ret, Args...>``；见 `src/codegen/delegate_gen.py`） |
| `d += f` / `d -= f` | `operator+=` / `operator-=`（`PyList<PyCallable<Ret, Args...>>`） |
| `d(args)` | 多播：每个槽位 ``handler(args…)``（``PyCallable::operator()``）；返回 **最后一次** 调用的结果 |
| `Function[[A], R]` | C 函数指针 ``R (*)(A)``（如 `list.sort(key=)`） |
| `Callable[[A], R]` | 可绑定槽位 ``PyCallable<R, A>``（`_closure` + `_func`；``__call__`` / ``operator()`` 转发 ``_func``） |
| `slot(args)` / `f(x)` | ``Callable`` 变量：``PyCallable::operator()(…)`` / ``__call__(…)`` |

用户自定义委托类写入入口模块 `.h`；``Delegate`` 基类（C++ ``PyDelegate``）经 `minimal.h` 聚合，无需单独 `#include "py2cpp/delegate.h"`。

``@delegate`` 类型作函数形参时按**非 const 引用**传递（``FuncDelegate<T>&``），以便在 callee 内 ``+=`` / ``-=`` 修改调用方实例。``Callable``（``PyCallable``）槽位可按值传递。类字段 ``handler: FuncDelegate[T]`` 上 ``handler += f`` / ``d += box.slot``（``slot: Callable[…]``）与局部变量相同。回归：``test/core/test_delegate.py``。

### 7.5 赋值与拷贝语义

| 写法 | 语义 |
|------|------|
| `a.__copy__(b)` | 类**实现**内显式深拷贝（如 `dict.__copy__`）；**测试/用户代码勿调用** |
| `dst: T = src`（`@copyable`） | 拷贝构造 / `operator=`（``str``、``@dataclass`` 等） |
| `dst: T = src`（标准库容器） | **移动** ``__move__``；``src`` 置空且 ``__moved__=True``；副本用 ``.copy()`` |
| 移动后再读 ``src``（非 ``src.__moved__``） | **翻译期报错**（``check_moved_use``）；运行期 ``_ensureActive`` 仍兜底 |
| `T(src)`（测试） | ❌ 勿用；容器用 ``dst = src.copy()``，``@copyable`` 用 ``dst: T = src`` |
| `c = b`（其它类） | 若存在 ``__move__`` 则移动，否则按字段生成 |
| `@refcount` 赋值 | 引用计数拷贝（`PyRefCount`） |
| `+b`（一元） | `@copyable` 类的拷贝构造 |
| `a, b = b, a + 1` / `xs[i], xs[j] = xs[j], xs[i]` | 右值各元素先求值到临时变量，再写入左值（``emit_parallel_tuple_assign``）；``PyTuple`` 返回值解包同理 |

### 7.6 静态类成员与字段默认值

| 类体写法 | C++ |
|----------|-----|
| `name: T = v`（无 `@const`） | 实例字段；`v` 为 **``@dataclass`` / 手写 ``__init__``** 的默认值，**不**生成 `static const` |
| `name: T = new(...)` | 成员初值：用字段类型 ``T`` 展开 ``new``（``char[:] = new(n)`` → ``PyArray<PyChar>(n)``）；**不是**无上下文 ``visit(new)`` |
| `name: T @const = v`（`v` 为 `int`/`float`/`bool` 字面量） | `static constexpr T name = v;` |
| `name: T @optional = v` | 可选实例字段；**不**进入 ``@dataclass`` 生成的 ``__init__`` / ``assign`` 形参 |

```python
from py2cpp import const

class Mixin:
  _testTag: int @const = 0

class Tests(Mixin):
  _testTag = 1   # 覆盖混入 → static const int _testTag = 1;
```

访问：`self._testTag` → `ClassName::_testTag`。

**``@dataclass`` 与 ``new``**：可变默认 ``items: list[int] = []`` / ``list[int] = new()`` 在 ``expand_dataclass`` 中从类体去掉并在 ``__init__`` **体内**初始化（不进 C++ 构造形参）；``field_defaults`` 同步 ``pop``，避免生成阶段对 ``ast.List`` 做 ``visit``。``new(...)`` 且注解为**非容器**用户类（如 ``style: UIStyle = new()`` / ``new(fontSize=11)``）则进入 ``__init__`` **形参**默认（C++ ``UIStyle style = UIStyle(…)``，关键字与目标类 ``__init__`` 形参表对齐）。类体若写 ``_buf: char[:] = new(0)``（如 ``JsonEncoder``），保留在成员声明阶段用字段类型展开。

### 7.7 默认 `__bool__` / `__iter__`

用户模块类在预处理阶段可自动补全协议（``passes/default_bool.py``、``passes/default_iter.py``；详见 [编码规范 §4.1.1](./编码规范.md#411-翻译期默认协议expand_default_bool--expand_default_iter)）。

| 机制 | 条件 | 行为 |
|------|------|------|
| **默认 ``__bool__``** | 未实现 ``__bool__`` | 无 ``@immutable`` ``__len__`` → 恒真；有则 ``return self.__len__() > 0`` |
| **`explicit` 构造** | 用户类 ``__init__`` / 默认构造 / generator 补出的 ``Foo()`` | 声明 ``explicit Foo(…);`` / ``explicit Foo();``；**拷贝/移动构造不加** ``explicit`` |
| **`explicit operator PyBool()`** | 类体有 ``__bool__``（含上表注入） | 生成 ``explicit operator PyBool() const { return __bool__(); }``；``if obj`` / ``assertTrue(obj)`` → ``static_cast<PyBool>(obj)`` |
| **`explicit operator PyInt()` 等** | 类体有 ``__int__`` / ``__float__`` / ``__complex__`` / ``__str__``（含 ``expand_default_numeric_convert`` 注入） | 生成对应 ``explicit operator Py*()``；``int(x)`` / ``float(x)`` / ``complex(x)`` / ``str(x)`` → ``static_cast<Py*>(x)`` |
| **`PyStr` 数值 operator** | ``text/str.PyStr`` | 声明 ``explicit operator PyInt()`` / ``explicit operator PyFloat()``（``sscanf``）；``int(s)`` / ``float(s)`` → ``static_cast`` |
| **默认 ``__iter__``** | ``__getitem__(int)`` + ``@immutable`` ``__len__``，且无 ``__iter__`` | 生成 ``{Host}_iterator`` + ``__iter__`` → ``return new(self)``（``0..len-1`` 下标，同 ``ListIterator``） |

**真值条件特例**：``PyRefCount<T>`` → ``(rc)``；``@boxing`` 的 ``T*`` → ``(ptr != nullptr)``；标量 ``int``/指针按 C++ 规则。

**``and`` / ``or``**：非 ``&&``/``||`` 布尔链；例如 ``a and b`` → ``(truthy(a) ? b : a)``，保留对象返回值。

回归：`test/util/test_list.py` 等` 中 ``ThreeInts``、``EmptySeq``（``DefaultSeqIterTests``）。

### 7.8 编译期成员派发（``PY2CPP_GETATTR`` / ``PY2CPP_SETATTR`` / ``PY2CPP_CALL``）

当译期**无法可靠选定** ``.`` 或 ``->``（未绑定 ``ClassInfo``、模板形参、复杂表达式、推断为 ``auto`` 等），读/写/调用走 ``member_access.h``（``src/codegen/member_access_cpp.py`` → ``generated/runtime/py2cpp/member_access.h``，经 ``minimal.h`` include）。**已知类型**（``self``、注解形参、``self`` 上已解析字段）仍直出 ``get_<attr>()`` / ``this->field->m()``。

| 条件 | 生成形态 | 示例 |
|------|----------|------|
| 成员访问不确定 | ``PY2CPP_GETATTR`` / ``SETATTR`` / ``CALL`` | 未注解模板形参 ``node.parent``；链式中某级类型未知 |
| 接收者为**当前函数的模板形参**（``T0`` 等）且函数带 ``template`` | 同上（必走宏） | ``def read_any(node): return node.parent`` |
| 接收者类型已知 | ``get_<attr>()`` 或 ``.``/``->`` 直发 | ``def read_typed(node: Node): return node.parent`` → ``node.get_parent()`` |
| 方法调用不确定 | ``PY2CPP_CALL(obj, method, …)`` | ``len(x)`` 当 ``x`` 不确定；``x in container`` → ``__contains__`` |
| 宏派发全部失败 | 译器在宏调用前 ``#line`` + ``static_assert(can_get_<attr>, …)`` | 例：MSVC 指向 ``test/foo.py:12``；文案 ``编译期: PY2CPP_GETATTR: 无法读取成员 'missing'…``（``compile_diagnostic_emit`` UTF-8 字面量） |

**宏定义**（业务 Python **勿**手写；仅译器输出）：

```cpp
/* 宏内经 py2cpp_invoke_* + enable_if 触发 static_assert（失败时仅 C2338，不实例化 pick 失败分支） */
#define PY2CPP_GETATTR(obj, attr)  (::py2cpp::access::py2cpp_invoke_get_##attr((obj), 0))
#define PY2CPP_SETATTR(obj, attr, val) (::py2cpp::access::py2cpp_invoke_set_##attr((obj), (val), 0))
#define PY2CPP_CALL(obj, method) …   /* 0 参；1–3 参为 PY2CPP_CALL1/2/3 */
```

每个翻译单元在 include 块后注入 ``PY2CPP_DECLARE_*``；**每条**含 ``PY2CPP_GETATTR`` / ``SETATTR`` / ``CALL`` 的 C++ 语句前，译器写入 ``#line`` 与前置 ``static_assert``（同一函数内多站点各自一组，见 ``test/fail/test_py2cpp_getattr_multi_site_fail.py``）。

**中文诊断**：``static_assert`` 文案由译器写成 ``\\xHH`` UTF-8 字面量（非源文件内嵌中文 + 宏拼接）；MSVC 须 ``/utf-8``（``compile.py`` 已加）。在终端查看编译输出时，Windows 建议 ``chcp 65001``（``build*.bat`` 已设置），或由 Python 以 UTF-8 解码 ``cl`` 的 stderr（见 ``compile._run``）。

每个翻译单元在 include 块后注入：

```cpp
namespace py2cpp { namespace access {
  PY2CPP_DECLARE_GETATTR(parent);
  PY2CPP_DECLARE_SETATTR(parent);
  PY2CPP_DECLARE_CALL(__len__);
} }
```

``PY2CPP_DECLARE_GETATTR/SETATTR`` 用 SFINAE：值/引用上 ``<attr>__get()`` 或 ``.<attr>``；指针上 ``-><attr>__get()`` 或 ``-><attr>``（**不再**对指针先解引用再 ``.``）。``PY2CPP_DECLARE_CALL`` 对值/指针分别派发 ``.method(args…)`` / ``->method(args…)``。

**边界**：``@property`` 读仍优先 ``<attr>__get()``（有 ``ClassInfo`` 时不走宏）；带 ``()`` 的方法/dunder 走 ``PY2CPP_CALL``；链式 ``a.b.c`` 为**每级一次** ``GETATTR``（仅该级接收者不确定时）。

**``expand_default_iter`` 迭代器**：宿主字段 ``_host`` 生成为 ``Host*``（非 ``void*``），``__init__(Host& _host)`` 中 ``this->_host = &_host``。

**与 ``getattr`` 折叠**：字面量 ``getattr(obj, "field")`` 走 ``expand_static_reflect``；本机制针对 **``obj.field`` / ``obj.method()``** 语法。

回归：``src/tests/test_cpp_attr_dispatch.py``；``test/lang/test_async.py``、``test/util/test_list.py``（``ThreeInts_iterator``）等。

### 7.9 `select`（译期路径选择）

**状态**：G1 已落地（``@dataclass`` / ``list`` struct backend；``JsonDocument`` backend ⏳ G2）。**完整 DSL、EBNF、分期与负例**见 **[selector.md](./selector.md)**。

在 **不引入新 Python 语法** 的前提下，用 **一条字符串字面量路径** 从 receiver 上 **只读** 选取子结构；译器 **内联** 为 C++（IIFE + ``append``），**无** runtime 路径解释器、**无** C++ ``select`` 成员、**无** ``@protocol Selectable``。

```python
names: list[str] = org.select(".teams[0].name")
hits: list[Member] = team.select(".members{.score > threshold}")
sibling: list[str] = org.select(".teams[0]:$t; $t.(members[0].name, members[1].name)")
```

| 规则 | 说明 |
|------|------|
| **调用** | ``receiver.select("…")``；**恰好一个**字符串字面量参数 |
| **返回** | 无后处理：**恒** ``list[T]``；有 ``@sort``/``@group``/``@count`` 时由末步推断（见 [selector.md §4.15](./selector.md#415-后处理sort-group-count)） |
| **注解** | ``AnnAssign`` 须与推断类型一致 |
| **路径根** | 相对 **receiver**；取 struct 字段须 ``.ident`` 起头（``".teams"`` ✓，``"teams"`` ✗） |
| **类声明** | **勿**手写 ``def select``（除非真实方法体且不与译器规则冲突） |
| **与 ``assign``** | 同属 ``TRANSLATOR_ONLY_METHODS``；``assign`` 写字段，``select`` 读路径 |

**路径 DSL 要点**（详见 [selector.md §4](./selector.md#4-路径字符串-dsl)）：

| 特性 | 示例 |
|------|------|
| 字段 / 下标 / 切片 | ``".teams[0].name"``、``"[-1]"``、``".members[1:3]"``、``".teams[:].name"`` |
| 过滤 ``{expr}`` | ``".members{.score > 0}"``；``{…}`` 内为 **Py2Cpp 表达式**；``.field`` 表当前元素字段 |
| 投影 ``.(a, b)`` | ``".f.(a.b, c).d"`` |
| 多路径 | ``".teams[0, 1].name"``、``".(teams[0], teams[1]).name"``（**禁止**顶层 ``",`` 并集） |
| 可选链 ``?`` | ``".teams?[0].name"``、``".data?['k']"`` |
| 递归 ``..`` | ``".teams..name"`` |
| ``:$`` / ``$`` / ``;`` | ``".teams[0]:$t.members[1].name"``；``";"`` 左绑右选；``;`` 右从根导航时 **不可** 引用左段 ``$`` |
| 后处理 | ``".members{.score > 0}@sort(-.score, .name)"``、``".teams@count"``、``".teams[0]:$t; $t.members@sort(.score - $t.minScore, .name)"``（键与 ``{filter}`` 同表达式子集；**禁止** ``@group@sort``、``@group@count``） |

**译器流水线**（非 AST pass，在 ``visit_Call`` / ``visit_AnnAssign`` 触发）：

```text
obj.select(".teams[0].name")
        ▼  parse_selector_literal → SelectorPlan / SelectorChainPlan IR
        ▼  selector_types：TypeGraph walk + 字段/``$`` 绑定校验
        ▼  selector_emit：inline C++ list[T]（无 select() 调用）
```

| 模块 | 路径 |
|------|------|
| 解析 | ``src/passes/selector_parse.py`` |
| 类型 | ``src/analysis/selector_types.py`` |
| 生成 | ``src/emit/selector_emit.py`` |
| 注册 | ``src/emit/call_emit.py``、``translator.visit_AnnAssign`` |

## 8. 装饰器与翻译期展开

装饰器在 `py2cpp/__init__.py` 中为 **恒等函数**；语义由 `passes/*` 在翻译前实现。

| 装饰器 | 作用 | C++ 中是否生成类 |
|--------|------|------------------|
| `@mixin` | 方法内联到宿主；可继承普通类并 **传递基类** 与 **static const** | 否 |
| `friends=(A,)` | 类头 keyword：``A`` 为友元，可访问本类 protected/private；生成 ``friend class …;`` | 否 |
| `@descriptor` | 描述符 `__get__`/`__set__` 内联到宿主 | 否（描述符类） |
| `@annotation` | `Type @Ann` 字段/方法注解，元数据；``@annotation(inheritable=…, repeatable=…)``（见 [§8.2.3](#823-annotation)） | 否 |
| `@refcount` | 引用计数对象模型 | 是（+ `RefCount`） |
| `@boxing` | 堆分配单对象（`new`）；无 `PyRefCount` | 是 |
| `@copyable` | 拷贝构造 + 拷贝赋值 | 是 |
| `@virtual` / `@override` / `@immutable` | C++ 虚函数/const/override | — |
| `@overload` | 同名方法/构造的 C++ 重载签名（见 [8.4](#84-overload)） | — |
| `@delegate` | C# 风格多播委托类型 | 是（+ ``Delegate`` / C++ ``PyDelegate``） |
| `@dataclass` | 从类体字段生成 ``__init__`` / ``__eq__`` / ``__repr__``；可与 ``@copyable`` 等叠用 | 是 |
| `@enum` | 整型 ``enum class``；``...`` 顺延；``@enum(flag=True)``；单继承合并成员（见 [§8.2.2](#822-enum)） | 是（无实例方法） |
| `@union` / `@variant` | Rust 式 ADT；``match`` 构造与解构（见 [编码规范 §4](./编码规范.md#41-类级)） | 是 |
| `@serializable` | 为 ``@dataclass`` / ``@union`` 生成 ``serialize[T: EncoderType]`` / ``deserialize[T: DecoderType]`` | — |
| `@protocol` | 概念/SFINAE traits；**无** C++ 实例类 | 否（traits 写入 `protocol_traits.h` + 使用方 `static_assert`） |
| `@staticproperty` | 静态 getter `Class::name__get()` | — |
| `@context` | 翻译期上下文工厂；``with`` 内联或作装饰器（详见 [§8.6](#86-decorator-与-context翻译期)） | — |
| `@decorator` | 翻译期包装；``yield`` → 调用 ``*_impl``（详见 [§8.6](#86-decorator-与-context翻译期)） | — |

### 8.1 `@mixin` 详解

```python
@mixin
class TestCaseMixin(TestCase):
  _testTag: int @const = 0
  @override
  def run(self, result: TestResult) -> None:
    self.beginTest(result, self._testTag, Self.__name__)
    self.test()
    self.endTest(result)

class MyTests(TestCaseMixin):
  _testTag = 42
  @override
  def test(self): ...
```

展开后宿主 **仅** 在 C++ 中继承 `TestCase`（`TestCaseMixin` 无 C++ 类型）：

- `run` 方法体并入 `MyTests`
- `Self.__name__` → `str("MyTests")`
- `_testTag` 从混入合并，宿主赋值覆盖
- 混入类体 **实例字段**（非 `@const` 的 `AnnAssign` / 带默认值）并入宿主；宿主已声明的字段不覆盖
- `Mixin.iterSubclasses()`：入口模块宿主按 **声明顺序**；`iterSubclasses(sortConst="_testTag")` 按同名 `static const` 升序（`expand_test_discovery`）

参见 `passes/mixins.py`：`propagate_mixin_carrier_bases`、`propagate_mixin_static_fields`、`propagate_mixin_instance_fields`、`apply_mixin_methods`。

### 8.2 `Self`

| 用法 | 翻译结果 |
|------|----------|
| `Self(...)` | 当前类构造函数（`PyList<T>`、`PyStr` 等） |
| `Self.__name__` | `PyStr("ClassName")` |
| `Self._testTag` | `ClassName::_testTag`（静态成员） |
| `Self.iterFields[Ann](mro=True)` | 同上；``mro=True`` 且 ``Ann.inheritable`` 时合并**实体基类**字段（宿主同名覆盖；跳过 mixin/annotation/protocol 基） |
| `Self.iterFields(publicOnly=…, mro=True, glob=…)` / `enumFields(…)` | 类体字段；``glob=`` 为 shell 通配（``fnmatchcase``）粗筛字段名；``mro=True`` 时合并实体基类字段 |
| `Self.getFieldType(field)` | 仅在会被 `Self.iterFields` 展开的混入方法内可用；`field` 须为编译期可确定的当前字段名，译期替换为去除全部 `@` 标记后的字段基础类型；可用于局部变量注解、泛型实参和 `is` / `is not` 类型比较 |
| `Self.iterMethods(…, mro=True, glob=…)` / `Self.iterMethods[Ann](mro=True, glob=…)` | 类体方法；``glob=`` 粗筛方法名；``[Ann]`` 须 ``Ann.inheritable`` 才合并基类方法 |

类体内与 **当前类同型** 的 `new(...)` 在翻译时也会变为 `Self(...)`（见 `_emit_new_ctor_expr`）。

| **叠用** | 可与 ``@copyable``、``@refcount``、``@boxing`` 组合 |
| **未支持** | ``kwOnly``、``slots`` |

### 8.2.2 `@enum`

整型枚举（对齐 CPython 3.13 的 ``IntEnum`` / ``Flag`` 子集，**非**标准库 ``enum`` 模块运行时）。导入：``from py2cpp import enum, int64``。

```python
@enum
class ModeEnum:
  Off = 0
  On = ...
  Debug = ...

@enum
class WideEnum(int64):
  Lo = 1
  Hi = ...

@enum
class ExtEnum(ModeEnum):
  Extra = 10
  More = ...

@enum(flag=True)
class PermFlag:
  Read = ...
  Write = ...
  Exec = ...
```

| 规则 | 说明 |
|------|------|
| **预处理** | ``expand_enum``（``passes/enum_expand.py``），紧接 ``expand_dataclass`` 之后；解析成员后**清空**类体（无 ``__init__`` / 方法 / 实例字段） |
| **类体写法** | 仅 ``name = 整型常量`` 或 ``name = ...``（``Ellipsis``）；须简单赋值，勿写方法 |
| **``...`` 顺延（普通）** | 在**已有成员序列**末值 **+1**；**首项不能**为 ``...``（须显式起始值） |
| **``@enum(flag=True)``** | ``...`` 对齐 CPython ``enum.Flag``：尚无成员时 **1**，否则取当前成员**最大值**的下一个 **2 的整数次幂**（1→2→4→8…） |
| **底层类型** | 默认 ``int`` → C++ ``PyInt``；``class E(int64):`` → ``enum class E : PyInt64`` |
| **单继承** | ``class Child(Parent):`` 仅支持**一个**父 ``@enum`` **或** ``int``/``int64`` 基类；先合并父成员再追加子成员；父为 ``flag`` 时子类自动沿用 Flag 顺延 |
| **C++ 形态** | ``enum class Cls : PyInt { MEM = v, … };``（``emit_enum_declaration``，``src/emit/enum_emit.py``） |
| **成员访问** | ``ModeEnum.On`` → ``ModeEnum::On``（属性读，非实例） |
| **``len(E)`` / ``for x in E``** | ``len(ModeEnum)`` → 成员个数编译期常量；``for m in ModeEnum:`` → 局部 ``static const E _tbl[]`` + 索引 ``for``（声明序，含单继承合并成员；**无** ``__iter__`` / 迭代器） |
| **``int(E.MEM)`` / ``E(n)``** | ``int(ModeEnum.On)`` → ``static_cast<PyInt>(ModePyInt{…})``（``{E}PyInt::operator PyInt()``）；``ModeEnum(1)`` → ``static_cast<ModeEnum>(static_cast<PyInt>(1))``；``class E(int64):`` 时生成 ``{E}PyInt64`` + ``operator PyInt64()``，``int(x)`` 经底层再收窄为 ``PyInt`` |
| **比较** | 同枚举类型 ``==`` / ``!=``（C++ ``enum class``）；**勿**与另一 ``@enum`` 或裸 ``int`` 混比（用 ``int(E.MEM)`` / ``E(n)`` 显式转换） |
| **Flag 位运算** | ``\|`` / ``&`` / ``^`` / ``\|=`` / ``~``；表达式与 ``|=`` 经底层整型运算后 ``static_cast`` 回枚举；模块内另生成 ``operator\|`` 等（``_emit_flag_operators``） |
| **``str`` / ``repr``** | 模块命名空间内全局 ``str(v)`` / ``repr(v)``（``emit_enum_support``）；``str(ModeEnum.On)`` → ``"ModeEnum.On"``；``repr`` → ``"<ModeEnum.On: 1>"``；组合 Flag → ``"PermFlag.Read\|PermFlag.Write"`` / ``"<PermFlag.Read\|PermFlag.Write: 3>"``（与 CPython 3.13 一致） |
| **``match``** | ``case E.MEM:`` → ``subject == E::MEM``（``passes/enum_match.py``）；``case E.A \| E.B:`` 为 **MatchOr**（``== A \|\| == B``），**不**表示 Flag 位掩码匹配——位组合请用 ``guard`` 或 ``(v & E.A) == E.A`` 等 |
| **默认协议** | **不**注入 ``__bool__`` / ``__iter__``（``expand_default_bool`` / ``expand_default_iter`` 跳过 ``@enum``） |
| **未支持** | CPython ``enum.Enum`` 运行时、``auto()``、``iter(E)``/实例成员迭代、与 ``int`` **隐式**互操作、``StrEnum``、推导式 ``[m for m in E]``（除非显式成员表） |
| **范本** | ``test/lang/test_enum.py``（基本 / 继承 / Flag / ``match`` / ``int``·``E(n)``）；``src/tests/test_enum_numeric_emit.py``（emit） |

标准库写法细则见 [编码规范 §4.1](./编码规范.md#41-类级) 中 ``@enum`` 条目。

### 8.2.3 `@descriptor`

描述符类标记 ``@descriptor``，**不生成 C++ 类型**。宿主字段写法（与普通字段相同，**默认值在 ``=`` 右侧**）::

```python
score: int @PlainValueVar() = 0
level: int @ClampedIntVar(0, 10) = 0
value: int @OffsetValueVar(100) = 50   # Desc(100) 为描述符构造实参
```

``Desc`` 的 ``__get__`` / ``__set__`` 内联为宿主 ``name__get()`` / ``name__set(...)``；存储字段 ``name__value``；方法体内 ``self.__value__`` 表示该存储。类内 ``@property`` / ``@property.setter`` 亦可用 ``self.__value__``；``@staticproperty`` / ``@staticproperty.setter`` 用 ``Self.__value__``（规则相同；``name: T @property`` 时存储亦为 ``name__value``）。**勿写** ``@{name}.setter`` 旧式链式装饰。

| 写法 | 说明 |
|------|------|
| ``name: T @Desc(...) = v`` | **唯一**支持的宿主字段形式；勿写 ``name: T = Desc(...)`` |
| ``def __get__(self):`` | 读属性；可仅 ``...`` → ``return self.__value__`` |
| ``def __set__(self, value):`` | 写属性；可仅 ``...`` → ``self.__value__ = value`` |
| ``def __init__(self, …):`` | ``@Desc(a, b)`` 绑定到 ``__init__``；``self._lo`` 等可折叠为常量 |
| **勿写** ``owner`` / ``obj`` | 多余形参翻译期报错；``self`` 即宿主实例 |

回归：``test/lang/test_descriptor.py``。

**泛型描述符（PEP 695）**：标准库 ``py2cpp/util/vars.py`` 提供 ``RangeVar[T: ComparableType]``、``LenRangeVar[T: SizedType]``；宿主仍写 ``level: int @RangeVar(0, 10) = 0``（左侧类型即 ``T``，勿写 ``RangeVar[int](...)``）。内联时将描述符形参 ``T`` 替换为宿主具体类型，并在 ``set_*`` / 签名校验 helper 入口生成 ``Comparable_check<…>`` / ``Sized_check<…>`` 的 ``static_assert``；校验失败 ``raise ValueError``。回归：``test/util/test_vars.py``。

**函数形参 / 返回类型**（与字段相同 ``T @Desc(...)`` 写法；C++ 签名仍为 ``T``）::

```python
def clamped(x: int @ClampedIntVar(0, 10)) -> int @ClampedIntVar(0, 10):
  return x + 1
```

- 进入函数时按形参顺序内联 ``Desc.__set__``；每个 ``return expr`` 前对 ``expr`` 校验。
- ``self.__value__`` 在签名校验中映射为被校验的形参名或返回临时变量（可用来改写非法值，而非 ``raise``）。
- 与 ``@annotation``（``T @Meta``）可叠放：``x: int @Meta @ClampedIntVar(0, 10)``。
- 描述符 / 注解 / 混入及其它特殊类型类名后缀见 [编码规范 §1.0](./编码规范.md#10-标识符命名强制) / [§4.1.2](./编码规范.md#412-反射相关类命名meta--var--mixin)（**S47**）。
- 支持模块函数、实例方法（含 dunder）、``@staticmethod``；描述符须实现 ``__set__``。
- **C++ 辅助函数**：``expand_descriptor_signatures`` 为每个带签名的函数生成 ``__set_<fn>_param_<arg>``（改写形参）与 ``__set_<fn>_return``（改写返回值临时 ``__py2cpp_return``）；模块级函数在 ``.h`` 声明、``.cpp`` 中 **helper 定义须位于** ``clampedId`` 等调用方之前（``_module_functions_emit_order``）。

回归：``test/lang/test_descriptor_func.py``；译器单测 ``src/tests/test_descriptor_signatures.py``。

### 8.3 `@staticproperty`

```python
class Vector2:
  @staticproperty
  def zero() -> Self:
    return Self(0.0, 0.0)
```

→ `static Vector2 zero__get();`，无 `cls` 参数。

**``@property.postsetter`` / ``@staticproperty.postsetter``**：类型由字段注解 ``name: T @property.postsetter(cb, …) = …`` 或 ``value: T`` 形参推断；``cb`` 可为 callable 字段、实例/静态方法（0/1 个除 ``self``/``cls`` 外形参）、``Self.…`` / ``self.…``，**可多参**（如 ``@property.postsetter(_syncToNative, stateChanged)``）。译器合成 ``name__get`` / ``name__set``（``name__set`` 内先写 ``name__value`` 再调 ``name__postset(value)``）；亦可用 ``@property.postsetter def name(…)`` 手写 postsetter 体 → ``name__postset``。不可与 ``@property`` getter / ``@property.setter`` 同属性叠用；字段简写与同名 postsetter 方法互斥；postsetter 内 ``self.__value__`` / ``Self.__value__`` 仍指 ``name__value``。回归：``test/lang/test_postsetter_property.py``。

### 8.4 `@overload`

**规则（与 `typing.overload` 不同，为 Py2Cpp 代码生成约定）：**

1. **只要同一类内出现多个同名方法，每一个都必须标 `@overload`**（含 `__init__` 的多个构造函数）。
2. 函数体为 **`pass` 的存根** → 仍生成 C++ 定义，但函数体为空 `{}`（不再做“仅声明”或自动转发到另一重载）。
3. 函数体含语句 → 正常翻译为该签名的完整实现。
4. 若某方法名已登记在 `method_overloads` 中，**不得**再保留未标 `@overload` 的同名校验方法（分析期报错）。

`__init__` 特殊处理：所有构造函数仍进入 `inits` 列表以生成声明；**实现**只从 `inits` 循环发出一次，避免与 `method_overloads` 重复生成。`str` 的 `__init__(int|float|bool)` 存根仍由 `py2cpp.cpp` 内联 `snprintf` 委托构造（跳过空存根翻译）。

示例：

```python
@overload
def __getitem__(self, index: int) -> T:
  ...

@overload
def __getitem__(self, index: slice[int, int]) -> list[T]:
  ...
```

生成代码采用 **Allman 大括号风格**（左大括号独占一行）：普通语句经 `translator._use_block` 输出；注入片段经 `src/codegen/brace_style.kr_to_allman`；生成器 ``__next__`` 经 `src/passes/generator_emit.py` 的 ``_use_block`` / ``case { ... }``，与 `generated/test/misc/test_io.cpp` 等同风格。

**Codegen C++ 模板**：七宏 ``BEGIN`` / ``END`` / ``EVAL`` / ``Exec`` / ``ECHO`` / ``INCLUDE`` / ``TYPE``（``ECHO`` 插入 ``*_gen.py`` 预生成片段；模板内 C++ API 直接书写）。详见 [codegen-templates.md](./codegen-templates.md)。

### 8.5 `@protocol` 与 SFINAE 约束

协议类用 **`@protocol`** 修饰，方法体为 **`...`**（或 `pass` / `Ellipsis`），**不生成** C++ `class`：

```python
from py2cpp.protocols import ComparableType, IteratorElementType

def sorted[T: ComparableType](s: list[T]) -> list[T]: ...

def zip[ItL: IteratorElementType, ItR: IteratorElementType](left: ItL, right: ItR): ...
```

协议内 ``type Element = ...`` 表示实现类型须提供 ``using Element``（或嵌套类型 ``Element``）；``zip`` / ``ZipIterator`` 用 ``IterableIteratorType`` + ``IteratorElementType``。标准库协议见 `py2cpp/protocols.py`。

**生成物**：

| 文件 | 内容 |
|------|------|
| `generated/runtime/py2cpp/protocol_traits.h` | 全部 `*_check` / `*_impl` / `*_requires`（独立 include guard） |
| `generated/runtime/py2cpp/protocols.h` | 薄壳：`#include protocol_traits.h`、空 `namespace protocols`、`protocols.inl` |
| 使用方（如 `dict.h`） | `static_assert(::DictKey_check<K>::value, …)` 等 |

**为何拆分 `protocol_traits.h`**：`str.h` / `dict.inl` / `list.inl` 与 `protocols.h` 存在 include 顺序与循环依赖；若 traits 只放在 `protocols.h` 内，该头被 include guard 跳过后，`dict.inl` 实例化时可能找不到 `DictKey_check`。因此 `dict` / `str` 等**直接** `#include "py2cpp/protocol_traits.h"`，而不强依赖完整 `protocols.h`。

| 名称 | 含义 |
|------|------|
| `Protocol_check<T>` | SFINAE：类型 `T` 是否满足协议 |
| `Protocol_verify<T>` | 显式 ``static_assert``：不满足时报 ``编译期: 类型 T 不满足 @protocol Protocol`` |
| `Protocol_impl<T>` | `applies == true/false` |
| `Protocol_requires<T>` | 用于函数模板默认非类型模板参数（`= 0`） |

**探测方式**（`src/codegen/protocol_traits_gen.py`）：

- **比较协议**（`ComparableType` / `EquatableType`）：对探测类型 `U` 生成 `decltype(U() < U())` 等表达式，并要求结果为 `PyBool`（**不**探测成员 `__lt__` 等）。另要求：若 `U` 为类且经 ``static_cast<PyBool>`` 可求值（``explicit operator PyBool()``），则须存在成员 `__eq__` 且返回 `PyBool`——避免仅有 conversion operator 的类被误判为满足全序比较（`src/codegen/protocol_traits_gen.py` 中 `reject_pybool_only`）。
- **迭代协议**（`IteratorType`）：`decltype(iter(U&))`、`decltype(next(U&))`（`operators.h` 中的 `::iter` / `::next`）。
- **判等 / 哈希**（`EquatableType` / `HashableType` / `DictKeyType`）：`U == U`、`U != U`；`hash(U)` → `PyInt`。
- **成员检测**（`ContainerType`）：`__contains__(U, PyInt)` 全局函数（`x in c` 同此路径）。
- **字面量初始化**（`AppendableType` / `MutableMappingType`）：`U::append(Element)`、`U::__setitem__(Key, Value)`（`list`/`deque` 的 `[]`、`dict` 的 `{}` 翻译约束）。
- **算术**（`ArithmeticType`）：`::__mod__(U,U)`、`::__truediv__(U,U)`、`::__floordiv__(U,U)`（**非** C `%`/`/`）。
- **数值塔**（`numbers` / PEP 3141，`protocols.py`）：`NumberType`（`hash`）→ `ComplexType` → `RealType` → `RationalType`（`numerator: int = ...` 等字段或 `@property`）→ `IntegralType`（**不**继承 `RationalType`，`PyInt` 可满足）。子协议用 Python 基类合并探测项。
- **协议成员**：关联类型 ``type Element = ...``；实例字段 ``name: T = ...``；属性 ``@property def name(self) -> T: ...``。
- **字符串格式化**（`StringFormatType`）：`::__mod__(PyStr, PyTuple<...>)`（**非** `PyStr %` 裸标量）。
- **上下文管理器**（`ContextManagerType` / `AsyncContextManagerType`）：探测 ``__enter__`` / ``__exit__``、``__aenter__`` / ``__aexit__`` 返回类型（``AsyncContextManagerType`` 要求 ``AwaitableType[T]`` / ``AwaitableType[PyNone]``）。
- **静态虚契约**（仅 ``@protocol``，对齐 C# ``static abstract``）：``@staticmethod`` + ``@abstract``（体 ``...``）或 ``@virtual``（可有默认体）；注解用 ``Self``（勿 ``IParsableType[TSelf]`` 式自引用泛型头）。SFINAE 探测 ``decltype(U::method(…))``；泛型函数内 ``T.method(…)`` → C++ ``T::method(…)``。实体类用 ``@staticmethod`` + ``@override`` 实现（**S18**：模块内 ``func[Cls]`` 绑定协议时强制）；**无**运行期静态虚表。回归：``test/lang/test_static_virtual.py``；负向：``test/fail/test_static_virtual_override_fail.py``。
- 其它全局 dunder：`__pow__` 等映射到 `operators.h` 中的同名函数。

**函数模板约束**（PEP 695）：

```python
def sorted[T: ComparableType](s: list[T]) -> list[T]:
  ...
```

→ C++ 形如 `template<typename T, Comparable_requires<T> = 0> ...`（**仅**在 `.h` 声明带 `= 0`；`.cpp` 定义不再写默认参数）。

**继承**：协议类**不作为** C++ 基类（`RangeIterator`、`range` 等不再写 `(IteratorType[int])`）；满足协议由具体类的 `__iter__` / `__next__` 等保证。

**头文件依赖**：`iterator.h` 等协议模块 traits 会 `#include "py2cpp/operators.h"`。`str.h` 在 **`PyStr` 完整定义之后** 再 `#include` `list.h` / `dict.h` / `tuple.h`，且 `list`/`dict` 等对 `PyStr` 仅 **前向声明**，避免循环 include 导致 `PyStr` 不完整。

### 8.6 `@decorator` 与 `@context`（翻译期）

`from py2cpp import decorator, context`。**无运行时装饰器语义**：`@decorator` / `@context` 在 `__init__.py` 中为恒等桩，由 `passes/decorators.py`（`expand_decorators`）在 **C++ 生成前** 改写 AST。工厂函数本身 **不生成** C++ 定义（从 `module_functions` 移除）。

| 要点 | 说明 |
|------|------|
| **流水线位置** | 在 `expand_generators` **之后**（工厂内 `yield` **不会** 变成 `*_generator`）、`expand_copyable` 之前 |
| **与 `@override` 等** | 仅展开**同模块**内用 `@decorator` / `@context` **定义的工厂**；`@override`、`@immutable`、`@virtual` 等 **不会** 当作工厂处理 |
| **回归** | `test/lang/test_decorator.py`（`build_all.bat`） |

#### 8.6.1 定义工厂

工厂须为模块级 `def`，并在**该函数自身**标 `@decorator` 或 `@context`（不是给工厂再套一层运行时装饰器）：

```python
from py2cpp import decorator, context

@decorator
def repeat(count: int = 2):
  for i in range(count):
    yield

@context
def sample(begin: str = "begin", end: str = "end"):
  print(f"{begin} {__func__.__name__}()")
  yield
  print(f"{end} {__func__.__name__}()")
```

| 规则 | 说明 |
|------|------|
| **分界 `yield`** | `@context` 工厂体内须有**顶层** `yield`（单独一条 `Expr(Yield)`）；`yield` **之前**为 enter、`yield` **之后**为 exit |
| **`yield` 在循环内** | `@decorator` 允许（如 `for` 里多次 `yield`）；`@context` 的 enter/exit 分界仍要求**顶层** `yield` |
| **无顶层 `yield` 的 `@context`** | 与 `@decorator` 相同：整段工厂体**替换**被装饰函数体（不做 enter/exit 切分） |

#### 8.6.2 `@decorator` — 包装函数 / 方法

**用法**：在目标函数上写 `@工厂名` 或 `@工厂名(...)`，工厂名即上节定义的函数名（如 `repeat`）。

```python
@repeat(3)
def func1():
  print("func1()")

@repeat
def func2():
  print("func2()")
```

| 规则 | 说明 |
|------|------|
| **`yield` 语义** | 工厂体内的 `yield` / `(yield)` / `yield ...`（无值或 `...`）表示**调用被装饰函数的实现**；**不要**写 `__func__(...)`（翻译期报错） |
| **生成 C++** | 被装饰函数体 → 工厂体（`yield` 已替换为对实现的调用）；另生成 `{name}_impl` 存放原函数体。模块级为 `static void func1_impl()`；类方法为类成员 `void A::inc_impl()`，调用处为 `this->inc_impl()` |
| **形参绑定** | `@repeat(3)` → 工厂形参 `count` 绑定为 `3`；`@repeat` 无参 → 使用工厂默认值 `count=2`（见 §8.6.5） |
| **类方法** | 支持（如 `@repeat(3) def inc(self): ...`）；仅**入口模块**中的用户类 |

#### 8.6.3 `@context` — 作函数装饰器

与 `@decorator` 类似，但工厂含**顶层 `yield`** 时：enter 语句 + 被装饰函数体 + exit 语句**顺序拼接**进被装饰函数。

```python
@sample
def func3():
  print("func3()")

@sample("start", "stop")
def func4():
  print("func4()")
```

`@sample("start", "stop")` 将工厂形参 `begin`/`end` 绑定为字面量；`@sample` 无参则用默认值 `"begin"` / `"end"`。

**与内层 `with` 叠加**（`test_decorator.py` 中 `A.func`）：先按 `@sample(...)` 展开 enter/exit，再对体内 `with sample:` 做 §8.6.4 内联（内层使用工厂**默认**形参，与外层装饰器实参无关）。

#### 8.6.4 `@context` — `with` 语句内联

当 `with` 满足下列条件时，**不**生成 `__enter__` / `__exit__`，而是把工厂的 enter/exit **内联**进 `with` 块前后：

| 条件 | 说明 |
|------|------|
| 表达式 | `with cm:` 或 `with cm(...):`，`cm` 为同模块 `@context` 工厂名 |
| 数量 | **仅一个**上下文（不支持 `with a, b:`） |
| **`as`** | **不支持** `with cm as x:` |
| 嵌套 | 支持 `with` 出现在 `if` / `for` / `while` 体内；会递归展开 |

```python
def func5():
  with sample:
    print("func5()")

def func6():
  with sample("start", "stop"):
    print("func6()")
```

**其它 `with`**（`StringIO`、`open`（→ `py_open`）、任意实现 `ContextManagerType` 的用户类）：保留 AST，由 `visit_With` 生成 `__enter__` / `__exit__`（见 [§6.3](#63-with-语句)）。内置 IO **不**走 `@context` 内联。

#### 8.6.5 工厂形参绑定

由 `bind_call_params`（`passes/decorators.py`）在展开时替换工厂体内的形参名：

| 调用形式 | 绑定 |
|----------|------|
| `@factory` / `with factory:` | 工厂 `def` 上的**全部默认值**（如 `count=2`、`begin="begin"`） |
| `@factory(a, b)` / `with factory(a, b):` | 位置实参覆盖；关键字实参覆盖对应形参 |
| 部分关键字 | 未写明的形参仍用默认值 |

绑定在**编译期**完成（生成常量或已知的 `PyStr(...)`），无运行时闭包。

#### 8.6.6 `__func__.__name__`

| 场景 | 翻译结果 |
|------|----------|
| `@decorator` / `@context` **作装饰器** | `PyStr("被装饰函数名")`（如 `"func3"`、`"inc"`） |
| **`with` 内联** 的工厂 enter/exit | `PyStr("<with context>")` |

用于日志、调试输出；**不是**运行时 `function.__name__`。

#### 8.6.7 与 `GeneratorType` / 协程的区分

| | `@decorator` / `@context` 工厂 | `def f() -> GeneratorType[...]: yield` |
|---|--------------------------------|-------------------------------------|
| Pass | `expand_decorators` | `expand_generators`（**更早**，但跳过 `@decorator`/`@context` 工厂） |
| C++ | 内联语句 + 可选 `*_impl` | `*_generator` 类 + `switch` 状态机 |
| `yield` | 翻译期“调用被装饰体”或 enter/exit 分界 | 协程挂起点 |

**禁止**在 `@decorator` / `@context` 工厂内混用“生成器返回值”语义；协程体内也不得再写裸 `yield`（见 [编码规范 §7.3](./编码规范.md#73-协程async-def--await--async-for--async-with)）。

#### 8.6.8 限制与不支持

- 无运行时装饰器栈；工厂 **不能** 从其它模块动态引用（须同次翻译、同模块定义）。
- `yield` 带返回值并转发给被装饰函数：仅支持无值 `yield` / `yield ...`（`...` 占位）；其它形式 → `NotImplementedError`。
- `with` 内联：无 `as`、单上下文、非 `async with`。
- `print(file=...)` 未实现；工厂内 `print` 译为 `printf`（见 [§6.5](#65-表达式与运算符)）。

#### 8.6.9 范本

完整用例见 **`test/lang/test_decorator.py`**：`repeat` / `sample`、模块函数与类方法、`with` 与装饰器叠加、`DecoratorTests`（`unittest`）。

## 9. 内存与所有权

### 9.1 显式堆 API

在 **Python 源码** 中调用（生成 C++ 调用，非真执行）：

| API | C++ |
|-----|-----|
| `alloc[T]()` | 单对象 `new` 包装 |
| `free(p)` | 释放 |
| `allocArray[T](n)` | `operator new(n*sizeof(T))` + 对每个元素 `placement new` |
| `freeArray(p)` | **`::operator delete(p)`**（与 `allocArray` 配对；**不是** `delete[]`） |
| `init(p, ...)` | placement new |
| `destroy(p)` | 显式析构（平凡类型为 no-op） |
| `id(x)` | 取 ``x`` 对象地址：值类型 ``&x``；``@refcount`` ``&(*x)``；裸 ``T*`` 为指针值本身（与 ``is`` 身份比较一致） |
| `init(x, …)` / `destroy(p)` / `free(p)` / `freeArray(p)` | **须**省略 ``[T]``（**S07**；C++ 从 ``T*`` 实参推导 ``T``） |

**释放数组前**须对**已构造**元素逐个 ``destroy(p+i)``，再 ``freeArray(p)``。`PyList`、`PyArray` 析构/`reshape`/`_clear` 已按此约定实现。

### 9.2 标准库容器生命周期

| 类型 | 析构/清理 |
|------|-----------|
| `PyArray<T>` / `PyArray2D/3D` | `__del__`：`destroy` 全部已构造元素 + `freeArray` |
| `PyList<T>` | `__del__` → `_clear`（`destroy` + `freeArray`） |
| `PyDict<K,V>` | `__del__` → `_clearEntries`（`destroy` + `free` 每条 `Entry`） |
| `PyDeque<T>` | `__del__` → `_clearNodes`（`destroy` + `free` 每个节点） |
| `PyStr` | 成员 `data: PyArray<PyChar>` 随类析构 |

### 9.3 `@boxing` 与 `@refcount`

**`@boxing`**（见 [编码规范.md](./编码规范.md)）用于链表/哈希桶等**独占堆节点**：

- `DictEntryUnsafe[K,V](...)` → `new PyDictEntry<K,V>(...)`；`DequeNodeUnsafe[T](...)` → `new PyDequeNode<T>(...)`。
- 链接字段：`Pointer[Self]`；释放：`destroy(ptr)` + `free(ptr)`。
- 与 `@refcount`、`@copyable` **不可同用**。

**`@refcount`**：

- `makeRefCount<T>(args...)`：控制块与对象同块分配；析构经类型擦除的 `destroy_fn` 按**真实类型**调用。
- `PyRefCount<U>` → `PyRefCount<T>` 仅当 `std::is_base_of<T,U>`（编译期检查）；共享同一控制块，以 `T*` 访问。
- `RefCount<T>` / `PyRefCount<T>` 通过 `->` 访问 `T`。
- **``T: refcount``**（PEP 695 装饰器约束）：仅编译期校验（``static_assert(py2cpp_refcount_check<T>)``）；``py2cpp_refcount_check<PyRefCount<U>>`` 为真，**无** per-class 偏特化。C++ 模板实参须为 ``PyRefCount<…>``（``list[Node]`` 等对 ``@refcount`` 类自动包装）；``WeakRef[T]`` 内层 ``T`` **不**包 ``PyRefCount``（``PyWeakRef<T>``）。
- **``T: copyable``**：仅编译期校验；``py2cpp_copyable_check<T>`` 对 ``PyByte`` / ``PyChar`` / ``PyBool`` / ``PyInt`` / ``PyInt64`` / ``PyUInt`` / ``PyUInt64`` / ``PyFloat`` / ``PyFloat64`` 及每个 ``@copyable``（含 ``@union`` 隐式 copyable）类保留全局偏特化（``refcount.h`` 之后 emit）。形参 C++ 仍为 ``T``。
- **``T: boxing``**：仅编译期校验；``py2cpp_boxing_check<U*>`` 委派 ``py2cpp_boxing_check<U>``；每个 ``@boxing`` 类保留全局 ``py2cpp_boxing_check<Cls<…>>`` 偏特化（``refcount.h`` 之后 emit）。模板实参 ``A[Cell]`` → ``A<Cell*>``（含 ``Pool[Cell]``；``Pointer[T]`` 在 ``T`` 已是指针时可得 ``T**``）；``T: boxing`` 形参 C++ 仍为 ``T``（实例化后为 ``U*``，成员访问 ``->``）。
- 用于 `TestCase`、`TestSuite` 中 `list[TestCase]` 与 `makeRefCount<Derived>()` 存入基类指针容器等；用户源码勿显式写 `RefCount`（**S31**），清空强引用用 `new()`。

### 9.4 不使用 STL

生成代码 **不链接 STL 容器**。动态数组为自研 `PyArray<T>` / `PyList<T>` 等。

### 9.5 标准库 Python 源码风格

**完整规范**见 **[编码规范.md](./编码规范.md)**（以 `str` / `list` / `dict` 为范本）。摘要：

- 用 `for i in range(...)` / `for x in iterable`，避免 `while i < n: i += 1`（**`deque` 链表遍历除外**）。
- 用 `self[i]`、`x in seq`，避免手写 `.__getitem__` / `.__contains__`。
- 用 `+=` / `-=`，避免 `x = x + 1`。
- 同类实例用 `Self()`，数组/异类用 `new(n)`（带注解）；字符串、元组、字典字面量见 [5.5](#55-构造与字面量约定) 与编码规范。

### 10.0 `util/memory`（``char[:]`` 组合 + 叶子加速）

### 10.1 `serde`（``@serializable`` + JSON 后端）

- **方案 A**：``@serializable`` + ``@dataclass`` → ``serialize(encoder)`` / ``User.deserialize(decoder)``。
- **方案 B**：``@union`` → JSON ``{"tag":"Variant","payload":{...}}``；无字段变体 ``{"tag":"Logout","payload":{}}``。
- 第一版要求 ``serialize[T: EncoderType](self, encoder: T)``（类方法 PEP 695 → C++ ``template<typename Enc>``）。
- **``Json`` 类静态 API**（PEP 695）：``Json.dumps[T](obj)``、``Json.loads[T](s)``（类型 if 分派 + codegen helper）、``Json.dump[T](obj, fp)``、``Json.load[T](fp)``（``return Json.loads[T](fp.read())``；``fp`` 为 ``TextIOWrapper`` / ``StringIO``）。``dump`` 经 ``JsonEncoder`` 直写 sink，**不**经 ``dumps`` 中间 ``str``。同质标量/容器与 ``@serializable`` 由 ``loads`` 类型 if + ``json.inl`` helper 实现；``indent==0`` 时 ``dumps`` 容器走 ``JsonEncoder.fastEncode``；紧凑字段/标量写路径用 ``JsonEncoder.appendListAt`` / ``appendIntAt`` / ``appendQuotedAt``（见 [编码规范 §9.4](./编码规范.md#94-native-原子化基础设施)）。**``varint``** 以 JSON 数字编解码。
- 类型级 API：``serialize[T: EncoderType](self, enc)`` / ``Cls.deserialize[T: DecoderType](dec)``；``JsonEncoder``/``JsonDecoder`` 的 ``dump_*``/``load_*`` 供编码器协议与手写拼装。
- 集成测 ``test/serde/test_json.py`` 以 ``Json.dumps``/``Json.loads`` 为主（含 ``varint`` / ``JsonEncoder`` 冒烟）；``@union`` match：``test/lang/test_union.py``。
- **部分访问 / CRUD**：``@protocol`` ``DocumentType`` + 实现类 ``JsonDocument[T]``（方法均在 ``serde/json.py``）；唯一入口 ``JsonDocument[T].open(path, mode)``（谁泛型谁传参；**禁止** ``JsonDocument.open[T](…)``）；实例 ``doc.load()`` / 快照 ``doc.dump()``；静态字段链译期 lowering（查/改/增/删零成本）；**暂不支持**动态 path。详见 [serde-document-crud.md](./serde-document-crud.md)。

### 10.2 `str` / `bytes` 与 `StringMixin`

- **共享**：`text/mixins.py` 的 `@mixin class StringMixin[T]` 经 `expand_mixins` 内联到 `str(StringMixin[char])`、`bytes(StringMixin[byte])`；宿主声明 **`data: T[:]`**（`PyArray<PyChar>` / `PyArray<PyByte>`）。
- **mixin 已提供**（两类型共用）：`__len__`、整数/切片 `__getitem__`、`find`/`index`/`rfind`/`rindex`（KMP）、`count`、`startsWith`/`endsWith`、**`glob(pattern, ignoreCase=True)`**（对齐 `fnmatch`/`fnmatchcase`，非 `pathlib.Path.glob`）、`__contains__`、`__add__`/`__mul__`、`__lt__`…`__ge__`、`join`、`split`/`rsplit`/`splitLines`、**`splitPrefix`/`splitSuffix`/`rsplitPrefix`/`rsplitSuffix`**（Py2Cpp 扩展：固定 ``maxSplit=1`` 等价；无参重载=空白切分，``sep`` 重载=分隔子串；无 ``maxSplit`` 形参）、**`xsplit`/`xrsplit`/`xsplitLines`**（Py2Cpp 扩展：`GeneratorType[Self, None, None]`，语义同 `split`/`rsplit`/`splitLines`；``xsplit`` 正向扫描渐进产出，``xrsplit`` 产出顺序与 ``rsplit`` 列表一致，``xsplitLines`` 逐行产出）、`strip`/`lstrip`/`rstrip`、`replace`、`makeTrans`/`translate`、`partition`/`rpartition`、`removePrefix`/`removeSuffix`、`expandTabs`、`ljust`/`rjust`/`center`/`zfill`、`lower`/`upper`/`swapCase`/`capitalize`/`title`、`isAlnum`/`isAlpha`/`isAscii`/`isDecimal`/`isDigit`/`isLower`/`isUpper`/`isSpace`、`_append`；`__eq__`/`__ne__`/`__hash__`（`str` 保留带缓存的 `__eq__`/`__hash__`）、`_norm_*`、`_sub`；空白/换行由宿主 `_isFieldWhitespace`、`_isLinebreak`、`_isCrLfPair` 提供；大小写/分类由宿主 `_toLowerChar`、`_toUpperChar`、`_isAlphaChar`、`_isCased`、`_is_decimal_char` 等提供；填充由 `_defaultPadChar`、`_zfillPadChar`；`translate` 输出经宿主 `_translateBufLen` / `_translateDeleteMarker`。
- **`str` 专有**：`PyStr` 码点（BMP 风格）；字面量 `"…"` / `""`；`__eq__`/`__ne__`（哈希缓存）、`__hash__`、`encode`、`split`/`strip`/`is*`、格式化等（见 `str.py`）。
- **`bytes` 专有**：`b"…"` 字面量；`bytes(n)` 零填充构造；`__repr__`；`decode`；`bytes[i]` 为 **`byte`**（Py2Cpp 扩展，非 CPython 3.13 的 `int`）。**未实现**：`fromhex`/`hex`、ASCII `capitalize`/`lower`/… 等。
- **`startsWith` / `endsWith`**：除单个 `Self` 外，支持 **`list[Self]`** 与堆 **`Self[:]`**（`str[:]` / `bytes[:]`，`new(n)` 后逐元素赋值；语义同多段 tuple）及 **`char[:]` / `byte[:]`**（单段裸缓冲）；栈定长 **`Self[:N]`** 须先切片为堆 `Self[:]` 或改用 `list[Self]`。**不支持**元组字面量参数。
- **`glob`**：`StringMixin` 公开实例方法；内部 ``_glob_*`` 亦为实例 helper（见 [编码规范 §6.0.1](./编码规范.md#601-私有-helper-实例方法优先)）。`ignoreCase=True`（默认）时对 name 与 pattern 做 `io.file.path.normCase` 等价规范化（`/`→`\` + ASCII `lower`）；**无**独立 `fnmatch` 模块。
- **`makeTrans` / `translate`**：`str` 用 `dict[char, char]`，`translate(table[, delete=new()])`（删除经 `makeTrans(..., remove=)` 写入 `_DeleteChar`）；`bytes` 用 `dict[byte, byte]`，`translate(table, delete=new())` 为默认空 `delete`（`delete` 中字节恒删；表内删除哨兵 `_DeleteByte`）。实现均在 `StringMixin`。
- **`find` / `rfind`**：正向/反向均为 **KMP**（`O(n+m)`）；`rfind` 保留区间内**最后一次**匹配。
- **`str`**：`__reversed__` → `PyStrReverseIterator`；`partition` / `rpartition` 为元组字面量；`str.format` / f-string 编译期子集；无 `operator||`，用 `explicit operator bool()`。

### 10.3 `list[T]`

- 底层 `PyArray<T>`（`data`）；逻辑长度 `_length`，与 `data.shape` 解耦（仅 `reshape` / `_clear` 时同步 `data.shape`）。
- **扩容**：CPython `list_resize` 规则 `(newSize + (newSize >> 3) + 6) & ~3`（非简单 2 倍）。
- 空列表 / 同类新建：标准库内 `Self()`；用户代码可用 `x: list[T] = []` 或 `new()`（有注解时）。
- **Python 3.13 可变序列**：`append`, `extend`, `insert`, `remove`, `pop`, `clear`, `index`, `count`, `sort`, `reverse`, `copy`。
- **`sort(key=, reverse=)`**：稳定 **Timsort**（自然 run + minrun + 二分插入扩展 + 归并）；`key` 为 `Function[[T], int]` 函数指针，`None` 表示按元素比较。
- **`__cmp__`** → 六个比较运算符；`==` 与逐元素比较一致。
- 运算符/协议：`__getitem__`/`__setitem__`/`__delitem__`（含切片，均 `@overload`）、`__add__`/`__iadd__`、`__mul__`/`__imul__`、`__reversed__`、`__iter__`、`__str__`/`__repr__`。
- `list[T](a,b,c)` **已废除**；用 `[a,b,c]` 或多次 `append`。
- `list(iterable)` 构造 **未实现**。

### 10.4 `dict[K, V]`

- `__getitem__`, `__setitem__`, `__contains__`, `__iter__`（键）, `get`, `__len__`；业务逻辑用 `key in self`，见 [编码规范.md](./编码规范.md)。
- 字面量：`d: dict[K,V] = {}` / `{k: v, ...}`；`out: Self = {}` 用于 `copy` / 合并。
- 桶数组：`buckets: ...[:] = new(capacity)`；冲突链节点 `@boxing class DictEntryUnsafe` → `new PyDictEntry<...>`，**`__del__` / `__copy__` 前** `_clearEntries` 释放旧链。

### 10.4 `set[T]` / `frozenset[T]`

- **元素约束**：`T` 须满足 ``DictKeyType``（``hash`` + 判等），与 ``dict`` 键相同。
- **空集合**：``s: set[T] = set()`` 或 ``set()``；**勿**用 ``{}``（那是 ``dict``）。
- **非空集合**：``s: set[T] = {1, 2}``、``fs: frozenset[T] = {…}``；集合推导与字面量同注解（``set`` 直 ``add``；``frozenset`` 临时 ``set`` + ``initFromSet``）；``for … in range`` 等同列表推导限制。
- **C++ 名**：``PySet<T>``（模块路径 ``util/set`` → 命名空间 ``py2cpp::util::py_set``）。
- **字面量**：带 ``add`` 方法的类型（含 ``set[T]``）可写 ``x: T = {…}``；``frozenset[T] = {…}``、``frozenlist[T] = […]``、``frozendict[K,V] = {…}`` 经临时可变容器 + ``initFrom*``，不暴露 ``append``/``add``/``insert_new``。
- **可变集合子集**（CPython 3.13）：``add``/``remove``/``discard``/``pop``/``clear``/``copy``/``update``、``|``/``&``/``-``/``^`` 及 ``|=`` 等、``isSubset``/``isSuperset``/``isDisjoint``、``__iter__``、``__cmp__``（无序，**无** ``__reversed__``）。
- **传参**：``list``/``dict``/``set``/``frozenset``/``deque`` 形参按 **``const T&``** 传递。
- **赋值**：``b = a`` 为移动（非 ``@copyable``）；``moved`` 为真后勿再读写该对象。
- **`frozenset`**：``fs: frozenset[T] = {…}``、``frozenset()``、``frozenset(list)``、``frozenset(other_set)``。
- 回归：`test/util/test_list.py` 等（`SetBasicsTests` 等，``_testTag`` 201–207）。

### 10.4.1 `frozenlist[T]` / `frozendict[K, V]`

- 与可变容器共享底层布局（`FrozenListMixin` / `FrozenDictMixin`）；**无**就地修改 API（无 `append`/`__setitem__` 等）。
- **构造**：空表 ``[]``/``{}``；非空字面量或 ``new(list|frozendict)`` 拷贝（``initFrom*`` 会先 `_clearEntries`）；勿空 ``frozendict()``/``frozenlist()``/无参 ``new()``。
- **迭代器 / 视图**：持 **`const` 指针** 遍历宿主（`FrozenListIterator._lst`、`frozendict_*._dct`）；`keys`/`values`/`items` 视图同样持指针，**不**拷贝整表。
- **`frozenlist`**：`__getitem__`、切片、`__iter__`、`__contains__`、`count`/`index`、`copy`、`__cmp__`（写在宿主类，因 `@overload` 不入 mixin）。
- **`frozendict`**：`__getitem__`、`__contains__`、`keys`/`values`/`items` 及对应迭代器、`get`、`copy`、`__cmp__`（键值相等，与插入序无关）。
- 回归：`test/util/test_list.py` 等（``FrozenListTests`` / ``FrozenDictTests``，``_testTag`` 208–209）。

### 10.5 `io`（`StringIO` / `TextIOWrapper`）

### 10.5.1 `time`

- **Python**：`py2cpp/system/time.py`（模块函数存根，实现在 `.inl`）。

### 10.6 `deque[T]`

- 侵入式**双向**链表（`DequeNodeUnsafe` 含 `prev`/`next`）；`append` / `appendLeft` 分配 `@boxing` 节点（`new` → `PyDequeNode`）。
- 方法对齐 Python 3.13 `collections.deque`：`append`/`appendLeft`、`extend`/`extendLeft`、`pop`/`popLeft`、`clear`、`copy`、`count`、`index`、`insert`、`remove`、`reverse`、`rotate`、`maxLen`（构造 `deque[T](n)`；未限长时 `maxLen()` 返回类常量哨兵 `Self._NoMaxLen`，对应 Python `None`）、`__reversed__`、`__add__`/`__mul__`/`__imul__` 等。
- 类内哨兵：`_EndIndex` / `_NoMaxLen` 为 ``@const``；``_normStop`` 等用 ``Self._EndIndex`` 比较（见 [编码规范 §6.1](./编码规范.md#61-哨兵形参)）。
- 空双端队列：``out: deque[T] = []``（``__add__``、``_repeated`` 等）；``return Self()`` 用于 ``-> Self`` 的早退（与 §5.3.1 形参 ``T0``/``void*`` 无关）。
- **`__del__`** / `clear()` 遍历释放全部节点（`destroy` + `free`）。
- 回归：`test/util/test_list.py` 等 中 `DequeLiteralTests`、`DequeMethodsTests`。

### 10.7 `tuple` / `PyTuple`

- 值：`(a, b)`、`return (x, y, z)`；**不要** `tuple[T,U](a,b)` 构造（除非无字面量语法的边缘情况）。
- 类型注解：`(T, U)` 与 `tuple[T, U]` 等价，均译为 `PyTuple<T, U>`。
- 编译期下标 `t[0]` → `get<0>()`（常量下标）。
- **单次求值**：`a, b, c = sl.indices(n)` 翻译为一个临时 `PyTuple`，避免悬垂引用。

### 10.8 内置（`__init__.py`）与 `operators.h`

- `range` → `py2cpp::util::range::PyRange`（**不**继承 `IteratorType`；``util/range.py``；``__iter__``/``__len__``/``__getitem__``/``__contains__``/``count``/``index``/``start``/``stop``/``step``/``__eq__``（``__ne__`` 由 ``expand_default_ne`` 注入）/``__reversed__``；**无** ``__lt__``/``__le__``/``__gt__``/``__ge__``；构造 ``PyRange(n)`` / ``PyRange(a, b[, s])``）
- `new` → 类型上下文构造（见 [5.5](#55-构造与字面量约定)）
- `dataclass`、`enum`、`union`、`variant`、`copyable`、`optional`、`const`（类型标记 ``@optional`` / ``@const``）→ 翻译期装饰器/标记；**无** ``field()`` / ``@autoinit``；``@enum`` 见 [§8.2.2](#822-enum)
- `len`, `print`, `zip`, `enumerate`, `next`, `iter`, `aiter`, `anext`, `reversed`, `repr` 等桩
- `alloc` / `free` / `init` / `destroy` 等内存 API 桩
- **`Function`**：C 函数指针类型标记（如 `Function[[T], int]`），用于 `list.sort(key=)` 等
- **`Callable`**：可绑定槽位类型标记（如 `Callable[[T], int]` → `PyCallable`），用于委托 `+=` / `-=`
- **`operators.h`**（由 `layout_emit` 展开 `templates/operators.h`，经 `minimal.h` 聚合）：`__pow__`、`len`、`iter`、`next`、`aiter`、`anext`、`reversed`、`repr` 的模板/重载；`len`/`iter`/`next`/`aiter`/`anext` 支持 **指针** 实参（如 `this`、`*_lst`）
- **`ZipIterator[ItL, ItR]`**（`PyZipIterator`）：保存两侧具体迭代器类型 `ItL`/`ItR`；`zip` 的步进值为 `PyTuple<...>`；`enumerate` **优先**索引内联（§6.2），否则 `EnumerateIterator` + `PyTuple<int, T>`

### 10.9 `ui`（Panel；译期 ``iterFields``）

模块：`py2cpp/ui/`（…）。字段遍历写在 ``UIPanelMixin`` 内，由 ``expand_iter_fields_meta``（``Self.getFieldAnnotation[Meta](field)``）或 ``expand_str_annotation_match``（旧式 ``match ann``）译期展开。

| 编译期 API | 说明 |
|------------|------|
| ``Self.iterFields(publicOnly=True)`` | 仅名不以 ``_`` 开头的字段（``UIPanelMixin`` 默认） |
| ``Self.getFieldAnnotation[AnnMeta](field)`` | 字段含该 ``@`` 则译期非 ``None``；``UILabelMeta`` → ``.text``；``UISliderMeta`` → ``.lo`` / ``.hi``；``*Meta`` 可 ``@annotation`` + ``@dataclass`` |
| ``Self.getFieldAnnotations(field)`` | 多 ``@`` 迭代（可选；Panel 先用 Label 再查其它 Meta） |

**Win32 用法**（推荐一行）：

```python
cfg: PlayerConfig = new()
cfg.showPanel()   # 默认 ``width``/``height`` 为 ``-1`` 按控件自适应；``showPanel("Title", 480, 360)`` 可固定客户区
```

分步（自定义标题、样式或复用 ``win``）：

```python
win: UIWindow = obj.createPanel("Title", -1, -1)   # 已 ``show`` / ``drawPanel`` / ``resize``，尚未 ``exec``
UIApp.run()   # 消息循环结束后 ``UIFormLayout`` sync 写回字段
```

或完全手写：

```python
win: UIWindow = new()
win.title = "Title"
win.show(-1, -1)   # ``-1`` 先最小隐藏窗口，布局后 ``resize``
obj.drawPanel(win)
win.resize(-1, -1)
UIApp.run()
```

**控件层**（Phase 0）：``UIObject`` 基类含 ``name: str``、``id: int``（按钮 ``id`` 按 ``@UIButtonMeta`` 方法声明序 0…）；``UIWidget`` 子类另含 ``handle``（Win32 句柄，``apply`` 挂载后写入）。``UICheckBox`` / ``UILineEdit`` / ``UIIntEdit`` / ``UIFloatEdit`` / ``UISlider`` / ``UIPushButton`` 由 ``UIFormLayout`` 登记并在 ``apply(win)`` 时挂载 Win32 控件；``UIPanelMixin`` 译期展开字段后自动 ``add_*`` 并 ``syncFromNative`` / ``syncToNative``。已移除旧 API：``UIWindow.input`` / ``button`` / ``pull`` / ``push`` / ``synced``。

``UIApp``（``py2cpp/ui/app.py``；Qt-like）：``isAvailable()`` 探测 Win32 后端；``run()`` 全局消息循环。``UIWindow(UIWidget)`` 继承 ``handle``；顶层窗口 ``show`` / ``close`` / ``resize`` / ``title`` / ``style``。

``UIWindow.title`` 为显式 ``@property``（存储 ``_title``）；``win.title = …`` 在已 ``show`` 时经 ``SetWindowText`` **即时**更新 caption（``show`` 前赋值则在建窗时使用）。

**Win11 外观**（``UIWindow.style`` / ``UIStyle``；C++ 在 ``UIWindow.show`` 时按窗口 DPI 缩放应用）：Common Controls v6 manifest、Per-Monitor DPI v2、默认 Segoe UI 11pt、紧凑行距、面板 ``(243,243,243)``、DWM 圆角。``WM_CTLCOLOREDIT`` 仍按 ``panelColor`` 着色输入框；``STATIC`` 标签 / 按钮 / 勾选框透明背景；滑条用 ``TBS_TRANSPARENTBKGND`` 且不走 ``WM_CTLCOLORSTATIC`` 透明刷，避免黑底与拖动重影。布局 metrics 用 ``(int, int)`` / ``(int, int, int)`` tuple（``margin``、``labelSize``、``editSize`` 等）；``rowSpacing`` / ``formSpacing`` 为标量。单行 ``EDIT`` 高度取 ``editSize[1]``（非 ``labelSize`` 行高）。

| ``UIStyle`` 字段 | 默认 | 含义 |
|------------------|------|------|
| ``fontName`` / ``fontSize`` | ``"Segoe UI"`` / ``11`` | 面板字体 |
| ``textColor`` / ``panelColor`` | ``(0,0,0)`` / ``(243,243,243)`` | RGB |
| ``margin`` | ``(12, 10)`` | 水平边距、顶边距（``show`` 设 ``nextY``） |
| ``labelSize`` | ``(88, 22)`` | 标签列宽、行槽高 |
| ``editSize`` | ``(260, 22)`` | 文本/int 编辑框宽×高（与行槽对齐） |
| ``sliderSize`` | ``(260, 22)`` | 滑条宽×高 |
| ``checkboxSize`` | ``(18, 18)`` | 勾选框 |
| ``buttonSize`` | ``(260, 22)`` | PushButton 宽×高 |
| ``rowSpacing`` / ``formSpacing`` | ``4`` / ``8`` | 行间距、标签与控件间距 |

自定义样式：构造 ``win`` 后改 ``win.style.*``，再 ``win.show(…)``（``show`` 后改 style **不**热更新）。

**暴露策略**：``UIPanelMixin`` 用 ``Self.iterFields(publicOnly=True)``，默认仅暴露**公有**字段（名不以 ``_`` 开头）；隐藏私有字段另可用 ``@UIInvisibleMeta`` 屏蔽仍出现在迭代中的公有字段；标签 ``@UILabelMeta("…")``；范围 ``@UISliderMeta(0, 100)``（与 ``RangeVar`` 无关，UI clamp 在控件层）。

**按钮**（``@UIButtonMeta`` 标在**无参实例方法**上；字段之后、按类内声明顺序布局）：

```python
@UIButtonMeta()          # 标签 = 方法名 ``apply``
def apply(self) -> None: ...

@UIButtonMeta("保存")
def save(self) -> None: ...
```

``UIPanelMixin`` 混入宿主 dataclass；``drawPanel`` 构建 ``UIFormLayout`` 并 ``apply``。``@UIButtonMeta`` 方法在 ``_ensurePanelForm`` 中译期展开为 ``UIPushButton.clicked +=`` 三线：``panelSyncFromForm``（``syncFromNative`` + 字段写回）→ 用户方法 → ``panelSyncToForm``（``push_row_*`` → 控件 ``__set`` → postsetter ``_syncToNative``）。``UICheckBox.stateChanged`` / ``UILineEdit.textChanged`` / ``UIIntEdit``·``UIFloatEdit``·``UISlider.valueChanged`` 接 ``panel_on_*_changed`` → ``panelSyncFromForm``（拖动/编辑时实时写回字段）。Win32 ``WM_COMMAND`` / ``EN_CHANGE`` / ``WM_HSCROLL`` 经 ``ui_form_on_*`` 触发控件 ``checked__set``/``text__set``/``value__set``；**事件处理末尾不再 ``syncToNative``**（避免 ``SetWindowText``/``EN_CHANGE`` 重入卡死）。Slider 拖动亦不回写 ``TBM_SETPOS``。``UIEventDelegate`` / ``UIValueChangedDelegate[T]`` 为 ``@delegate`` 信号。``@UIButtonMeta("…")`` 仅控制按钮 caption；``btn.id`` 为 ``iterMethods[UIButtonMeta]`` 声明序（0 起）。宿主完全重写 ``drawPanel`` 且不含 ``iterMethods`` 循环时**不**自动加按钮。

编译期反射：``Self.iterMethods(publicOnly=…)``、``Self.iterMethods[Ann]()``、``Self.getMethodAnnotation[AnnMeta](method)``。

**约束**：``drawPanel(win)`` 的 ``win`` 须 ``@ref``；``drawPanel`` **勿** ``@immutable``。注解 ``match`` 仅 ``case X():`` / ``case _:``。``ui/__init__.py`` **勿** re-export 子模块。

范本：``test/ui/test_panel.py``、``test/ui/test_widget.py``、``test/ui/test_window.py``；``demo.bat panel``。

**暂不实现**：``UIGroupMeta`` / ``UIShowIfMeta``、嵌套 dataclass 递归、enum 下拉、每帧 Immediate Mode GUI。

### 10.10 `ui.flow`（蓝图编辑器）

**完整规格**：[ui-flow.md](./ui-flow.md)。

模块：`py2cpp/ui/flow/`（``meta``、``model``、``catalog``、``builtins``、``runtime``、``layout``、``style``、``canvas``、``panel``、``shell``、``palette``、``serialize``）。通用画布：``py2cpp/ui/canvas.py``（``UICanvas`` / ``+canvas.inl``）。宿主 ``@dataclass`` 混入 ``UIFlowMixin``；**方法级** ``@FlowNodeMeta`` / ``@FlowPureMeta`` / ``@FlowEventMeta`` 译期注册为 palette 节点；内置 Branch/ForLoop；``FlowRuntime`` 沿 Exec 执行图。

**用法**：

```python

```

**交付阶段**：

| 阶段 | 内容 |

| **P2.1** ✅ | ``FlowRuntime`` + 内置 Branch/ForLoop；**Run** Play / Play from Selected / Stop |

**菜单（摘要）**：

| 菜单 | 典型项 |

## 11. 单元测试框架

模块：`py2cpp/test/unittest.py`（**非** CPython `unittest`）。

### 11.1 模型

| 类型 | 说明 |
|------|------|
| `TestCase` | `@refcount`；`failures` 计数；软断言（不抛异常） |
| `TestResult` | `@refcount`；跨 `run`/`beginTest`/`endTest` 共享计数与用例名（**勿**按值传递） |
| `TestCaseMixin` | `@mixin(TestCase)`；提供默认 `run` |
| `TestSuite` | `list[TestCase]`（C++：`PyList<PyRefCount<TestCase>>`） |
| `TextTestRunner` | ``verbosity``：0 静默；1 进度 ``[n/N] PASS/FAIL``（每行含 ``perfCounter`` 耗时）+ 汇总总耗时；2 另含 ``tag`` |

### 11.2 编写用例

```python
from py2cpp import *
from py2cpp.test.unittest import TestCaseMixin, TestSuite, TextTestRunner

class MyTests(TestCaseMixin):
  _testTag: int @const = 1        # 覆盖混入 static const；子类可写 _testTag = N 无重复注解

  @override
  def test(self):
    self.assertEqual(1, 1)
    self.assertTrue(True)
    # @copyable：b2: Box = b；@dataclass 关键字：box: Box = new(w=1)
    # 生成器：next(g)；文件：assertTrue(f) 勿 f.__bool__()

def main():
  suite: TestSuite = new()
  for Class in TestCaseMixin.iterSubclasses(sortConst="_testTag"):
    suite.addTest(Class())         # → makeRefCount<…>()
  return TextTestRunner().run(suite)  # 0=成功
```

**无反射**：不会自动发现 `test_*`；**一个类一个 `test()`**（原 `test_core` 等合并进单一 `test()`）。

`test/**/test_*.py`（`build_all.bat` 集）与 `test/lang/test_protocol.py`（`build_protocol.bat`）**必须**采用上表结构；`main` 只负责跑 suite。范本见 [编码规范 §10](./编码规范.md#10-测试代码test)（``test/lang/test_dataclass.py``、``test/lang/test_kwargs_options.py``、``test/lang/test_protocol.py`` 等）。

`assertEqual`, `assertNotEqual`, `assertTrue`, `assertFalse`, `assertIs`, `assertIsNone`, `assertIsNotNone`, `assertIn`, `assertNotIn`, `assertGreater`, `assertGreaterEqual`, `assertLess`, `assertLessEqual`

## 12. 与 CPython 对比

| 维度 | CPython | Py2Cpp |
|------|---------|--------|
| 执行 | 字节码解释 | 预编译为 C++ 机器码 |
| 类型 | 运行时动态 | 编译期注解 + 分析 |
| 对象模型 | `PyObject*` 统一 | 每类生成独立 C++ 类型 |
| 异常 | 全功能 try/except | 极少；断言多用计数 |
| 迭代器停止 | `StopIteration` 异常 | `IterResult` 的 `done` / `Return` 变体 |
| 字符串 | Unicode 灵活、UTF-8 | `PyStr` 码点数组；已实现 3.13 方法集 |
| `list` | 完整内置 + 列表推导等 | `PyList` 子集；Timsort；`sort(key=)` 为函数指针 |
| 比较 / 排序 | 富比较、`key` 任意可调用 | 推荐 `__cmp__`；`key` 须 `Callable` 或元素可 `<`；泛型约束用 `@protocol` + SFINAE |
| 迭代器协议 | `collections.abc.IteratorType` 运行时 ABC | `IteratorType[T]` 为编译期 traits；生成器 `for` 展开为 `PyIterResult` |
| 委托 | `functools`、单播函数 | `@delegate` 多播；同参调用、末返回值 |
| 导入 | 任意模块 | 仅翻译捆绑的标准库+用户代码 |
| 反射 | `getattr`, `inspect` | 仅字面量 `getattr`/`setattr` 折叠 |
| GIL / 线程 | 有 GIL | 无解释器；`py2cpp.concur.thread` 提供 `Thread` / `Lock` / `atomic[T]` / `Queue[T]` 子集，跨线程共享对象需自行同步 |
| 标准库 | 完整 | 见第 10 节子集 |
| 枚举 | ``enum.Enum`` / ``IntEnum`` / ``Flag`` 运行时 | ``@enum`` 翻译期 ``enum class``；``len(E)`` / ``for m in E`` 内联；``str``/``repr``/Flag 位运算子集对齐 3.13（见 [§8.2.2](#822-enum)） |
| `unittest` | 发现 `test_*`、mock | `TestCaseMixin` + 显式 `test()` |
| 开发调试 | pdb、REPL | `--debug` 日志；需重新翻译编译 |

**结论**：语法 **看起来像 Python**，语义是 **静态 C++ 子集**；不要假设任意 PyPI 代码可移植。

## 13. 与 C++ 对比

| 维度 | 手写 C++ | Py2Cpp 生成 |
|------|----------|-------------|
| 语法源 | C++ | Python 子集 |
| 标准库 | STL / 第三方 | 自研 `py2cpp` 运行时（翻译自 .py） |
| 模板 | 直接使用 | 由 PEP 695 生成 |
| 多态 | 虚函数、接口 | `@virtual` / `@override` + `PyRefCount` |
| 字符串 | `std::string` | 自定义 `PyStr` 类 |
| 异常 | C++ 异常 | 有限 `throw`；多用返回值/计数 |
| 内存 | RAII、智能指针 | `PyRefCount` + `alloc`/`destroy`/`freeArray` 显式 API；容器析构已补齐 |
| 代码风格 | 任意 | 生成 C++ 默认 **Allman** 大括号 |
| 构建 | CMake 等 | `main.py -c` 或 `compile.py` |
| 可读性 | 生成代码冗长 | 以 Python 为单一真相源 |

**何时用手写 C++**：需 STL、异常、线程库、完整 C++20、或与现有 C++ 工程深度集成时。

**何时用 Py2Cpp**：算法用 Python 写更清晰、目标为独立 exe、可接受标准库子集与翻译约束。

### 14.4 常见问题

| 现象 | 可能原因 |
|------|----------|
| 切片/字符串比较错 | 曾有多重 `PyTuple.get` UB；已要求单次 unpack；需重译 runtime |
| `range` 负步长 / 切片 | 须用 `step>0` / `step<0` 分支；勿假定 `i < stop` |
| `allocArray`/`freeArray` 不配 | 须 `destroy` 后 `freeArray`（标量 `delete`，非 `delete[]`） |
| 委托 `d(5)` 期望链式 | 多播为**同参**调用；`d+=f; d+=g` 时 `d(5)` 为 `g(5)` 非 `g(f(5))` |
| `@overload` 混用 | 同名方法必须**全部** `@overload`；`pass` → 空 C++ 体 |
| `print` 失败用例名乱码 | 对 `PyStr`/`list[str]` 下标须推断为 `PyStr`；重译 runtime |
| `this` 传参错 | 成员函数内 `f(self)` 须为 `f(*this)`（按值参数） |
| 未初始化 `_testTag` | 混入须 `_testTag: int @const = 0`；子类写 `_testTag = N` 覆盖 |
| MSVC 找不到 cl | 运行 `vcvars64` 或使用 `build_*.bat` |
| `PyStr __str__` / `encode` 编译错 | 多为 `str.h`↔`list.h` 循环 include；重译 runtime（见 [8.5](#85-protocol-与-sfinae-约束)） |
| `DictKey_check` 未定义 / `static_assert` 失败 | 确认 `dict.inl` 或 `dict.h` 能见到 `protocol_traits.h`；勿只 include 被跳过的 `protocols.h` |
| LNK2005 符号重复（`PyStr`/`unittest` 等） | 测试 TU 勿同时链接 `py2cpp.cpp` 与完整 `minimal.h`（`compile.py` 已对 `test/` 跳过）；重译 runtime |
| LNK2019 `py_open` / `format` | `io.inl` 须含 `py_open`；`minimal.h` 末尾须含 `operators.inl`（标量 `format`） |
| `bytes.inl` 找不到 `repr` | 使用 `this->__repr__()` 或确保 `operators.h` 已 include；勿在 const 成员中对 `this` 单独 `::repr(this)` 除非有指针重载 |
| `len(this)` / `len(ptr)` 无匹配 | 使用 `operators.h` 指针重载，或写 `len(*p)` |
| `PyListIterator` 无法从 `PyList` 转换 / 无默认构造 | 重译 runtime（`list.__iter__` 须为 `PyListIterator<T>(this)`；`ListIterator` 须有无参 `@overload` `__init__`，见 [编码规范 §6.3 / §7.1](./编码规范.md#71-生成器函数yield--yield-from)） |
| 生成器 `while+yield` 只产出一次 | 旧版状态机在 `break` 后直接 `return done`；升级译器并重译 |
| `with` 与 CPython 异常语义不一致 | 生成代码 ``__exit__()`` 无参数；勿依赖 ``exc_type`` 等 |
| 文件打开失败仍编译通过 | ``fopen`` 失败时对象为假；测试用 ``assertTrue(f)`` / ``assertFalse(f)``，勿 ``f.__bool__()`` |
| 类体 ``h: int = 1`` 变成 ``static const`` | 实例默认**勿**加 ``@const``；类常量写 ``h: int @const = 1`` |
| ``field()`` / ``@autoinit`` | 已移除；用 ``@dataclass`` + 类体默认值或手写 ``__init__`` |
| 测试关键字构造 ``Cls(a=1)`` | 用 ``obj: Cls = new(a=1)``（§5.5） |
| ``@copyable`` 测试拷贝 ``Cls(src)`` | 用 ``dst: Cls = src`` |
| bootstrap 报 ``new() 需类型上下文`` | 检查类体 ``name: T = new(...)`` 是否缺 ``T`` 注解；``@dataclass`` 勿留 ``field_defaults`` 中的 ``[]`` AST；方法体内 ``self._f``/``other._f``（``Self`` 形参）赋值 ``new(...)`` 或空 ``[]``/``{}``/``""`` 等须能解析字段类型 |
| 模板形参 ``node.parent`` 编译/链接怪 | 确认是否应改为 ``node: Node``；宏路径见 [§7.8](#78-编译期成员派发py2cpp_getattr--py2cpp_setattr--py2cpp_call) |
| 非字面量 ``select`` path | 须字符串字面量；见 [§7.9](#79-select译期路径选择) |
| ``select`` 路径语法 / ``$`` 作用域错 | 对照 [selector.md §4.13–§4.14](./selector.md#413-同链-绑定与--引用) |

## 15. 接手建议与常见坑

### 15.1 修改翻译器的流程

1. 若改 **标准库行为**：编辑 `py2cpp/<域>/*.py`，重跑 `python main.py py2cpp\__init__.py -o generated --no-main`。
2. 若改 **语法/代码生成**：编辑 `src/translator.py` 或 `src/passes/*.py`，补充 `src/tests/`。
3. 若改 **类型规则**：`src/analysis/analyzer.py`、`src/analysis/ir.py`。
4. **不要** 直接改 `generated/`（会被覆盖）；改源后重新翻译。

### 15.2 添加标准库 API

1. 在对应 `py2cpp/<域>/xxx.py` 添加方法（Python 实现逻辑）。
